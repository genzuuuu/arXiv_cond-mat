## 一、灵巧手、多指抓取与手中操作

**ConGraspXL** 在 GraspXL 基础上加入可控约束条件（接近方向、接触区域、手腕轨迹、功能手型等），提出层次化约束表示与掩码残差接口，可组合多种任务约束，作为即插即用的底层抓取控制器，支持全身抓取补全与人体动作模仿。
[ConGraspXL](https://arxiv.org/abs/2609.16319)

**UniDex-ViTac** 利用人类视频引导仿真生成机器人演示与指尖接触观测，训练统一的视触觉灵巧操作策略（ACT 骨干），仅用二值接触信号即可在仿真与真机上超越纯点云基线，真机成功率达 66.4%。
[UniDex-ViTac](https://arxiv.org/abs/2609.16504)

**ProxiDex** 提出"动力学引导的近邻策略"，将手-物近邻作为交互状态，构建硬件无关的接触表征，并用动作条件化的近邻动力学（前向-逆向耦合）在视觉不可靠时稳定动作生成，支持 VR 遥操作中的沉浸反馈。
[ProxiDex](https://arxiv.org/abs/2609.16586)

**Residual Fault Adaptation (RFA)** 针对灵巧手手中操作中的运行时关节故障，用冻结的健康教师策略 + 循环残差策略补偿隐藏的命令通道故障，配合故障注入域随机化，实现零样本真机部署。
[RFA](https://arxiv.org/abs/2609.17404)

**Fingers as Legs** 让拟人手用同样的手指完成自支撑移动与操作：RL 训练 + 仿真标定 + 位置控制器，实现无缆爬行、转向、跌倒恢复，并在无视觉条件下执行键盘指令、在有俯视视觉时推动物体。
[Fingers as Legs](https://arxiv.org/abs/2609.17172)

**SlipSense** 基于 TacV5（32×32 压阻阵列 240Hz + 3 轴 MEMS 加速度计 8kHz）做多模态滑动检测，跨模态注意力 + 因果时序预测，Macro F1 96.7%、23.1ms 内检出 76% 滑动事件，并能零样本迁移到 Tesollo 灵巧手。
[SlipSense](https://arxiv.org/abs/2609.15910)

**Hand Pose & Contact Forces from Wrist-Worn Pressure Sensor Array** 用腕带式电容压力阵列 + 循环网络从肌肉/肌腱位移推断全手姿态与逐指接触力，MAE 4.6°，力估计 R²=0.57（配合外部位姿可达 0.75），为机器人学习提供高频触觉演示。
[Wrist-Worn Pressure Array](https://arxiv.org/abs/2609.16518)

## 二、VLA 模型与视觉-运动策略

**TEMPO** 指出 VLA 在动态操作中的两大表征失败——运动模糊与状态混叠，通过冻结视频基础模型提取运动摘要 + 紧凑本体历史解决，Bottle Handover 成功率从 44% 提升到 74%，并发布 TEMPO-Bench。
[TEMPO](https://arxiv.org/abs/2609.16864)

**XRoboToolKit-T** 提出带触觉驱动的遥操作系统，包含稳定器触觉模块（法向力分布 + 伪剪切力）与精修器触觉模块（VLA 预测修正动作），在移液、注射器插入等接触密集任务上提升数据采集效率与稳定性。
[XRoboToolKit-T](https://arxiv.org/abs/2609.16437)

**ManiSkillFormer** 提出神经-符号框架，用任务条件化"几何契约"（关键点、表面法线）连接感知与动作，LLM 生成契约与运动模板并存入技能库，在双臂机器人上实现无演示的组合式操作（抓放 88.24%、长程任务 50–80%）。
[ManiSkillFormer](https://arxiv.org/abs/2609.16331)

**SAVLA** 提出对称感知 VLA：冻结 VLM 骨干，配合等变 flow-matching 动作头与规范化器，将状态/动作/条件分解为不变与等变通道，LIBERO 平均提升 5.1 点，LIBERO-Goal 旋转鲁棒性从 41.5% 提升到 90.4%。
[SAVLA](https://arxiv.org/abs/2609.16641)

**The Latent That Never Was** 对 ACT 中 CVAE 消融做取证式复现：原始论文报告的从 35% 跌到 2% 的效果未能重现，推理时 latent 实际被置零不使用，跳过编码器还可提升训练吞吐；发布代码与评估工具。
[ACT CVAE Re-run](https://arxiv.org/abs/2609.16745)

**Rethinking Visual Embodiment Dependence** 研究"视觉具身依赖"（VED），提出 3D 点云中的具身规范化（规范末端执行器表示 CER），保留控制相关几何、抽象形态，显著改善无机器人演示的人到机器人策略迁移，并给出配置去相关增强。
[CER / VED](https://arxiv.org/abs/2609.16815)

**AdaDE (Dense→MoE)** 将 VLA 中稠密 FFN 块转为 MoE 层，利用路由器统计导出专家保留掩码，动态去激活 40% LLM 参数后仍保留 LIBERO 95.1%、RobotWin2.0 42.0% 的成功率。
[AdaDE](https://arxiv.org/abs/2609.16503)

**FluxVLA Engine** 开源、配置驱动的 VLA 工程平台，统一数据格式、训练、仿真评估、优化推理与机器人接口，集成双臂仿真、自动数据生成与人在环 rollout/接管/修正、实时分块（RTC）加速推理。
[FluxVLA Engine](https://arxiv.org/abs/2609.17210)

**MPCoT** 提出奖励引导的多路径潜在推理框架（可配置深度 K、宽度 M），在 LIBERO/CALVIN 与 ALOHA 双臂任务上把 OpenVLA-OFT 平均成功率从 71.3% 提升到 82.0%，且不生成推理 token。
[MPCoT](https://arxiv.org/abs/2606.06245)

**vla-eval** 开源 VLA 统一评测框架（WebSocket+msgpack + Docker 隔离），支持 14 个仿真基准与 6 个模型服务，并行评测最高 47× 加速，并发布聚合 657 条结果的 VLA 排行榜。
[vla-eval](https://arxiv.org/abs/2603.13966)

**DIDO** 通过分布匹配蒸馏 + 交互中心表征引导，把多步视频世界模型蒸馏为单步去噪，LIBERO 99.0%、LIBERO-Plus 76.6%、RoboTwin 92.0%，显著降低闭环控制延迟。
[DIDO](https://arxiv.org/abs/2609.15570)

**ReWeight** 用演示级检索 + 样本级加权把自我中心人类数据融入 VLA 后训练，学习跨具身视觉运动表征衡量人机行为相似度；仿真 39%→57%，真机平均 68.8%。
[ReWeight](https://arxiv.org/abs/2609.13851)

**ISS Policy** 在 DiT 骨干扩散策略上加入隐式场景监督：由生成动作预测末端运动，再预测未来点云表征，并设计非对称梯度路由与变化平衡目标；MetaWorld/Adroit 达 SOTA。
[ISS Policy](https://arxiv.org/abs/2512.15020)

**sensVLA** 面向轮式装载机的空间落地 VLA：Qwen3-2B VLM + flow-matching 动作专家，BEV 特征经专用交叉注意力直接送入动作专家，纵向速度 RMSE 降低 28%，相机流损坏时退化减少 29%。
[sensVLA](https://arxiv.org/abs/2609.17021)

**ShieldVLA** 基于 HJ 可达性做安全对齐微调，用视觉观测学习无模型可达值函数，配合基于 rubric 的 VLM 安全分数；五个基准上安全代价平均降低 57%，成功率 +0.13。
[ShieldVLA](https://arxiv.org/abs/2609.13231)

**FiberTune** 指出 VLA 微调存在"动作纤维上的视觉残差坍缩"，用在线动作探针过滤动作预测方向并对齐冻结视觉教师的残差，六个仿真设置全胜，真机 SO-101 从 72.7%→78.1%。
[FiberTune](https://arxiv.org/abs/2606.08653)

**ActSafeGuard** 为 flow-matching 策略提供可微、与训练对齐的硬约束保障层，通过解析射线缩放算子让策略自然学习约束流形，在 π0.5 与 Fast-WAM 上实现 100% 步级安全率且不损成功率。
[ActSafeGuard](https://arxiv.org/abs/2609.11697)

**TIDAL** 提出时域交错的扩散-动作循环，高频微控制环与低频宏意图环解耦，动态拦截任务性能提升 2.5×，反馈频率提升 4×，真机上对未建模动力学更鲁棒。
[TIDAL](https://arxiv.org/abs/2601.14945)

**DiffAdapterVLA** 把轨迹 token 注入驾驶 VLM 后层，使规划在骨干内部完成，用逐层 DiffAdapter 做递归轨迹精修，NAVSIM 上以少量可训练参数实现低延迟闭环规划。
[DiffAdapterVLA](https://arxiv.org/abs/2609.15322)

**世界-动作模型相关**：**World-Action Models Survey** 系统综述 WAM（表征、转移建模、动作接口、数据与扩展），提出"可信—可控—可行动"三级能力框架；**ModAR** 首个自回归去噪多模态（点轨迹、DINO 特征、深度）再预测动作的 WAM，训练 FLOPs 约为视频模型初始化方案的 1/20；**WholeBodyWAM** 将预训练世界-动作先验扩展到人形全身移动操作，仿真成功率 91.9%。
[WAM Survey](https://arxiv.org/abs/2609.16074) | [ModAR](https://arxiv.org/abs/2609.17524) | [WholeBodyWAM](https://arxiv.org/abs/2609.16644)

**World Models for Embodied Intelligence** 另一篇世界模型综述，提出 Plausible / Controllable / Actionable 三级能力与 3×4 矩阵，强调以"是否改善闭环行为"为评价标准。
[World Models Survey](https://arxiv.org/abs/2609.16697)

**XPACE** 统一具身世界模型，同时作为世界-动作模型与世界模拟器，用共享视频骨干连接异质经验（无动作视频 + 有人类/机器人动作演示），并用自生成恢复数据做策略自改进，已在 XPENG IRON 人形上验证。
[XPACE](https://arxiv.org/abs/2609.17372)

**GeoLAM** 从无动作人类视频学习几何落地的潜在动作：冻结几何特征层次重建 + 训练期 4D 几何教师监督，可见性/置信度加权，部署时无需教师与未来视频生成。
[GeoLAM](https://arxiv.org/abs/2609.17099)

**Auto-HSI** 用 LLM 在线自动生成个性化人-集群交互代码：用户用自然语言 + 手势演示说明期望集群行为，系统自动生成状态机控制 50 个仿真机器人（进球、迷宫变形、分组进球），并演示真机运行与运行时接口更新。

## 七、人形与全身控制

**Weave** 从人体-物体交互演示学习全身灵巧人形操作：接触感知重定向 + 接近运动补全 + 接触/几何感知策略（29 身体关节 + 12 手指关节），9 类物体训练交互 92.5%、未见序列 65.0%，并开源约 9,000 条物理执行 rollout。
[Weave](https://arxiv.org/abs/2609.16683)

**RECAL** 机器人-环境交叉注意力层，包裹"看不见几何"的全身控制器，用点云交叉注意力在平衡/跟踪目标与避碰之间权衡，支持浮基与末端指令及持物避碰，仿真多场景优于其他几何感知 WBC，真机 Digit V3 验证。
[RECAL](https://arxiv.org/abs/2609.16405)

**Learning Human-Like Badminton Skills** 提出"模仿到交互"渐进 RL 框架，从人类数据建立运动先验并蒸馏为紧凑状态表征，用流形扩展把稀疏击球点泛化为稠密交互体，实现人形羽毛球零样本 sim-to-real。
[Badminton Humanoid](https://arxiv.org/abs/2602.08370)

**Skill Composition for Legged Robot RL** 立场论文：把独立子策略的组合本身当作研究问题，主张安全、随时可切换的组合机制能把"下一步做什么"交给规划器/自动机/符号控制器，使机器人行为可预先验证。
[Skill Composition](https://arxiv.org/abs/2609.14647)

**SafeFlow** 文本驱动人形全身控制：物理引导的修正流匹配 + 三级安全门（文本嵌入 Mahalanobis OOD 检测、方向敏感度过滤、硬运动学约束），Unitree G1 上在成功率、物理合规性与推理速度上优于扩散与重定向基线。

## 八、世界模型安全与其他具身智能交叉

**Backdoor Attacks on Latent World Models** 揭示预训练世界模型作为"现成动力学骨干"复用的供应链后门：仅控制发布 checkpoint 即可劫持下游控制器（Dreamer 想象式 actor 训练或 MPC/CEM 规划都会自行"重新发现"攻击目标动作），触发时 100% 劫持且干净任务仍保持约 75% 成功率，触发移除后失效。
[World Model Backdoor](https://arxiv.org/abs/2609.15781)

**MameLoshnLM** 首个开源 8B 意第绪语模型（Llama 3.1 继续预训练）+ Oytser 高质量预训练语料 + Kashes 多任务基准，指出网络规模多语数据的噪声问题是低资源语言建模的普遍失败模式。
[MameLoshnLM](https://arxiv.org/abs/2608.05850)

**ZebraArena** 程序化生成、知识最小化的诊断环境，用于研究工具增强 LLM 的"推理-动作耦合"，具备可控难度与理论最优查询数，发现 GPT-5、Gemini 2.5 Pro 在困难实例仅约 60% 准确率、工具调用比最优多 70–270%。
[ZebraArena](https://arxiv.org/abs/2603.18614)

**MCPAgentBench** 基于真实 MCP 定义的任务基准，用动态沙盒向 agent 呈现含干扰项的候选工具列表，评测工具选择/鉴别能力与执行效率。
[MCPAgentBench](https://arxiv.org/abs/2512.24565)
