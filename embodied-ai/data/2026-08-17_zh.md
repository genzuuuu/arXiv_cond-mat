# 今日机器人学与人工智能论文速览

## 具身智能与VLA模型

**[BICPO-VLA: Behavior-Identified Continuation Preference Optimization for Smooth Asynchronous Vision-Language-Action Control](https://arxiv.org/abs/2608.13924)**
针对请求到交接间隙的三重耦合问题（行为意图歧义、物理状态漂移、残差不兼容），提出指令感知因果历史编码器识别行为，通过顺序Haar子空间生成将动作块分解并加速生成，最后通过Flow-DPO在行为匹配候选中实现对生成块的适应性调整。

**[AdvDex: Learning Dexterous Manipulation from Human Demonstrations via Joint-Aligned Actions and Adversarial Learning](https://arxiv.org/abs/2608.14028)**
提出统一的视觉-语言-动作框架，包含OmniShare多模态人手演示数据集和JAAS（关节对齐动作空间，SE(3)腕部姿态+15手指关节），通过域对抗学习消除实施例特异性信息，实现零样本人-机器人技能迁移。

**[Reflex: Enabling Fast and Predictive Vision-Language-Action Models for Reaction-Critical Manipulation](https://arxiv.org/abs/2608.14379)**
提出ReflexBench基准（6个动态任务）和ReflexVLA模型，通过潜在未来预测和多帧时序融合增强时序推理，利用批量视觉编码与CUDA Graph回放降低部署延迟，用于反应关键的动态操作场景。

**[Evolve Vision-Language-Action Model into an Agent with On-the-fly Tool-use](https://arxiv.org/abs/2608.14047)**
提出ART（Agentic Robot with Tool-use）框架，将VLA模型与工具注入结合，通过工具使用降低动作解空间复杂度，在少量数据（30K轨迹）下实现20%的成功率提升。

**[StageWAM: Joint-Embedding Stage Prediction for World-Action Models in Robot Manipulation](https://arxiv.org/abs/2608.10780)**
区分短期物理未来与阶段级语义未来，通过Stage-JEPA预测下一推断阶段的潜在目标，在50个RoboTwin 2.0任务上达到90.25%成功率。

**[ATOMOS: 空间机器人遥操作演示](https://arxiv.org/abs/2608.14031)**
展示平面航天器模拟机器人在有损延迟网络下的遥操作控制，结合状态预测与轨迹跟踪实现对接操作，包含首尔-斯德哥尔摩洲际远程实验。

## 灵巧操作与触觉感知

**[CHORD: Learning Dexterous Manipulation Using Contact Wrench Guidance From Human Demonstration](https://arxiv.org/abs/2607.00033)**
提出以物体为中心的接触力/力矩空间引导框架，将人手与机器人运动统一到诱导瞬时运动的相似性度量上。构建含4,739个双手灵巧操作任务的大规模仿真基准，平均成功率82.12%，并成功迁移到真实机器人。

**[From Reach to Insert: Tactile-Augmented Precision Assembly under Sub-Millimeter Tolerances](https://arxiv.org/abs/2605.04649)**
提出IL+RL两阶段触觉增强精密装配方法。在0.05mm最严苛间隙下实现67%成功率，最大接触力降低60%、力矩降低44%。引入触觉组采样和触觉评价器提升关键接触段覆盖率。

**[Effect of Twisted-Yarn Architecture on Pressure and Proximity Sensing Characteristics of Textile Capacitive Sensors](https://arxiv.org/abs/2608.14406)**
系统研究纱线层级架构（1/2/4层绞合）对纺织电容传感器压力与接近感测特性的影响。四层传感器灵敏度达0.1331 MPa⁻¹，低迟滞、15,000次循环稳定，4×4阵列实现空间接触映射，机器人集成延迟403ms。

**[Estimating Dynamic Soft Continuum Robot States From Boundaries](https://arxiv.org/abs/2505.04491)**
提出基于基底力/力矩传感器的软体连续机器人动态状态估计对偶设计（边界观测器），Lyapunov分析证明收敛性，发现增益-收敛率的凸关系使参数调优高效化。

## 世界模型与规划

**[hint²: Hierarchical World Models for Inference-Time Temporal Logic Guidance](https://arxiv.org/abs/2608.13678)**
利用层级世界模型在推理时引导短视策略满足LTL时序逻辑规范。高层模型预测任务原子命题转换，低层动力学模型提供局部安全引导，在CALVIN上超越现有推理时引导方法，并成功部署于UR5e。

**[OccPlanner: Goal-Aware Occupancy-Conditioned Diffusion Planner for Pixel-Goal Navigation](https://arxiv.org/abs/2608.14160)**
将像素目标导航中的目标像素通过L3ROcc转换为自车度量空间局部3D占用标注，条件扩散规划器在未知场景中将成功率从20.81%提升至71.55%。

**[LatentAM: Real-Time, Large-Scale Latent Gaussian Attention Mapping](https://arxiv.org/abs/2602.12314)**
在线3DGS建图框架，通过在线字典学习构建可扩展的潜在特征图，支持开放词汇机器人感知，12-35 FPS近实时速度。

**[Marionette: Predicting World States, Rendering Geometry, Painting Appearance](https://arxiv.org/abs/2608.14530)**
将交互式游戏世界模型解耦为世界状态预测、零参数渲染器和外观合成。预测276维显式3D世界状态，可编辑和修复长期行为一致性。

**[Traj-LeWM: Path-Aware World-Model Planning via Latent Trajectory Cost](https://arxiv.org/abs/2608.14125)**
在轻量级视觉世界模型中引入目标条件潜在轨迹代价，结合端点距离与路径信息进行规划排序，在Push-T、OGBench-Cube等任务上提升3-14个百分点。

## 操作sim-to-real与机器人学习

**[PFM-HR: Pose Flow Matching for Humanoid Robots](https://arxiv.org/abs/2608.03227)**
提出可复用的流匹配先验（PFM-HR），直接从大规模无序姿态数据训练，通过Pose Geometry Score调制跟踪奖励，提升单动作与通用动作跟踪性能。

**[A Change of Frame Makes Balance Observable: Humanoid Single-Leg Stance](https://arxiv.org/abs/2608.00500)**
提出Deployable Dynamic-CoM（DDC）策略，通过坐标系变换使动态质心观测可仅从编码器和IMU重建，实现单腿平衡89/90保持成功率，并零样本迁移至Unitree G1。

**[Genie Sim 3.0: 人形机器人高保真综合仿真平台](https://arxiv.org/abs/2601.02078)**
基于LLM的自然语言场景生成工具，发布200+任务、10,000+小时合成数据开源数据集，验证零样本sim-to-real迁移能力。

## 机器人与自主系统（其他）

**[Communication in modular robotic motor control](https://arxiv.org/abs/2608.13904)**
受大脑双侧半球组织启发，提出双GRU模块循环控制器，通过可学习延迟通道通信，在肌肉骨骼模拟器中显著优于单块架构和無通信模块控制器。

**[Vibration Suppression in Collaborative Flexible Payload Manipulation](https://arxiv.org/abs/2608.14244)**
面向聚变反应堆远程维护，提出领导-跟随双机械臂协同操作柔性载荷的振动抑制策略，通过等效质量-弹簧-阻尼建模和导纳控制实现被动能量耗散。

**[Spatiotemporal Tube-Based Safety-Certificate for Articulated Vehicles](https://arxiv.org/abs/2608.14531)**
为铰接车辆（牵引半挂车、AGV等）提出时空管安全证书规划方法，确保后挂车厢始终在道路走廊内。

**[Coverage Aware Active Evaluation for Failure Discovery](https://arxiv.org/abs/2608.13719)**
结合代理评估与有限目标系统结果，通过控制变量残差建模预测目标风险，在自动驾驶、操作和四足速度跟踪任务中发现高达2倍于随机采样的失败。

## 机器人视觉与导航

**[Graph-MambaNav: 利用物体关系知识的目标导航](https://arxiv.org/abs/2608.13723)**
提出目标感知时空图Mamba编码框架，利用LLM先验初始化节点排序和边权重，在AI2-THOR和RoboTHOR上提升导航性能并验证真实机器人部署。

**[OpenBelief-Nav: Evidence-Preserving Object Memory for Open-Vocabulary Navigation](https://arxiv.org/abs/2608.13923)**

## 自主驾驶与无人机

**[BDD 感知与规划系列](https://arxiv.org/abs/2608.13878)**
提出知识-数据双驱动强化学习（KDDRL），通过条件深度生成模型合成意图感知未来轨迹，解决混合交通中意图不确定性、长尾安全和混合动作空间问题。

**[PILOT: Privileged Imitation Learning for UAV Motion Planning](https://arxiv.org/abs/2608.14082)**
面向部分可观测性的约束感知特权模仿学习框架，通过TCN融合历史深度图像与里程计，计算开销降低80%以上，并实现室内外零样本部署。

**[AgilePE: Autonomous UAV Pursuit-Evasion via Self-Play Reinforcement Learning](https://arxiv.org/abs/2608.14135)**
完整自主无人机体追逃系统，通过竞争性自博弈（PFSP）和多样化对手池训练，硬件对齐仿真管线实现零样本迁移到真实四旋翼。
