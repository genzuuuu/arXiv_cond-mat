## 一、灵巧操作、多指抓取与手中操作

- **GUARD**：用策略训练分布学到的异常分数做 Q-steering，引导扩散/flow 策略避开低支持区域；Adroit 四个任务名义 96%、扰动 80%，并在手中旋转螺丝刀任务实现真机 sim-to-real，成功率提升 40/25 个百分点。[GUARD: Anomaly-Informed Q-Steering for Generative Robot Policies in Dexterous Manipulation](https://arxiv.org/abs/2611.10343)

- **SimDuoReal**：以对象位姿为唯一奖励训练双臂 RL，自发涌现预抓取、重抓、手中调整与换手；蒸馏为单一策略后真机 80 次试验成功 61 次（76.3%），仿真条码扫描 85% 对比双臂无换手 60.4%。[SimDuoReal: Object-Centric Bimanual Policy for Emergent Dexterity](https://arxiv.org/abs/2611.10410)

- **DexForesight**：把动作条件化的空间世界模型（预测 3D 手部点运动与视觉特征变化）隐式注入灵巧策略 latent，部署时只用 RGB；DexJoCo 11 任务 49.4%→60.5%，真机 58.3% 对比最强基线 50.0%。[DexForesight: Grounding Dexterous Policies with Implicit Spatial Foresight](https://arxiv.org/abs/2611.11166)

- **BAT-WAM**：面向灵巧手的 world-action model，分别学习触觉与动作码本，用 RGB 条件 latent bridge 双向连接；全遮挡下触觉重建 RMSE 降 34.73%，部分遮挡降 38.84%，未来触觉预测相对 OpenWAM+HandTouch 降 85.56%。[BAT-WAM: Bridging Action and Touch in World-Action Models for Dexterous Hands](https://arxiv.org/abs/2611.10967)

- **Grasp-Taxonomy Conditioning**：把四类攀岩抓法标签作为 DP3 点云策略的“模式开关”。不加标签时仿真 rollout 全部退化为 jug 抓（正确率 25%），加标签 94%；80 次配对真机试验平均滑脱力 9.6N→14.3N，完全滑脱比例 44%→10%。[Grasp-Taxonomy Conditioning as a Mode Switch for Dexterous Grasping of Climbing Holds](https://arxiv.org/abs/2611.12017)

- **Grip, Trace, Write**：自由持笔的高自由度书法，双分支 actor 分离“握笔保持”与“臂腕书写”，BC 初始化 + RL 优化墨迹/力/时间/保持奖励；无需微调即泛化到未见中英文内容。[Grip, Trace, Write: Force-Aware Imitation and Reinforcement Learning for High-DoF Robotic Handwriting](https://arxiv.org/abs/2611.10451)

- **GAP（灵巧钢琴）**：学习“如何适应”而非“如何动作”的适应先验，用梯度引导网络根据配对执行结果调整下一步动作；仿真 F1 提升约为 fast-adaptation 基线的 2.4 倍，真机每曲约 7 分钟适应后 F1 提升 3.6%–23%。[GAP: Generalized Adaptation Prior for Dexterous Piano Playing](https://arxiv.org/abs/2611.12111)

- **HOM（相对接触速度手-物机构）**：把手机械与工具统一为“手-物机构”，用统一的笛卡尔相对接触速度描述运动，五款不同灵巧手均可由同一简单参考轨迹完成“抓取—装夹—挥舞”全过程。[Relative Contact Velocity-Controlled Hand-Object Mechanism for Dexterous Tool Manipulation](https://arxiv.org/abs/2609.25619)

- **混合腱-连杆手指**：4 个机械自由度仅用 3 个驱动器，DIP 通过四连杆+扭簧+限位与 PIP 耦合，腱绳走线引入 MCP-PIP 机械耦合；指尖峰值力 4.56N，可与圆柱、长方体、不规则物体形成不同接触姿态。[Design of a hybrid tendon-linkage finger with coupled and adaptive motion](https://arxiv.org/abs/2611.11885)

- **Lang2Morph**：用 LLM 把自然语言任务需求映射为 OPH 参数化手部形态，结合任务推理、几何约束与反馈筛选；三只制造出的手在操作任务上呈现明显不同的功能特性。[Lang2Morph: Language-Driven Morphological Design of Robotic Hands](https://arxiv.org/abs/2509.18937)

- **LFX**（非机器人，仅一笔带过）：光场多形态融合的语义分割/SOD 框架。[LFX: Fusion-Form-Flexible Light Field Modeling for Dense Semantic Segmentation and Salient Object Detection](https://arxiv.org/abs/2503.00747)

## 二、触觉感知与视触觉融合

- **触觉可替代腕部相机**：在视觉+自我中心视角基础上加入两片低成本触觉阵列，训练/部署均不用腕部图像；三个接触密集任务中加腕相机提升 18.3–28.3 个百分点，加触觉提升 31.7–60.0 个百分点，且在三个任务上均优于带腕相机的纯视觉策略。[Tactile Sensors Are an Effective Substitute for Wrist Cameras in Contact-Rich or Occluded Manipulation](https://arxiv.org/abs/2611.10490)

- **Which Taxels, Not How Many**：在固定教师、训练流程与候选 taxel 的受控协议下比较触觉配置，三款手、手掌内旋转与抓取任务。结论：由接触统计选出的一小部分 taxel 即可匹敌大规模均匀布置；少接触位点的 taxel 等价于无触觉；全 taxel 下输入张量排布不影响性能——均匀布置高估了任务所需 taxel 数。[Which Taxels, Not How Many: Tactile Sensor Placement for Dexterous Policies](https://arxiv.org/abs/2611.10647)

- **LingBot-Touch**：跨压阻、磁性、视触觉等异构传感器的统一触觉表征基础模型，token 即插即用，可接入 diffusion policy 与 π0.5、LingBot-VLA 等 VLA，在多平台仿真与真机上稳定提升灵巧操作。[Learning Heterogeneous Tactile Representation for General Dexterous Manipulation](https://arxiv.org/abs/2611.12806)

- **PCTac**：力致变色光子晶体指尖，以稠密色相场作为触觉观测，标定显示法向载荷与色相响应可重复；接入 Diffusion Policy 后 90 次真机 rollout：PCTac Hue 75.6% vs PCTac RGB 66.7% vs 楔形 RGB 63.3% vs 纯视觉 32.2%。[PCTac: Mechanochromic Photonic-Crystal Tactile Sensor for Dexterous Manipulation](https://arxiv.org/abs/2611.12383)

- **SpectraTac**：无相机、主动 RGB 照明 + 分布式颜色感知的光学触觉传感器，直径 19.2mm、厚 4mm、成本 <5 美元；三维力 MAE 为 0.161/0.164/0.429N，九区域接触分类 99.9%。[SpectraTac: A Compact Camera-Free Optical Tactile Sensor with Distributed Color Sensing](https://arxiv.org/abs/2608.30368)

- **AetheRock + ForceVT**：臂戴式采集装置（GelSlim-Mini + 指部压阻），ForceVT 用视觉与力引导触觉表征学习，缓解制造差异与传感器退化；平均性能较视触觉基线 +13%，触觉保真度下降时仍保持 55.0% 任务进度（满保真 58.0%）。[AetheRock: An Arm-Worn Robot Teaching System for Force-Guided Vision-Tactile Learning](https://arxiv.org/abs/2606.09777)

- **柔性压电触觉识别**：32 传感器 + 100ms 时窗在边缘平台端到端约 101ms、每次推理 63.8µJ，F1 达 0.9903。[Flexible Piezoelectric Tactile Sensing System for Intelligent Object Recognition](https://arxiv.org/abs/2611.07779)

- **Tactile MNIST**：面向主动触觉感知（分类、定位、位姿、体积估计）的 Gymnasium 兼容基准，含 13,580 个合成 3D 数字与 600 个 3D 打印数字的 153,600 条真实触觉样本，并用 CycleGAN 做真实感渲染。[Tactile MNIST: Benchmarking Active Tactile Perception](https://arxiv.org/abs/2506.06361)

- **UniOMA**：在对比损失上加入 Gromov–Wasserstein 重心正则做几何感知的多模态结构对齐，重点覆盖力/触觉等样本密度不均的模态，在五个机器人基准上优于 SOTA 对比基线。[UniOMA: Unified Optimal-Transport Multi-Modal Structural Alignment for Robot Perception](https://arxiv.org/abs/2611.12351)

## 三、视觉-语言-动作（VLA）策略与视觉-运动学习

- **SPARK-VLA**：冻结 3D 专家、把 3D 理解蒸馏进 LoRA 视觉分支，并用由动作损失梯度监督的轻量 router 选取动作相关视觉 token；仅 0.5B 语言骨干、约 53M 可训练参数，在 LIBERO/Plus、CALVIN 与真机操作上表现强劲。[Spatial Representation Distillation and Knowledge Routing for Vision-Language-Action Models](https://arxiv.org/abs/2611.10443)

- **RAGu**：把 DROID 等域不匹配演示通过几何标定 warp 到目标域，粗到细检索最兼容轨迹，并在 flow-matching 推理过程中做引导而非改权重；真机 VLA 成功率 20%→80%，覆盖仿真、sim-to-real 与跨本体人形操作。[Zero-Shot VLA Adaptation with Retrieved Guidance](https://arxiv.org/abs/2611.10894)

- **PAIR**：用本体感受对齐联合的“图像-射线”表征，把相似机器人状态在跨视角下拉近；可训练 DP 或后训练 VLA，仿真与真机分别较无射线条件的 BC 基线高 12.7 与 26.7 个百分点。[PAIR: Proprioception-Aligned Image-Ray Representations for Viewpoint-Robust Manipulation](https://arxiv.org/abs/2611.11798)

- **OASIS**：让中间表征与动作空间共享刚体几何——用 SE(3) 末端轨迹预测作为监督，动作解码器以预测器的位姿监督隐状态为条件生成动作块；仿真与真机在成功率与 OOD 泛化上优于 VLA/WAM 基线。[OASIS: Observation-Action Space Alignment via SE(3) Trajectory Prediction for Robotic Manipulation](https://arxiv.org/abs/2605.25829)

- **ForeAct**：把预训练视频世界模型改造为单次前向的表征骨干（不做未来帧合成与迭代去噪），用可学习 token 做下一帧相对深度监督，训练期用、部署期去掉几何读出；LIBERO 96.6%、SimplerEnv-Bridge 63.5%、90 次真机 74.4%。[ForeAct: Geometry-Guided Action Learning from World Representations](https://arxiv.org/abs/2611.11500)

- **ALAM**：从无动作视频学代数一致的 latent action（组合与可逆一致性正则），冻结编码器后用 latent transition 序列与机器人动作联合 flow-matching 生成；MetaWorld MT50 47.9%→85.0%，LIBERO 94.2%→98.1%。[ALAM: Algebraically Consistent Latent Action Model for Vision-Language-Action Models](https://arxiv.org/abs/2605.10819)

- **ZPRL**：不在动作空间加残差，而是通过紧凑 bottleneck latent 做在线 RL 扰动来“驾驶”预训练策略；8 个仿真任务 + 4 个真机任务，真机平均成功率较模仿基线 +33.7 个百分点，动作更平滑。[Beyond Action Residuals: Real-World Robot Policy Steering via Bottleneck Latent Reinforcement Learning](https://arxiv.org/abs/2605.19919)

- **AnchorQ**：用 flow reversal 把参考行为映射为状态条件 latent anchor，在 anchor 周围采样局部粒子并做价值引导的由粗到细改进；同交互预算下真机成功率 +37%，仿真任务吞吐 +97%。[Sample-Efficient Reinforcement Learning for Policy Improvement via Flow-Reversed Action Anchors](https://arxiv.org/abs/2610.22852)

- **DASH（人形异步解耦）**：System 2（慢 VLM）与 System 1（快 flow-matching 动作头）以 LCM 并发运行，动作头融合过时语义与新鲜视觉 ResNet 特征，配合失同步训练与时序聚合；0.8B–8B 骨干下均保持 20Hz（同步方案从 9.7Hz 降到 4.1Hz），真机灵巧手 pick-and-place 明显更优。[Decoupled Asynchronous System for Humanoids (DASH): Latency-Agnostic Scaling of Vision-Language-Action Models for Humanoid Manipulation](https://arxiv.org/abs/2611.11854)

- **Control-Aware Command Generation**：把“从不连续模型预测生成连续目标位置”当作跟踪控制问题，并用预测位置方差做自适应动作跳帧；在双臂机器人上配合 ACT 与 OpenVLA-OFT 显著提速且保持成功率。[Control-Aware Command Generation for Asynchronous Control and Action Inference with Vision-Based Policies towards Fast Execution](https://arxiv.org/abs/2611.11089)

- **FAFM**：用 DCT 把离散动作块变到频域做 flow matching，再用余弦基重建连续动作，并加一阶时间导数正则（Sobolev 型约束）；对异构控制频率鲁棒，在 LIBERO、LapGym、避障与真机 Franka 上均提升成功率与平滑度。[Frequency-Aware Flow Matching for Continuous and Consistent Robotic Action Generation](https://arxiv.org/abs/2606.20135)

- **VLA-MOPD**：多教师 on-policy 蒸馏整合多个 flow-matching VLA 专家，在学生实际访问的观测与中间 ODE 状态上查询对应教师；LIBERO 平均 75.4%→98.9%，RoboTwin 2.0 73.0%→89.3%，Piper 真机 70.0%→90.0%。[VLA-MOPD: On-Policy Distillation for Multi-Task VLA Policy Consolidation](https://arxiv.org/abs/2611.12286)

- **VLA 样本效率研究**：六个 VLA（π0、π0.5、GR00T N1–N1.7）在四个 LIBERO 套件上变化演示数与训练步数。全量微调下差 2 分的模型在 50 条演示时成功率可差 3 倍；π0.5 比 π0 少需 2–5 倍演示；冻结 VLM 严重损伤 π 系列但几乎不影响 GR00T。[How Many Demonstrations Does a VLA Need? On the Sample Efficiency of VLA Finetuning](https://arxiv.org/abs/2611.09964)

- **ReSkill**：用编码 agent 从指令与技能库构建对象中心任务图，按节点执行记录定位失败，任务级/技能级修订经全任务评估与配对比较后采纳；RoboDojo 十任务平均 30.0%→86.2%，真机 80 次 62 次成功（77.5%）。[ReSkill: Selective Self-Improvement for Robot Manipulation](https://arxiv.org/abs/2611.10510)

- **MoE-DAgger**：用因果 router 历史区分“正常相邻阶段切换”与“真正需要人工纠正”，在阶段化操作中实现选择性人工接管；匹配人工预算下 Green/Red 任务 84.0%/78.0%，比滤波熵基线高 22/26 个百分点。针对 DAgger 选择性数据采集。[MoE-DAgger: Transition-Aware Router-Entropy Gating for Selective Human Correction in Phase-Structured Manipulation](https://arxiv.org/abs/2611.10825)

- **BATCH**（跨本体人类演示）：用循环一致性自监督学时序表征建立人-机对应，再以行为对齐协同训练与人→机风格迁移两个目标训练自回归 video-action diffusion 模型，真机操作对未见任务配置泛化更好。[BATCH: Behavior Alignment for Cross-Embodiment Learning from Humans](https://arxiv.org/abs/2611.10148)

- **UniLatent**：在仿真中渲染成对源/目标机器人观测，把源视觉编码器对齐到冻结目标编码器，共享潜空间缩小本体外观/几何差异；三个仿真任务两个目标臂上零样本最高 93%，真机 xArm→Franka 每任务 10 条演示微调后 27/30 成功。[UniLatent: Cross-Embodiment Transfer via Latent Observation Alignment](https://arxiv.org/abs/2611.10061)

- **Thermo-VLA**：把热像分解为冷/热属性表示，经语言条件残差调制注入 RGB token；双机械臂 Unitree G1 上四个热相关任务平均 0.86，较直接拼接 RGB-热图的 π0.5 高 18 个百分点，未见物体/场景 0.78。该残差调制机制迁移到颜色属性也有一致提升。[Thermo-VLA: A Thermal-Aware Vision-Language-Action Model with Gated Residual Modulation for Robotic Manipulation](https://arxiv.org/abs/2611.11981)

- **Kinora**：面向 text-to-motion → 机器人重定向 → 交互验证的版本化工作流，52 关节作者骨架 + 过程化预览，人动编辑保留区间外帧，机器人编辑生成不可变候选并以其报告决定接受/导出。[Kinora: A Versioned Workflow for Text-to-Motion Generation, Robot Retargeting, and Interactive Validation](https://arxiv.org/abs/2611.11601)

- **GMD-Mamba / TinyUNet3D**（医学分割，非操作，仅一笔带过）：分组多方向 Mamba 轻量 3D 分割；以及把 139M SegMamba-V2 蒸馏到约 0.96M TinyUNet3D。[GMD-Mamba: Lightweight 3D Medical Image Segmentation Using a Grouped Multi-Directional Mamba](https://arxiv.org/abs/2611.10032) / [Ultra-Lightweight 3D Medical Image Segmentation via Knowledge Distillation in Label-Scarce Domains](https://arxiv.org/abs/2611.10033)

## 四、人形/全身控制、遥操作与模仿学习

- **DASH 人形 VLA**（见上节）：并发慢 VLM + 快动作头，解除骨干规模对控制频率的耦合。

- **DreamVLA**：用生成的人体运动轨迹引导仿真 RL 专家，再以“参考条件化 DAgger”蒸馏成 VLA，无需新任务遥操作数据；评估取物、开抽屉、按按钮、行走取物等任务。[DreamVLA: From Generated Human Motions to Humanoid Vision-Language-Action Policies](https://arxiv.org/abs/2611.10872)

- **Kimodo-Policy / KAM**：把全身运动作为直接预训练目标，冻结 Kimodo text-to-motion 骨干 + ControlNet 视觉条件，root-body-hand 分层协调；HumanoidArena 72.14%，SIMPLE 有竞争力，8 个真机任务平均 60%。[Kimodo-Policy: Learning Kinematic Action Models for Humanoid Loco-Manipulation](https://arxiv.org/abs/2611.11554)

- **LHNav**：长程多目的地人形导航，按时间尺度分 Brain（任务推理）/Cerebellum（VLA motion token）/Brainstem（全身控制）三角色异步协同，并用物理落地数据引擎生成沿碰撞感知路径的运动参考；单目标演示训练的 VLA 在长程任务上 75.56%，Unitree G1 上完成零样本长程执行。[LHNav: Long-Horizon Humanoid Navigation via Multirate Coordination and Physics-Grounded Action Data](https://arxiv.org/abs/2611.12136)

- **Retargeting-free 全身遥操作**：单次前向把原始人体运动映射为机器人关节指令，用全身运动基元码本把 OOD 观测投影到合理基元并从部分输入恢复全身运动；VR、光学动捕、text-to-motion、单目视频多输入下时延与鲁棒性均优于基线（Unitree G1）。[Beyond Retargeting: Low-Latency and Robust Humanoid Whole-Body Teleoperation with Learned Atomic Motion Primitives](https://arxiv.org/abs/2610.07891)

- **HuMI**：无本体（humanoid-free）全身数据采集，用便携硬件捕捉丰富人体运动，再经分层学习管线转成灵巧可行的人形技能；跪、蹲、抛、走、双臂操作五类任务，采集效率为遥操作 3 倍，未见环境成功率 70%。[HuMI: Humanoid Whole-Body Manipulation from Humanoid-Free Demonstrations](https://arxiv.org/abs/2602.06643)

- **LessMimic**：推理期不需要运动参考输入，只由 root 命令 + 交互类型标志驱动，并以距离场表面距离/局部方向短历史作为交互表征；物体尺度 0.4×–1.6× 下 PickUp/SitStand/Push/Carry 稳定，五任务序列 62.1%、15 任务 23.5%。[LessMimic: Versatile Humanoid-Object Interaction with Unified Distance Field Representations](https://arxiv.org/abs/2602.21723)

- **Festival Video to the Stage**：把阿波舞从单目视频迁移到 Unitree G1 的商业人形 sim-to-real 流水线（人体网格恢复→运动重定向→仿真 RL 跟踪→ONNX 上机），含 11 版上机阶梯与静默制品损坏、状态估计漂移等问题的排查。[From Festival Video to the Stage: A Sim-to-Real Ladder for Long-Horizon Expressive Whole-Body Dance on a Commercial Humanoid](https://arxiv.org/abs/2611.11127)

- **Muscle-Aware Retargeting + Null-Space Exploration**：两阶段利用肌肉冗余——先做带硬语义/解剖/接触约束的有界运动重定向，再在肌肉激励到广义力的零空间做有界扰动注入 value-guided flow policy；24 段动捕基准全部解出，样本减半，关节中心误差降 44%。[Burden, Bounty, or Bliss? Muscle-Aware Retargeting and Null-Space Exploration for Whole-Body Musculoskeletal Control](https://arxiv.org/abs/2611.10682)

- **RoboMoCap**：14 名被试、200+ 小时、6 路头戴相机 + 腕部视觉惯性 + 120Hz 光学全身动捕的大规模自我中心全身动捕数据集，系统覆盖变速行走、转弯、受限导航、地形穿越、负重搬运与行走中操作。[RoboMoCap: A Large-Scale Whole-Body Motion Capture Dataset with Egocentric Vision for Robot Learning](https://arxiv.org/abs/2611.10994)

- **Unified Inertial Encoder**：用运动学 IMU 合成把人与对应人形在共同惯性接口上表示，联合训练速度估计与运动-文本对齐；零样本迁移到 Unitree G1（无物理仿真、无真机微调）在五个数据集速度误差最低（G1 上 0.099m/s）。[A Unified Inertial Encoder for Human and Humanoid Motion](https://arxiv.org/abs/2611.10137)

- **AetheRock/ForceVT**（见触觉节）：臂戴式力-视觉-触觉示教。

## 五、操作任务的 sim-to-real 与世界模型

- **MolmoBot**：质疑“仅仿真不够”的共识，用 MolmoBot-Engine 过程化生成 170 万条专家轨迹训练三类策略；不做任何真机微调，桌面 pick-and-place 在 4 个设置下 79.2%，对比 π0.5 的 39.2%，并在移动操作（开门、抽屉、柜体、移动抓放）上零样本迁移。[MolmoB0T: Large-Scale Simulation Enables Zero-Shot Manipulation](https://arxiv.org/abs/2603.16861)

- **ObjectWorld**：提出“3D 全物体流”（含遮挡区域的稠密 3D 轨迹），发布 1210 小时全物体流数据集与可扩展标注流水线，训练以图像+任务描述为输入的世界模型，支持跨新场景与新本体的下游操作。[ObjectWorld: Scaling Object-Centric World Models with A Large-Scale 3D Full-Object Flow Dataset](https://arxiv.org/abs/2611.11085)

- **DreamTrue**：多视角、跨本体机器人世界模型，把动作轨迹渲染为图像空间条件并用离线几何标定对齐；反事实后训练扩展失败交互覆盖，人类标注视频缺陷集训奖励模型做 RL 后训练，交互缺陷率 48.12%→6.25%。[DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training](https://arxiv.org/abs/2610.12468)

- **SmolWAM**：边缘端紧凑 latent world-action model（2B Cosmos Policy 蒸馏，12/28 层、1008 token、单步 rectified flow），LIBERO 400 集 95.5%，A100 上 57ms/2.3TFLOP/2.4GiB，较五步教师延迟降 11×、内存降 3.2×。[SmolWAM: A Latent World-Action Model for Robotic Manipulation on Edge Devices](https://arxiv.org/abs/2610.13740)

- **Library of Hands**：不重训世界模型，只校正“指令→实际动作”的映射（hand），用冻结模型通过两帧图像读出 hand 并存库；闭环下三个仿真任务 28.6%→62.3%，无变化场景仅损失 0.6 个百分点，另两个世界模型同样适用。[Library of Hands: Fix the Hands, Not the World Model](https://arxiv.org/abs/2611.12678)

- **World In-Context Learning / RoboScript**：冻结模型从单条演示出发，在仿真中“排练”任务并把反馈写进 context 而非权重，冻结为 Task Memory 后部署；RoboTwin 2.0 全部 50 任务 clean/random 平均 83.4%（每任务一条演示、零梯度），比最强训练型策略高 20+ 分，并经跨本体记忆适配迁移到真机双臂。[World In-Context Learning for Agentic Robot Manipulation](https://arxiv.org/abs/2611.12885)

- **SyncTwin**：VGGT 离线重建物体级 3D 资产库 + 在线 real-to-sim 同步（跟踪物体状态、补全部分观测几何），在仿真中做碰撞感知规划再回真机执行，针对动态与遮挡场景提升操作成功率与运动安全性。[SyncTwin: Fast Digital Twin Construction and Synchronization for Safe Robotic Manipulation](https://arxiv.org/abs/2601.09920)

- **SoftPAT3D**：面向可变形体的文本到 3D 场景生成，用制造方式而非生成出的错误形变确定静止形状，赋予材质库初值并优化，遮挡支撑面重建为水密碰撞网格，在统一接触模型下驱动整场景到静平衡；65 个 prompt 均无不良互穿，场景可直接支持编辑与机器人操作。[SoftPAT3D: Physics-Augmented Text-to-3D Scene Generation with Deformables](https://arxiv.org/abs/2611.11087)

- **FlowPilot**：首个面向实时机载无人机导航的 world-action model，flow matching 同时去噪未来深度与可执行轨迹，双流 MoT 共享注意力；Jetson Orin NX 上平均 10.2ms，室外仅用机载感知达到 10m/s。属具身 sim-to-real 但非操作，简记。[FlowPilot: Real-Time World-Action Modeling for Agile UAV Navigation](https://arxiv.org/abs/2608.00635)

## 六、强化学习/扩散策略改进与规划控制（操作相关）

- **Dynamics-Informed Action Learning (DIAL)**：训练时 rollout alignment 让前向模型见自己的自回归 latent，多步逆动力学监督训轻量逆头，推理时用逆-前向自回归耦合生成 dynamics-informed 动作序列来初始化 CEM 均值；四个视觉控制基准（含长程）优于现有 latent world model 与规划基线。[Dynamics-Informed Action Learning for Goal-Conditioned Latent Planning](https://arxiv.org/abs/2611.10660)

- **Streaming Failure Forecasting**：VLA 失败监控器在部署后持续学习——冻结离线网络、每回合后只重拟合最后一层线性读出（Jetson CPU 核 2.18ms/次），阈值仅在成功后移动；5 个仿真测试套件中 4 个优于冻结监控，真实 SO-101 434 条回放中每个 VLA 均更优。[Streaming Failure Forecasting: VLA Failure Monitors That Keep Learning After Deployment](https://arxiv.org/abs/2611.11688)

- **MIND**：用稀疏自编码器把 VLA 策略内部激活分解为可解释特征，并把这些特征与机器人位置/运动/环境关联、通过激活引导检验因果影响；从成功/失败执行中学习特征演化模式，在执行中检测偏离并给出诊断。[Detecting and Explaining Robot Policy Failures from Sparse Internal Features](https://arxiv.org/abs/2611.10400)

- **Test-time search for ACT**：在 PushT 上对冻结 ACT 做 action chunk 的 beam search（克隆仿真状态 rollout 打分），成功率 0%→18%，平均累积奖励 39.44→103.2；并提出 One Step Ahead 门控，只在预测覆盖下降超阈值时触发完整搜索，运行时约降 3×。[Look Ahead: Search-Driven Reasoning in Embodied AI](https://arxiv.org/abs/2611.10769)

- **SMC-as-MPC**：证明 predictive sampling、MPPI、CEM 及其有偏/有色噪声/退火变体都是同一 SMC 推断算法的特例，由 proposal、更新规则、重采样阈值三个独立轴确定；长视野导航中重采样使碰撞率降 30%，push-T 从 1%→100%（仿真）、10%→90%（Franka FR3 真机）。[Sampling-based Model Predictive Control as Sequential Monte Carlo Inference](https://arxiv.org/abs/2611.10877)

- **PAIR / OASIS / AnchorQ** 等已在上文，不再重复。

- **BECON**：把约束偏好条件 MORL 视为部分可观测任务规格问题，用近期历史推断 latent 任务上下文（偏好与安全预算），经不确定性门控与暴露信号融合；在多目标控制任务上对任务漂移更鲁棒、约束满足更好。[BECON: Belief-Conditioned Constrained Multi-Objective Reinforcement Learning under Drifting Preferences and Budgets](https://arxiv.org/abs/2611.12053)

- **TrajLift**（非操作，仅一笔带过）：以延迟调制热扩散在语义层级上建模语言回忆轨迹，用于阿尔茨海默病诊断。[TrajLift: Lifting Memory Recall Trajectories with Latency-Modulated Heat Diffusion](https://arxiv.org/abs/2611.12197)

## 七、机器人基准与评测（操作/具身相关）

- **HARP-Bench**：把“共享工作空间中主动活动的人”作为操作问题的一部分，设 Cueing / Contribution / Interruption / Co-presence 四种条件，提供动态人-在环演示生成管线；评估 VLA、模仿学习与启发式策略，发现人-在场变体普遍困难，且任务成功率提高并不一致带来更安全行为，失败主因是操作与恢复。[HARP-Bench: Benchmarking Robot Manipulation Around Active Humans](https://arxiv.org/abs/2611.11123)

- **GeoMind**：54 个任务变体、围绕空间推理与空间记忆的桌面操作基准，并有可扩展的自动生成与标注流水线；发现具身 agent 普遍难以在空间变化后保持身份追踪、也难把关系/几何约束转成可执行动作。[GeoMind: A Benchmark for Spatial Understanding in Robotic Manipulation](https://arxiv.org/abs/2611.12175)

- **Embodied First Exam**：面向 coding agent 控制机器人的统一 agent-native 评测，1156 任务/35 套件/47 种机器人，含空间拼图、灵巧操作、多机器人交互、动态全身控制与 sim-to-sim；最强 agent 在 456 个核心任务 Standard 设定下仅 34%。[Embodied First Exam](https://arxiv.org/abs/2611.12177)

- **Stochastic Challenges**：提出“随机挑战”范式做真机操作基准——基于可复现真实场景、从同一分布随机采样任务，用成功率比较不同实验室的不同机器人；在一个移动操作基准上比较了两台机器人在两个实验室的结果。[Benchmarking Real-World Robotic Manipulation through Stochastic Challenges](https://arxiv.org/abs/2611.12804)

- **AgentRobustBench**：从工具使用 POMDP 的观测/动作/奖励元数据/转移动力学四类组件出发，构造 22 类扰动（每类有 GitHub issue 或文档失败依据）；观测扰动掉点 <5%，而奖励相关与转移扰动分别掉约 40% 与 30%，规模扩大不能弥合。并给 ToolRL-DR 域随机化 RL 配方，3B 骨干达到接近开源 14B 函数调用基线的扰动后精度。[AgentRobustBench: A Sim-to-Real Benchmark and Domain-Randomized RL Recipe for Tool-Use Agents](https://arxiv.org/abs/2611.12177)（注：与上一条不同，本条目链接为 https://arxiv.org/abs/2605.11928 的对应版本）

- **DeliverBench**：11 个真实多阶段专业项目（含财务尽调、合同起草、药物安全报告）、150 子任务、每项目 2–15 次新材料/客户反馈增量；子任务依赖 agent 自己先前的交付物，评测最终交付包与各子任务 rubric。最强系统最终交付 65.0/100，子任务 90 分阈值通过率 50.0%。[DeliverBench: Benchmarking AI Agents on Delivering Realistic Multi-Stage Professional Projects](https://arxiv.org/abs/2611.03412)

- **SpreadsheetBench 2**：321 个工作流级电子表格任务（生成/调试/可视化），平均 11.8 个工作表、593.5 次单元格修改、跨表依赖；八个前沿 LLM 在统一多轮 agent scaffold 下最高整体准确率 34.89%，调试准确率低至 12.00%。[SpreadsheetBench 2: Evaluating Agents on End-to-End Business Spreadsheet Workflows](https://arxiv.org/abs/2606.29955)

- **RoboWits**（双机械臂认知推理基准）与 **ACT / 其他 agent 基准**：多为一笔带过类。其中 RoboWits 值得注意：30 个种子任务 + 200 个变异任务，微调后的 VLA 在变异任务上明显脆弱，GPT-6 Astra 零样本策略优于所有微调 VLA 但在变异任务上仍损失约 1/5。[RoboWits: Unexpected Challenges for Robotic Creative Problem Solving](https://arxiv.org/abs
