## 一、VLA 模型与后训练 / 强化学习

- **[Agentic-Teacher: An Agentic Data Engine for Failure-Driven VLA Post-Training](https://arxiv.org/abs/2611.17394)**：用编码智能体分析 VLA 失败 rollout、生成闭环代码策略作为示范生成器，配合时序动作噪声与流匹配损失筛选数据；LIBERO-10 从 79.4%→87.8%，RoboCasa 三个任务从 0%→30%。
- **[ESI: An Embodied Self-Improvement Flywheel for LLM-VLA Agents](https://arxiv.org/abs/2611.18176)**：LLM 负责子任务语义监督、VLA 负责执行，用环境交互自动迭代 prompt、技能接口与 VLA 参数；RoboDojo 十任务平均成功率 49.41%，超过 GO-3 Nano Preview。
- **[Training Reasoning Models in Simulation to Natively Use Real Robots](https://arxiv.org/abs/2611.18562)**：27B 开源推理模型在仿真中做 robot-use RL（PEAR/RURL），无需示范；LIBERO 1.6%→74.4%，真机双臂 60% 成功，LIBERO-Pro 上远超 π0.5（57.4% vs 0.75%）。
- **[D-VLA: A High-Concurrency Distributed Asynchronous Reinforcement Learning Framework for VLA Models](https://arxiv.org/abs/2605.13276)**：面向十亿级 VLA 的分布式异步 RL 框架，平面解耦 + 四线程流水线 + 双池显存管理，LIBERO 上吞吐与采样效率显著优于主流 RL 框架。
- **[E0: Expressive Fine-Grained Discrete Action Prediction for VLA Models via Tweedie Discrete Diffusion](https://arxiv.org/abs/2511.21542)**：把动作生成建模为量化动作 token 上的 Tweedie 离散扩散；LIBERO、VLABench、ManiSkill 与真实 Franka 上平均领先 8.1%。
- **[Vision-Language-Action Models: A Life-Cycle Survey of Design, Training and Deployment](https://arxiv.org/abs/2611.18372)**：综述 88 篇 VLA 工作，按输入/架构/动作输出/中间预测/预训练数据/后训练/实时执行七轴分析 22 个模型，并指出 benchmark 高分模型在物体或相机轻微移动时失效。
- **[Recursive Belief Vision Language Action Models](https://arxiv.org/abs/2602.20659)**：用自监督世界模型维护紧凑信念状态，VLM 每任务只查询一次；长程抓放/堆叠成功率比 π0 高 52.5%/37.5%，推理延迟降低至多 5 倍。
- **[FlashRT-PAI: Fast Kernels Are Not Fast Pipelines for Physical AI](https://arxiv.org/abs/2610.24349)**：面向 VLA/VA/WAM 的低延迟推理引擎，深度核融合 + 执行契约 + 状态胶囊；官方编译路径 1.3–3.7 倍加速，4-bit π0.5 在 LIBERO-10 达 94.04%。

## 二、灵巧手 / 手中操作 / 触觉感知

- **[TouchTwin: Scaling Human Touch Data via Real-to-Sim-to-Real](https://arxiv.org/abs/2611.17619)**：指出 vision-tracked 手部姿态存在“力差”——视觉只恢复手指停在哪，不恢复按多紧；用 880-taxel 手套记录真实触觉并回放于 MuJoCo，策略抓握力达记录值 0.99x，20/20 成功，未见扰动 35/36。
- **[The Missing Touch: Sensing and Displaying Localized Contact Geometry Brings Teleoperation Closer to Human Dexterity](https://arxiv.org/abs/2608.19372)**：给双向力反馈遥操作加视觉触觉传感器 + 32 像素触觉显示器，回放空间接触图案；按钮辨别与滚桩任务中动作更少、耗时更短，且触觉增强示范训练出的策略同样受益。
- **[VOKE: Visual Object Kinematics Estimator for Dexterous In-Hand Manipulation](https://arxiv.org/abs/2611.16423)**：在现有位姿估计器上接可插拔运动学模块，输出物体位姿、线/角速度与加速度，并用运动先验精化位姿；DexYCB、OakInk 上提升位姿精度，运动学增强策略可零微调迁移到真机。
- **[IORA: Irregular Object Immobilization under Restricted Actuation](https://arxiv.org/abs/2610.30969)**：面向低自由度耦合手的支撑面感知抓取合成，把手与物体局部表面建图做运动学可行匹配并物理验证；可生成高成功率、抗扰动的固定构型，并在烹饪场景真机验证。

## 三、遥操作与人机交互

- **[HEIR: Harness Egocentric Intent for Human-Robot Interactions](https://arxiv.org/abs/2611.17238)**：配对人类语音、注视、自我中心视频与机器人观测及遥操作导航-操作轨迹，支持意图 grounding、执行规划与任务完成研究，并做真机实验。
- **[Toward Resilient Self-Driving Laboratories through Telerobotic Interventions](https://arxiv.org/abs/2611.18496)**：为自主实验室故障恢复设计 6-DoF 机械臂遥操作接口（3D 鼠标，耦合/解耦两种速度控制）；解耦模式完成更快、旋转动作更少，参考路径引导会改变操作者风险偏好。
- **[A$^3$: Adaptive Audio Agent Framework for Collaborative Edge Computing](https://arxiv.org/abs/2611.18064)**：边缘音频智能体的链路感知降级框架（与机器人遥操作间接相关，简述）。

## 四、Sim-to-Real 与仿真基准

- **[Heavy Metal Acrobatics: Learning Dynamic Control for Skid-Steer Loaders](https://arxiv.org/abs/2611.18365)**：在 5 吨 John Deere 332G 滑移装载机上做仿真 RL + sim-to-real，实现两轮平衡、越野行驶、轨迹跟踪、旋转与铲斗摆动等此前仅少数世界纪录级操作员完成的特技（Science Robotics）。
- **[Geometric Refinement and Distributional Alignment for Sim2Real Roadside LiDAR Detection](https://arxiv.org/abs/2611.03936)** 与 **[Coordinate Frame Recovery, Per Class NMS and Null Return Modelling for Sim2Real V2X LiDAR Detection](https://arxiv.org/abs/2611.03940)**：UrbanTwin Sim2Real LiDAR 挑战赛方案，分别针对路侧与 V2X 场景，强调坐标系统恢复、逐类 NMS、零返回点建模等诊断性改进。
- **[Model-Free Assessment of Simulator Fidelity via Quantile Curves](https://arxiv.org/abs/2512.05024)**：用分位数曲线在分布层面量化 sim-to-real 差距，模型无关、支持一般输出空间，并在 WorldValueBench 上评估四个 LLM 与人类分布的对齐。
- **[PoliMop: Policy-in-the-Loop Motion Planning in 3D Spaces for Mobile Robots](https://arxiv.org/abs/2611.18110)**：运动学 RRT 用物理仿真展开策略 rollout，以策略能力评估可达性；预规划质量点路径引导采样，规划时间最多降低 63%，支持四足、人形与轮式机器人即插即用。
- **[PROOF: Perceptive Robustness via Out-of-Distribution Fallback for Legged Locomotion](https://arxiv.org/abs/2611.18305)**：教师-学生两阶段学习，学生在 OOD 视觉输入下预测外感受特征不确定性并抑制；Unitree Go2 在严重遮挡与强光照变化下仍稳定跑酷。

## 五、操作策略学习、接触丰富任务与视觉表征

- **[On the Utility of Pre-Trained Visual Representations for Policy Learning of Contact-Rich Insertion Tasks](https://arxiv.org/abs/2611.17631)**：在两个高度相似的插入任务上比较视觉基础模型表征与接触中心表征，发现最佳表征甚至在不同任务间就会翻转，但空间 grounded 尤其接触信息始终有价值。
- **[When Does Cross-View Consistency Matter in Multi-View Appearance Augmentation? A Controlled Study for Visuomotor Policies](https://arxiv.org/abs/2611.17751)**：用仿真状态回放解耦跨视角耦合，发现外观一致性约束可放松，而任务相关几何与跨视角空间对应必须保护（几何反耦合降低成功率 3.30 个百分点）。
- **[Objectives as Policies: Vision-Language Model Cost Programs for Contact-Rich Manipulation](https://arxiv.org/abs/2611.18298)**：VLM 生成可编辑的目标程序（阶段序列 + 成本库 + 完成条件），经 real-to-sim 数字孪生由采样 MPC 执行并迭代更新；四个桌面接触丰富任务优于强基线。
- **[Imitation Policies Learn a Proprioceptive Anchor: A Predictive Law for Perception Noise and Its Closed Loop Cost](https://arxiv.org/abs/2611.17658)**：证明模仿策略会把本体状态当作“锚”来折减噪声读数，权重 α=V/(V+s²)，V 可由一次测量预测十个留出敏感度（MAE 0.025 vs 经典 EIV 0.37）。
- **[Fast Non-Parametric Heteroscedastic Imitation Learning With Geometric Priors](https://arxiv.org/abs/2610.08650)**：流形感知的非参数概率策略学习，支持流形输入/输出与大姿态变化，位置+姿态轨迹更新 <3 ms，用于自主执行与共享控制。
- **[Grounding Object-to-Object Hazard Reasoning into 3D Risk Fields for Task-Conditioned Safety](https://arxiv.org/abs/2611.17566)**：VLM 判断任务是否应拒绝，并识别可预防的物体对危险与需避免的空间关系，经开放词汇分割与深度构建 3D 风险场，接入避障模块修正标称运动。

## 六、导航、世界模型与规划

- **[Learning Latent Goal Costs for Visual World-Model Planning with an Expanding Curriculum](https://arxiv.org/abs/2611.17529)**：在冻结 I-JEPA 嵌入上拟合小型残差适配器改进潜空间目标代价，配合由近及远的课程；DotWall 54%→98%，PointMaze 82%→96%。
- **[Racing the Clock: Teaching VLNs Budget-Conditioned Object Search](https://arxiv.org/abs/2611.17442)**：研究预算条件下的目标搜索，发现部分可观测下的 Bellman 专家示范比全局最优 TSP 专家更利于学习探索；2000 步时找到 71.4% 可达目标实例。
- **[ERA: Error-Resistant Autonomous Object Navigation with Predicted Depth](https://arxiv.org/abs/2611.17730)**：无深度传感器、用 RGB 预测深度做零样本物体导航，提出“带误差移动”范式（可修正占据图 + 可达视点探索 + 跨视角验证）；将 VLFM 成功率从 10.8% 提升到 61.7%，并真机部署。
- **[X-Nav Technical Report: Real-World Long-Horizon Indoor-to-Outdoor Navigation on a Humanoid Robot](https://arxiv.org/abs/2611.17598)**：首个双足人形室内到室外语言指令长程导航系统，仅用机载 RGB；在 Lingxi X2 上完成约百米任务，并用数字孪生数据做部署期适配。
- **[Evaluating Language Models as Spatial Priors for Object-Goal Navigation](https://arxiv.org/abs/2611.18123)**：评估两个开源 LLM 能否提供房间内目标位置先验；结论是可用于物体-房间关联与受约束坐标生成，但不能替代真实布局先验做放置分布。
- **[VLAN: Vision-Language Accessible Navigation](https://arxiv.org/abs/2611.18346)**：1000 场景、2 万轨迹的无障碍导航基准，按人形/四足/视障/行动障碍等具身提供不同动作与可通行标签；现有 VLM 难以跨用户画像一致调整障碍相关性与安全标准。

## 七、多机器人协作与操作任务规划

- **[Robots that Collaborate: Sequential Asymmetric Imitation for Learning Coupled Robot Policies](https://arxiv.org/abs/2606.16490)**：单遥操作者课程学习双移动操作臂耦合行为：A 先与顺从人类示范学习，B 对已部署 A 学习，再用稀疏干预精化 A；真实任务中提升成功率、相位同步与让行行为。
- **[When Will You Hand It Over? A Hidden Start Delay Makes Self-Play Handover Robust to Unfamiliar Partners](https://arxiv.org/abs/2611.18491)**：发现自博弈交接策略对陌生伙伴脆弱（95%→31%），根因是学习到单一 rendezvous；加入隐藏起始延迟随机化后，陌生脚本伙伴成功率 31%→80%，高力接触减少 3–5 倍。
- **[PingpongDuo: Agile Humanoid Table Tennis Doubles with Safe Team Coordination](https://arxiv.org/abs/2610.20579)**：人形乒乓球双打的分层框架：团队层联合选位并用学习风险估计过滤危险方案，个体层分开训练步法与击球；仿真回球成功率 +13.2%，真机两机器人严格交替连续对打 10+ 拍。
- **[Courteous Anticipation: Improving Long-Lived Task Planning in Persistent Shared Environments](https://arxiv.org/abs/2607.20289)**：共享持久环境中，用各机器人独立学习的未来成本估计联合最小化即时与期望未来成本；两机器人家庭环境总成本比短视规划低 10.4%，三机器人餐厅低 20.5%。
- **[EmbodiExp: Compositional Experience Transfer for Embodied Agents](https://arxiv.org/abs/2610.39180)**：把过去任务的经验组织为“结果 grounded”的子目标经验并在线组合；EB-Habitat 68.0%、EB-ALFRED 68.3%，显著高于无经验智能体。

## 八、其他相关（简略）
