### 一、视觉-语言-动作（VLA）模型与泛化

- **TipDex-VTLA**：结合视觉动作可靠性与触觉预测验证，在光照变化下自适应精修灵巧操作动作。[TipDex-VTLA](https://arxiv.org/abs/2611.25683)
- **A²-VLA**：通过智能体式可供性发现，让 VLA 策略适应新工具，真实机器人工具使用任务成功率提升 30.7 个百分点。[A²-VLA](https://arxiv.org/abs/2611.25656)
- **OVOA-VLA**：将动作监督对齐到各视角相机坐标系，提升空间泛化，LIBERO-Plus 达 88.1%。[One View, One Action](https://arxiv.org/abs/2611.26161)
- **TacInno**：分离视觉与动作无法解释的"触觉创新"作为训练目标，六个仿真任务平均 87.5%。[TacInno](https://arxiv.org/abs/2611.26405)
- **Verify2Act**：VLM 提议计划 + 潜在世界模型在 DINOv2 空间想象 + 双头评论家验证，六任务 83.3% 成功。[Verify2Act](https://arxiv.org/abs/2611.25243)
- **CauSyncVLA**：异步双系统控制，因果潜在世界模型预测当前感知记忆，LIBERO-10 达 93.8%、5.04× 吞吐。[CauSyncVLA](https://arxiv.org/abs/2611.25667)
- **RefreshGrad**：在线自适应数据采样，按五种策略原生信号动态调整时间窗口权重，LIBERO-Plus 提升至 76.1%/81.3%。[RefreshGrad](https://arxiv.org/abs/2611.25398)
- **Dune**：零阶优化器，用时间条件历史误差回归稳定 VLA 测试时自适应，低内存下提升成功率。[Dune](https://arxiv.org/abs/2611.25400)
- **Hindsight Self-Distillation**：用后续帧教策略从当前帧提取信息，LIBERO 98.50%、RoboTwin 2.0 92.31%。[HSD](https://arxiv.org/abs/2611.25777)
- **Homeward**：免训练观察适配器，将未标定部署相机观测规范化回训练视角，LIBERO-Plus 大幅提升。[Homeward](https://arxiv.org/abs/2611.24455)
- **UniVEP**：统一速度与端点预测，按噪声水平切换端点恢复与速度精修，RoboTwin 单次 61.36%。[UniVEP](https://arxiv.org/abs/2611.26103)
- **PhysVAM**：以未来任务价值预测引导动作生成，仿真与真实任务分别提升 27.0/27.5 个百分点。[PhysVAM](https://arxiv.org/abs/2611.26105)
- **Flatness Preserves Instruction Following**：用锐度感知最小化（SAM）微调，指令跟随提升超 55%。[Flatness](https://arxiv.org/abs/2606.23641)
- **SimVLA**：受控消融研究，表明训练动态是最大影响因素（Δ≈54–94%），极简基线 LIBERO 达 98.6%。[SimVLA](https://arxiv.org/abs/2602.18224)
- **VLA 生命周期综述**：综述 89 篇工作，提出七条设计轴，覆盖设计、训练与部署。[VLA Survey](https://arxiv.org/abs/2611.18372)
- **Flow-Based VLA 注意力分析**：检验"径向动作汇"假说，发现端点 token 并不符合汇特征，前缀 BOS 才是真汇。[Radial Attention](https://arxiv.org/abs/2611.26385)
- **RAVEL**：滚动异步推理，动作专家连续运行 + 快速观察通路，降低响应延迟。[RAVEL](https://arxiv.org/abs/2609.34170)
- **FastRoverVLA**：越野自动驾驶 VLA，解耦视觉计划生成与运动条件执行，FDE 降低 18.0%/36.7%。[FastRoverVLA](https://arxiv.org/abs/2611.26242)
- **DMT-Attack**：用扩散先验搜索自然外观纹理攻击 VLA，宏平均攻击成功率 57.9%。[DMT-Attack](https://arxiv.org/abs/2611.25695)
- **ThinkWAM / CoT-WAM / WEVO**：世界动作模型与 VLA 结合方向，分别关注动作精修、VLM-WAM 协同训练与人形全身 loco-manipulation。[ThinkWAM](https://arxiv.org/abs/2611.21258)｜[CoT-WAM](https://arxiv.org/abs/2611.23803)｜[WEVO](https://arxiv.org/abs/2611.25251)

### 四、世界模型与规划

- **MAWAM**：多智能体世界-动作模型，联合生成各机器人未来视图与动作块，真实三任务平均 67.8%，仿真四臂 90.3%。[MAWAM](https://arxiv.org/abs/2611.25105)
- **GEMS**：生成时间结构子目标 + 潜在经验记忆，Cube 92.8%、Push-T 68.4%、Meta-World 54.1%。[GEMS](https://arxiv.org/abs/2611.25134)
- **MoRE**：混合运动专家（刚体/可变形/抓取）3D 世界模型，结合 MPC 提升真实操作。[MoRE](https://arxiv.org/abs/2611.25336)
- **Fast-JEPA**：重构预测计算，直接预测完整候选结果，96.50% 平均成功率、2.41× 加速。[Fast-JEPA](https://arxiv.org/abs/2611.25927)
- **PILOT**：视频模型生成子目标 + VLA 策略初始化 CEM，真实 UR5e 四任务 68.8%。[PILOT](https://arxiv.org/abs/2610.14335)
- **LeCompass**：基于冻结 LeWorldModel 的状态索引执行框架，Cube 86.9% 原生 4cm 到达。[LeCompass](https://arxiv.org/abs/2611.25679)
- **AFFECT**：动作效应匹配辅助目标，使世界模型对动作扰动的视觉变化更忠实，DROID 上策略成功率与真实相关性从 0.47 升至 0.79。[AFFECT](https://arxiv.org/abs/2611.25980)
- **Unstick**：诊断 JEPA 规划器"停滞"失败（≥96%），用残差记忆或随机重初始化打破规划不动点。[Unstick](https://arxiv.org/abs/2611.25415)
- **LATER**：动作条件时序证据检索，受工作记忆启发，Two-Stage PushT 终端成功率 15.5%→25.0%。[LATER](https://arxiv.org/abs/2611.25671)
- **SemRole**：以语义角色（任务条件结构）表征场景演化，LIBERO 45.5%→83.0%。[SemRole](https://arxiv.org/abs/2608.22294)
- **LAQ**：面向世界动作模型的潜在感知 4-bit 量化，LIBERO-Plus 76.4%/83.3%，压缩 3.8×、加速 1.66×。[LAQ](https://arxiv.org/abs/2611.25614)
- **SteerTrace**：针对 WAM 的定向通用攻击，并追踪其在模型内部的作用路径（未来 token、当前帧 token、FFN 神经元）。[SteerTrace](https://arxiv.org/abs/2611.25719)
- **LoopedWAM / WAMotor**：循环权重共享与推测推理加速 WAM。[LoopedWAM](https://arxiv.org/abs/2611.25595)｜[WAMotor](https://arxiv.org/abs/2611.25413)
- **World Models Favor Learned Priors**：TailWorld 基准 + RIFT，揭示世界模型偏好学习先验而非视觉证据。[RIFT](https://arxiv.org/abs/2611.26366)

### 五、人形机器人与全身控制

- **Awaken-HI**：约 5 万小时第一人称立体视频 + 同步全身人体运动，共享动作专家同时预测人体运动与重定向机器人动作，八任务平均 93.75%。[Awaken-HI](https://arxiv.org/abs/2611.26420)
- **SuperMimic**：单一可微世界模型摊销全身运动跟踪学习，单 GPU 3 小时超越 128 GPU 7 天基线，GPU 时减少 >1000×。[SuperMimic](https://arxiv.org/abs/2610.28480)
- **ECHO**：上下文行为基础模型，混合退火采样 + 上下文表征与残差适配，Unitree G1 上实现极端杂技与地形交互遥操作。[ECHO](https://arxiv.org/abs/2611.25778)
- **PGX**：长时程人形 loco-manipulation，谓词状态机 + VLA 技能 + 世界坐标锁定，Unitree G1 验证。[PGX](https://arxiv.org/abs/2611.26596)
- **RoboForge**：跨空间运动精修，质量引导扩散修复人体运动 + 运动学/动力学修复，BeyondMimic 成功率 89.51%→96.20%。[RoboForge](https://arxiv.org/abs/2603.17927)
- **LocoMuJoCo**：全身控制模仿学习基准，9 人形/3 骨骼肌/4 四足，MuJoCo+MJX+MjWarp 统一 API。[LocoMuJoCo](https://arxiv.org/abs/2611.26293)
- **人形滑板**：无参考终止塑形强化学习，让 K1 人形学习滑板。[Skateboarding](https://arxiv.org/abs/2611.26054)
- **FAB**：快速准确人体估计，联合预测骨架关节与稠密表面点，含人→人形重定向器 FAB-Retarget。[FAB](https://arxiv.org/abs/2611.25801)

**总体观察**：今日论文中，VLA 的效率与泛化（异步推理、量化、测试时自适应、视角鲁棒）非常密集；世界模型作为规划器与策略改进环境（WAM/JEPA）成为主流范式；触觉方面强调"视觉/动作无法解释的接触动力学"作为监督信号；灵巧操作基准开始显式控制源-目标任务相关性以区分迁移与记忆；人形全身控制借助可微世界模型与大规模人体数据显著降低算力门槛。
