# 今日 arXiv 机器人学与人工智能精选论文总结

## 具身智能与 VLA 模型

**1. VLAff：视觉-语言-可供性统一模型**
[VLAff: Vision-Language-Affordance Model for Unified Actionable Affordances](https://arxiv.org/abs/2608.05215)
- 从第一人称人类视频中提取视觉、抓取和轨迹可供性，构建大型数据集 EgoAffordance（204K 片段）。
- 基于大视觉语言模型，统一生成可供性热图、抓取位姿和轨迹，支持零样本操控和可供性引导的机器人学习。

**2. W2-VLA：世界到手腕的精细操控 VLA**
[World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation](https://arxiv.org/abs/2608.05369)
- 提出任务条件化的未来手腕建模，将主视角和腕部视角分离处理。
- 引入 W2-CoT 合成管线生成结构化标注，在 LIBERO、RoboTwin 2.0 及真实任务中提升精细接触操控，动作生成率超 80 Hz。

**3. JoyAI-RA 0.5：双动作对齐的机器人操作学习**
[JoyAI-RA 0.5: Scaling Robot Manipulation Learning via Dual Action Alignment](https://arxiv.org/abs/2608.05674)
- 通过隐式动作推断和显式动作对齐，实现人类视频、仿真和真实机器人数据的统一学习。
- 任务得分随人类第一视角预训练数据量持续提升，验证了弱标注人类视频可作为主要训练信号。

**4. In-Context VLA：上下文后训练与工具使用**
[In-Context VLA: Endowing Vision-Language-Action Models with Language via In-Context Post-Training and Agentic Tool Use](https://arxiv.org/abs/2608.05738)
- 证明自由文本思维链会损害底层控制，提出上下文后训练+代理工具使用接口。
- 在 RoboCasa、SimplerEnv、LIBERO 和 8 项真实任务中达到 SOTA 性能。

**5. MMaDA-VLA：统一多模态指令与生成的大扩散 VLA**
[MMaDA-VLA: Large Diffusion Vision-Language-Action Model with Unified Multi-Modal Instruction and Generation](https://arxiv.org/abs/2603.25406)
- 完全原生的离散扩散 VLA，共享 token 空间联合去噪未来目标观测和动作块。
- LIBERO 平均成功率 98.0%，CALVIN 平均成功序列长度 4.78。

**6. DFM-VLA：离散流匹配迭代动作细化**
[DFM-VLA: Iterative Action Refinement for Robot Manipulation via Discrete Flow Matching](https://arxiv.org/abs/2603.26320)
- 通过 token 级概率速度场实现动作标记的迭代修正，解决早期 token 错误无法纠正的问题。
- 引入度量对齐动作分词器和两阶段解码策略，在 CALVIN 和 LIBERO 等基准上验证有效。

**7. DyPES-VLA：跨具身操控的共享动力学先验**
[DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment Manipulation](https://arxiv.org/abs/2608.06374)
- 通过未来预测目标学习共享动力学先验，MoE 动作头直接输出各具身原生动作空间。
- LIBERO 达到 98.0%，RoboCasa-GR1 59.25%，RoboTwin 2.0 89.02%。

**8. ω-0：潜空间预测全身动作世界模型**
[ω-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation](https://arxiv.org/abs/2608.06375)
- 面向人形机器人行走+操作并发任务，直接预测控制器兼容的全身动作潜变量。
- 收集 40+ 小时 ω-HOME 数据集，在 11 项家用任务上优于模仿学习、VLA 等基线。

## 世界模型与动作预测

**9. GeniWorld：可泛化的交互世界模型**
[GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions](https://arxiv.org/abs/2608.06332)
- 基于 URDF 渲染将数值动作转化为视觉动作表示，解耦具身运动学与环境动力学。
- 即使在有限固定场景数据训练下，也能零样本泛化到高度随机的未知环境。

**10. XEWorld：跨具身世界模型泛化测试**
[XEWorld: Can Action-Conditioned World Models Generalize to Unseen Robot Embodiments?](https://arxiv.org/abs/2608.05799)
- 揭示当前世界模型本质上是 2D 视觉模式匹配器，泛化由视觉相似性而非物理运动学相似性主导。
- 指出实现真正的跨具身泛化需要解耦视觉外观与底层物理动力学。

**11. Enfold：折叠世界模型想象至预测表征**
[Enfold: Folding World Model Imagination into Predictive Representations for Ultra-Efficient Embodied Control](https://arxiv.org/abs/2607.26657)
- 将生成器的未来构建计算内化为仅由当前输入推断的表征，部署时无需执行生成器。
- 动作延迟降低 3.7 倍，Enfold-Flash 版本达 10.1 倍。

**12. Tactile-WAM：触觉感知世界动作模型**
[Tactile-WAM: Touch-Aware World Action Model with Tactile Asymmetric Attention](https://arxiv.org/abs/2606.26663)
- 通过非对称注意力阻挡视频查询访问触觉键，同时保留动作查询的触觉访问。
- 在 ManiFeel 上成功率从 15.6% 提升至 32.7%，5 项真实任务平均成功率 49.2%。

**13. DynamicWAM：动态操控中的双路径运动条件**
[DynamicWAM: Dual-Path Motion Conditioning for World-Action Models in Dynamic Manipulation](https://arxiv.org/abs/2608.00793)
- 引入历史流条件（光流编码）和运动学描述符（位移、速度、加速度）双路径。
- DOMINO 上成功率 38.2%，12 项真实动态任务平均成功率 46.7%。

## 灵巧操作与接触操控

**14. CADRE：动态接住掉落物体的接触感知恢复**
[CADRE: Dynamic Catching via Implicit Contact Descriptors and Task-Appropriate Recovery Affordances](https://arxiv.org/abs/2510.14768)
- 结合 NDF 启发的接触特征模块和隐式恢复可供性函数，实现掉落物体抓取恢复。
- 可零样本泛化到不同几何形状的未见物体。

**15. TRACT：接触丰富操作的时间路由动作块**
[TRACT: Temporally Routed Action Chunks with Chronological Phase Authority for Contact-Rich Manipulation](https://arxiv.org/abs/2607.29285)
- 解决动作块跨越程序边界时的相位时序失配问题，引入任务局部图约束相位权威。
- 6 项真实任务变体各 10 次试验中，全序列成功率 10/10，无相位歧义。

**16. MDIR：接触丰富遥操作的任务流形阻抗重定向**
[MDIR: A Task-Manifold Impedance Retargeting Method for Contact-Rich Teleoperation](https://arxiv.org/abs/2607.29271)
- 单次演示的控制器到控制器阻抗重定向，保留任务通道响应同时降低腕部力峰值。

**17. VIDP：可变阻抗扩散策略**
[VIDP: Variable Impedance Diffusion Policy for Compliant Robot Manipulation from Diverse Demonstrations](https://arxiv.org/abs/2608.06210)
- 通过任务参数化方向感知混合模型提取一致性轨迹分布，映射为刚度分布。
- 联合预测位姿动作和任务柔顺性，无需力传感器即可实现可变阻抗控制。

## Sim-to-Real 与机器人学习

**19. 平行连杆机构的仿真侧动力学归一化**
[Bridging the Sim-to-Real Gap in Parallel-Link Leg Mechanisms via Simulator-Side Dynamics Normalization](https://arxiv.org/abs/2608.01697)
- 提出 S3N 方法对串行树替代模型的动力学进行归一化，关节位置误差 RMSE 降低 80.9%。
- 圆形运动相位平均 sim-to-real 差距从 17.3% 降至 9.9%。

**20. TRACE：不可靠接触条件下的本体感知里程计**
[TRACE: Learned Proprioceptive Odometry for Legged Robots under Unreliable Contact Conditions](https://arxiv.org/abs/2608.05975)
- 端到端学习本体感知里程计，脚感知交叉注意力模块自适应加权 IMU 和腿部运动学信息。
- 在多种地形上比经典滤波、混合和纯学习方法一致降低位置漂移。

**21. Rapid Embodiment Adaptation for Quadrupedal Locomotion**
[文章链接](https://arxiv.org/abs/2608.01506)
- 半秒内从短交互历史推断具身参数（关节限位约束和躯干质量变化）。
- 真实 Unit2 Go2 上即使完全锁死一条腿或携带 5 kg 负载仍能保持稳定运动。

**22. GCSL-NF：带负反馈的目标条件监督学习**
[Autonomous Learning From Success and Failure: Goal-Conditioned Supervised Learning with Negative Feedback](https://arxiv.org/abs/2509.03206)
- 每次轨迹评估两次：对重标注目标正向评估，对原始目标纠错评估。
- 无需奖励函数或几何距离，通过对比学习得到相似度函数。
