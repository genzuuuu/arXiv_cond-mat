### 二、 视觉-语言-动作（VLA）模型

本节汇总了在 VLA 模型架构、训练、适应性和泛化能力方面的研究。

1.  **SUAVE: Unified Video-Action Models via Masked Diffusion**
    - **核心内容**: 提出 SUAVE，一个统一的视频-动作模型。它使用掩码扩散 Transformer，将视频、动作和语言表示为共享序列中的离散 token，从而统一了世界模型、机器人策略和视频-动作模型的功能。
    - **链接**: [SUAVE: Unified Video-Action Models via Masked Diffusion](https://arxiv.org/abs/2610.04009)

2.  **Vela: Scaling Vision-Language-Action Models with Adaptive Action Curve Parametrization**
    - **核心内容**: Vela 通过将未来机器人行为表示为连续轨迹（样条曲线）来改进 VLA 模型。该方法使用运动相关的时序支持和统一的动作接口，使固定输出预算能适应不同运动的时序分辨率。
    - **链接**: [Vela: Scaling Vision-Language-Action Models with Adaptive Action Curve Parametrization](https://arxiv.org/abs/2610.05230)

3.  **ExStereo: Lifting 2D Vision-Language-Action Models to 3D with Explicit Stereo Representations**
    - **核心内容**: ExStereo 模块通过从立体图像对重建场景几何，为预训练的 2D VLA 模型增强 3D 感知能力。动作 token 通过交叉注意力机制选择性地关注立体 token，从而生成基于 3D 场景信息的机器人动作。
    - **链接**: [ExStereo: Lifting 2D Vision-Language-Action Models to 3D with Explicit Stereo Representations](https://arxiv.org/abs/2610.04805)

4.  **RoboIRS: Inference-Time Internal Representation Steering for Generalist Robot Policies**
    - **核心内容**: RoboIRS 是一种推理时内部表示引导方法，通过训练线性分类器来选择和引导任务特定的方向，从而在不更新策略参数的情况下，恢复 VLA 和 WAM 在分布外任务上的能力。
    - **链接**: [RoboIRS: Inference-Time Internal Representation Steering for Generalist Robot Policies](https://arxiv.org/abs/2610.04681)

5.  **RealtimeWAM: One-Step Asynchronous World Action Models**
    - **核心内容**: RealtimeWAM 通过一步动作生成和异步推理，解决了世界动作模型（WAMs）的推理效率瓶颈。它提出了教师锚定一致性蒸馏和跨专家波前流水线技术，在多个基准上实现了近乎无损的性能和显著的端到端加速。
    - **链接**: [RealtimeWAM: One-Step Asynchronous World Action Models](https://arxiv.org/abs/2610.06617)

6.  **ProbeFlow: Training-Free Adaptive Flow Matching for Vision-Language-Action Models**
    - **核心内容**: ProbeFlow 是一个无需训练的自适应推理框架，用于加速 VLA 模型中的流匹配动作头。它通过评估轨迹复杂度动态调整积分步数，在 MetaWorld 上实现了 14.8 倍的动作解码加速。
    - **链接**: [ProbeFlow: Training-Free Adaptive Flow Matching for Vision-Language-Action Models](https://arxiv.org/abs/2603.17850)

7.  **FLASH: Efficient Visuomotor Policy via Sparse Sampling**
    - **核心内容**: FLASH 用连续的勒让德多项式轨迹表示取代离散动作块生成，通过稀疏采样和从历史多项式系数开始流匹配，实现了单步推理。该方法在多个任务上达到 SOTA 成功率，推理速度比扩散策略快 175 倍。
    - **链接**: [FLASH: Efficient Visuomotor Policy via Sparse Sampling](https://arxiv.org/abs/2605.15492)

8.  **Do VLAs Understand and Adapt to the Objects They Handle, or Simply Replay Learned Behaviors?**
    - **核心内容**: 该研究探讨 VLA 模型是否真正理解物体的物理属性。通过线性探测和表征相似性分析发现，VLA 模型对物理属性的编码较弱，且在任务中很少利用这些信息来调整动作，更多地是重放已学会的行为。
    - **链接**: [Do VLAs Understand and Adapt to the Objects They Handle, or Simply Replay Learned Behaviors?](https://arxiv.org/abs/2610.06078)

### 三、 世界模型与仿真

1.  **FLEX-WAM: Flexible Block-Causal World-Action Models for Long-Horizon Imagination and Planning**
    - **核心内容**: FLEX-WAM 是一个灵活且高效的块因果世界-动作模型，支持可变长度上下文和无因果预测时域，并可通过 KV 缓存实现高效的实时推演。它通过平衡状态和动作的梯度贡献，解决了模型对指令动作响应弱的问题。
    - **链接**: [FLEX-WAM: Flexible Block-Causal World-Action Models for Long-Horizon Imagination and Planning](https://arxiv.org/abs/2610.05483)

2.  **DreamFormer: Dream Imitation with a Transformer World Model for Language-Conditioned Robotic Manipulation**
    - **核心内容**: DreamFormer 提出一种基于模型的智能体，通过在学习的 Transformer 世界模型的潜在想象中模仿专家演示来获取语言条件下的多任务技能。该方法在 CALVIN 基准上表现优异，并展现出强大的零样本迁移能力。
    - **链接**: [DreamFormer: Dream Imitation with a Transformer World Model for Language-Conditioned Robotic Manipulation](https://arxiv.org/abs/2610.04540)

3.  **Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation**
    - **核心内容**: Token-World 提出在 VLM 的 token 空间中建模世界动态。它首先将 VLM 特征压缩为紧凑的 token 状态，然后在此空间中学习未来动态，并映射回策略面向的表示，从而提高了开环特征保真度和策略-动作一致性。
    - **链接**: [Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation](https://arxiv.org/abs/2610.00575)

4.  **Magic-W0: A Structured World-Action Foundation Model for Physical Intelligence**
    - **核心内容**: Magic-W0 是一个世界-动作基础模型，通过“当前状态”、“转换”和“未来状态”的结构化世界转换来联合建模物理状态演化和连续动作。它采用层级对齐的世界-动作交互架构，在多个机器人任务中展现出强大的泛化能力。
    - **链接**: [Magic-W0: A Structured World-Action Foundation Model for Physical Intelligence](https://arxiv.org/abs/2609.39870)

5.  **SimForcing: Distilling Simulation Motion Priors into Real-Domain Robot World Models**
    - **核心内容**: SimForcing 是一个由仿真引导的框架，通过潜在运动蒸馏和多块仿真条件化，将仿真中的运动知识迁移到真实域的机器人世界模型中。该模型能生成动作条件化的视频，并可用于初始化 VLA 模型以提升下游任务成功率。
    - **链接**: [SimForcing: Distilling Simulation Motion Priors into Real-Domain Robot World Models](https://arxiv.org/abs/2610.06598)

6.  **EnvDreamer: Large-Scale Multimodal-to-Environment Generation for Embodied AI**
    - **核心内容**: EnvDreamer 是一个利用大型语言和视觉模型生成 Unreal Engine 5 环境的框架，用于具身 AI 和机器人训练。它生成了 20,000 个通过验证的环境数据集，并展示了在导航、重排和操作等任务上的有效性。
    - **链接**: [EnvDreamer: Large-Scale Multimodal-to-Environment Generation for Embodied AI](https://arxiv.org/abs/2610.04301)

### 五、 抓取与操作策略

本节汇总了在抓取检测、操作策略学习以及任务规划方面的研究。

1.  **RAGrasp: Geometry-Semantic Template Retrieval and Grasp Transfer**
    - **核心内容**: RAGrasp 是一个检索增强的平面二指抓取流程，无需端到端重训练。它使用 DINOv2 特征和 SAM2 分割物体，通过两阶段几何-语义检索级联选择模板并进行抓取迁移。在真实世界试验中，对已见和未见物体的抓取成功率分别达到 20/20 和 19/20。
    - **链接**: [RAGrasp: Geometry-Semantic Template Retrieval and Grasp Transfer](https://arxiv.org/abs/2610.04438)

2.  **GraRe: Grasp Candidate Re-Ranking for Frozen 6-DoF Grasp Detectors**
    - **核心内容**: GraRe 提出对冻结的 6-DoF 抓取检测器进行候选重排序。它从候选属性、局部几何和物体上下文估计抓取质量，并与检测器置信度结合产生最终排序，在 GraspNet-1Billion 上使平均 AP 提升高达 13.56 个点。
    - **链接**: [GraRe: Grasp Candidate Re-Ranking for Frozen 6-DoF Grasp Detectors](https://arxiv.org/abs/2608.00946)

3.  **Robot Learning with Visual Predicted Force**
    - **核心内容**: 该研究展示了通过视觉力预测（从 Fin Ray 夹爪的形变中预测力）实现力感知操作。它训练了一个视觉力估计器和一个动作-力提议策略，在测试时选择预测力最接近目标的动作，无需在部署时使用力或触觉传感器。
    - **链接**: [Robot Learning with Visual Predicted Force](https://arxiv.org/abs/2610.04741)

4.  **Nudge Before You Push: Physics-Aware Navigation via Tactile Probing**
    - **核心内容**: TANav 通过一个短暂的“轻推”来测量推动阻力，从而在站点定义的处理边界下进行导航。TacPhys 将力序列读取为质量估计，用于推动授权。在模拟中，该方法显著减少了遗漏推动和边界违规。
    - **链接**: [Nudge Before You Push: Physics-Aware Navigation via Tactile Probing](https://arxiv.org/abs/2610.04924)

5.  **REDIRECT: A 1% Fix for Bad Robot Habits**
    - **核心内容**: REDIRECT 旨在用 1% 的全训练样本-反向传播预算来修复机器人从遥操作数据中习得的“坏习惯”。它仅使用回合级的保留/问题标签，定位问题分支，并为原始观测分配连贯的保留延续，在三个 ManiSkill 任务中将平均成功率从 68.2% 提升至 90.3%。
    - **链接**: [REDIRECT: A 1% Fix for Bad Robot Habits](https://arxiv.org/abs/2610.03997)

6.  **Reward-DAgger: Robot-Gated Interactive Imitation Learning with General-Purpose Progress-Based Reward Models**
    - **核心内容**: Reward-DAgger 是一个机器人门控的交互式模仿学习框架，它使用通用奖励模型提供的密集进度信号来决定何时需要人工干预。该方法与策略架构无关，在八个模拟和真实任务中持续提升了自主成功率。
    - **链接**: [Reward-DAgger: Robot-Gated Interactive Imitation Learning with General-Purpose Progress-Based Reward Models](https://arxiv.org/abs/2610.04054)
