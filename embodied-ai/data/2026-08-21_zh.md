# 具身智能与机器人操作相关论文摘要

## 触觉感知与遥操作

**[The Missing Touch: Spatially Distributed Tactile Feedback Brings Teleoperation Closer to Human Dexterity](https://arxiv.org/abs/2608.19372)**  
研究发现空间分布触觉反馈是遥操作性能与人类灵巧度差距的关键因素。通过32自由度触觉指尖显示器，再现机械手的局部形变信息后，操作性能显著提升，遥操作轨迹与自然人类行为的偏差降低29–79%。

**[HiTac-WAM: A Hierarchical Tactile World Action Model for Contact-Rich Robot Manipulation](https://arxiv.org/abs/2608.19574)**  
提出层级触觉世界动作模型，预测接触状态、3D形变场和滑移风险三个层次的未来触觉状态。层级结构将3D位移L2误差降低17.6%，在芯片抓取、擦黑板和USB插入任务中，真实机器人成功率从31.1%提升至72.2%。

## 灵巧手与多指抓取

**[GOAG: Generative and Object-Agnostic Grasp Planner for Dexterous Robotic Manipulation](https://arxiv.org/abs/2608.19759)**  
提出基于生成模型的对象无关抓取规划方法，学习特定灵巧手的接触表面分布，推理时仅引入对象特征即可采样有效抓取构型。在MultiDex数据集上平均成功率达86.93%，无需对象特定训练数据。

**[CoToGrasp: Contact-Topology-Conditioned Dexterous Grasp Synthesis via Canonical Workspace Learning](https://arxiv.org/abs/2608.19776)**  
提出按特定接触拓扑条件化生成多样化稳定抓取，通过特征规范工作空间解耦语义意图与对象几何，实现对新物体的零样本泛化，并在物理机器人上验证了可行性。

**[ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using Reinforcement Learning](https://arxiv.org/abs/2608.19182)**  
大规模RL框架，先在通用对象重定位任务上预训练灵巧策略，再通过稳定的后训练流程蒸馏到感知学生模型，实现23-DoF Kuka-Allegro和29-DoF Flexiv-Sharpa的零样本sim-to-real迁移，达到人类速度的灵巧操作。

## 视觉-运动策略与VLA模型

**[Fine-Tuning VLAs with Self-Demonstrated Generative Control for Multi-Task Manipulation](https://arxiv.org/abs/2608.19490)**  
提出自监督方法，利用零样本VLA生成的在线交互rollout作为微调补充数据，在目标机器人上保留原有指令跟随能力的同时学习新技能，在真实ALOHA机器人和RoboTwin仿真中验证了效果。

**[OrthoSkillVLA: Continual Skill Learning via Gradient-Informed Skill Subspace Adaptation](https://arxiv.org/abs/2608.19589)**  
针对VLA模型持续技能学习中的灾难性遗忘，对VLM和ActionHead施加分离的子空间约束，并为输出层引入轻量级MoE解码器，在模拟和真实环境中均优于基线。

**[GS-VLA: Plug-and-Play Viewpoint Canonicalization for Frozen VLA Policies via Gaussian Splatting](https://arxiv.org/abs/2608.19066)**  
轻量级3D高斯规范器预处理，使冻结的VLA策略对视角偏移保持鲁棒。实验显示相机位移可将LIBERO成功率从90%降至10%，而该方法无需策略重训练即可大幅恢复性能。

## 分层操作与任务规划

**[Learning Hierarchical Skill Policies with Offline Quality-Diversity Reinforcement Learning](https://arxiv.org/abs/2608.19684)**  
提出QDOS框架，通过优势加权质量-多样性预训练目标提取多样且高价值的技能，结合双数据集复用策略，在结构化操作和运动任务上显著优于强基线。

**[Where to Touch, How to Contact: A Hierarchical RL-MPC Framework for Geometry-Aware Sim-to-Real Manipulation](https://arxiv.org/abs/2601.10930)**  
高层RL策略预测接触意图（接触位置+子目标位姿），低层接触隐式MPC优化局部接触模式。数据效率提升40倍，实现零样本sim-to-real迁移。

## 世界模型与操作规划

**[GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction](https://arxiv.org/abs/2608.18234)**  
首个用于人形全身控制的行为世界模型（BWM），因果Transformer同时预测动作、状态和潜在行为命令分布，实现在地形交互、不合理命令和摔倒恢复上的显著提升，真机可迁移至不同型号。

**[Mask2Real-WM: Segmentation Masks as a Sim-to-Real Bridge for Controllable Dexterous World Models](https://arxiv.org/abs/2607.04546)**  
两阶段动作条件世界模型，将像素预测解耦为分割掩码动力学模型+真实感渲染模型。利用分割空间更小的sim-to-real差距，实现50小时仿真预训练+2.5小时真机微调，对23自由度全部分轴可控。

## Sim-to-Real与策略评估

**[SCAPE: Scenario-Conditioned Simulation-Augmented Policy Evaluation](https://arxiv.org/abs/2608.19425)**  
场景条件仿真增强策略评估框架，预测特定场景下的真实性能并校准不确定度。在自动驾驶和四足速度跟踪任务中显著降低场景级预测误差。

**[Sim-to-Real Betting on the E-Process: Bringing "simulators" to anytime-valid confidence sequences](https://arxiv.org/abs/2606.24038)**  
将sim-to-real性能估计与任意时点有效置信序列整合，为机器人性能测试提供高效可靠的平均估计认证方法。

## 人体动作学习与技能获取

**[HOST: Robots Acquire Manipulation Skills in Seconds from a Single Human Video](https://arxiv.org/abs/2607.20033)**  
级联自接地预测框架，从单个人类视频中秒级获取技能（平均29秒，成功率62%），且不遗忘已掌握技能，比基于50个演示微调的基线快507倍。

## 多模态具身交互

**[EATR-Stereo: Embodiment-Aware Token Routing of Paired Stereo Evidence for Humanoid Vision-Language-Action Control](https://arxiv.org/abs/2608.17453)**  
保留主视图令牌并构建主视图对齐的跨视辅助令牌，配合身体分段本体感觉编码器，在33自由度物理人形上实现60%完整任务成功率，遮挡下恢复能力提升至80%。

## 其他相关

**[Video2DoorTraversal: Push Door Traversal via Simulated Door Twins](https://arxiv.org/abs/2608.20251)**  
单视频real-to-sim-to-real框架，重建关节化仿真门孪生体并训练双深度策略，五个真实门平均成功率96.57%，对未见门零样本成功率80.95%。

**[Learning Vision-Driven Reactive Soccer Skills for Humanoid Robots](https://arxiv.org/abs/2511.03996)**  
统一RL控制器直接耦合视觉感知与运动控制，虚拟感知系统模拟机载视觉噪声，球位置估计误差降低46%，踢球耗时缩短64%。

**[DECOWAM: Decoupled Whole-Body World-Action Model for Legged Mobile Manipulation](https://arxiv.org/abs/2608.20114)**  
解耦移动操作中相机自运动与基座/手臂动作，冻结FastWAM骨干并训练残差适配器，动作MSE降低21.7%，在79次闭环试验中展现了最佳全身协调性。

**[HiTac-WAM的另一个角度](https://arxiv.org/abs/2507.04234) - SoftVTBench: A Safety-Aware Visuo-Tactile Benchmark**  
提出考虑安全性的视触觉基准，分开评估目标成功与安全成功。实验表明仅评估成功率会高估策略表现，触觉感知可将安全成功率从21.4%提升至35.6%。

**[Neurosymbolic Embodied Agents](https://arxiv.org/abs/2608.16794)**  
神经符号具身智能体，将长时程家务任务分解为任务导向视觉探索和约束符号规划，4B-27B模型在VirtualHome和ALFWorld上成功率均超90%。
