## 一、具身智能与 VLA 模型

### 1. 未来预测与动作生成的监督位置
- **Token-World**：在 VLM token 空间中建模世界动力学，将 VLM 特征压缩为紧凑 token 状态，预测未来动态后映射回策略表示。闭环下其模拟策略性能与参考策略的相关性显著高于 Ctrl-World。[Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation](https://arxiv.org/abs/2610.00575)
- **Where Predictive Supervision Goes Shapes What VLA Policies Learn**：通过受控实验发现，预测监督的位置（而非预测质量本身）决定了 VLA 策略学到的视觉表示是否对控制有用，直接影响分布偏移下的鲁棒性。[Where Predictive Supervision Goes Shapes What VLA Policies Learn](https://arxiv.org/abs/2609.36645)
- **Completion Aware Guidance (CAG)**：针对 World Action Models 在短 chunk 控制下常产生的“任务未完成想象”，提出训练无关的采样引导方法。RoboTwin 2.0 子集成功率从 64% 升至 70%，任务未完成想象从 79% 降至 40%。[Completion Aware Guidance for World Action Models](https://arxiv.org/abs/2610.01559)

### 2. 长时程记忆与推理
- **ECoMEM**：用可复用的 grounded concept 库表示任务相关历史，Writer 更新记录、Reader 将其转为记忆 token 条件化 VLA。在 16 个 RoboMME 任务中 15 个领先，真实机器人任务 86.1% 成功率（无记忆 VLA 仅 8.6%）。[ECoMEM: Explicit Concept Memory for Memory-Dependent Robot Control](https://arxiv.org/abs/2610.00801)
- **Divide-and-Remember (D&R)**：从 POMDP 出发证明最优记忆应最大化 $I(a_t; m_t \mid o_t)$，提出递归记忆方法，在 64 token 预算下于 RoboMME 四个套件均达 SOTA。[Divide-and-Remember: Recursive Action-Relevant Memory for Long-Horizon VLA Policies](https://arxiv.org/abs/2610.00982)
- **MIKASA-Robo-VLA**：90 个语言条件操作任务的长时程记忆 benchmark，其中 70 个隐藏任务相关线索，28 个信息间隙超过最宽固定上下文 VLA 的 16 帧窗口。参考 π₀.₅ 基线平均成功率仅 0.211。[MIKASA-Robo-VLA: Benchmarking Memory in VLA Models for Long-Horizon Manipulation](https://arxiv.org/abs/2610.00604)

### 3. 推理链监控与安全
- **TRUST**：离线训练的价值模型可从部分前缀预测推理正确性，监控并选择性引导冻结 VLA 的推理生成。在 Alpamayo 1.5 驾驶 VLA 上推理正确率从 75.9% 提升至 90.0%，碰撞率降低 30.4%；但在 DeepThinkVLA 操作模型上任务性能基本不变，揭示推理正确性提升不自动带来具身性能提升。[When Reasoning Helps Action: Monitoring and Steering Chain-of-Thought in Vision-Language-Action Policies](https://arxiv.org/abs/2610.00601)

### 4. 组合泛化与技能对齐
- **CRAFT**：针对 VLA 在未见技能组合上的泛化失败，通过固定演示观测、改变指令构造反事实对，并利用技能表示迁移监督信号。在三个 VLA 模型和两个仿真 benchmark 上提升未见组合成功率。[Same Scene, Different Task: Skill Alignment for Compositional Generalization in VLAs](https://arxiv.org/abs/2610.00524)
- **Continual Imitation Learning Benchmark**：发现强持续学习性能不总能转化为可靠的语言接地，提出语义鲁棒性、目标适应性和语言敏感性等诊断指标。[Does Continual Imitation Learning Remain Grounded? A Language-Perturbed Benchmark for Robotic Task Retention](https://arxiv.org/abs/2610.00542)

### 5. 高效推理与蒸馏
- **DriftOPD**：无教师、无 rollout 的序列级 on-policy 蒸馏框架，将序列级 reverse-KL 分解为 chunk 级 reverse-KL 项和未来势能项，用一步 drifting 目标优化，使一步 VLA 策略达到多步教师水平的任务成功率。[DriftOPD: Sequence-Level Reverse-KL Distillation for One-Step VLA Policies](https://arxiv.org/abs/2610.00317)
- **K-MF**：针对 MeanFlow 直接应用于机器人基础模型导致性能崩溃的问题，提出 Kinematic MeanFlow，将时间导数项解耦为两个子区间项分别捕捉早期和晚期去噪动态，在 GR00T-N1.6 上动作头延迟降低 67.5%~74.4%。[Kinematic MeanFlow: One-Step Action Generation Policy for Robotic Foundation Models](https://arxiv.org/abs/2610.00864)
- **eRLT**：通过 token 和层路由从冻结 VLA 中提取任务相关动作信息构建 RL 状态表示，在七个 LIBERO 和 RoboTwin 任务上平均归一化学习曲线 AUC 提升最多 23.7%。[eRLT: Efficient VLA Reinforcement Learning via Action-Relevant Token Routing](https://arxiv.org/abs/2610.00913)

### 6. 其他 VLA 相关
- **TOAST**：随机动作 tokenization 方法，训练时对同一量化动作序列采样不同 tokenization，在 LIBERO 上训练数据仅剩 1/16 时成功率提升 6.8 个点，真实机器人任务平均成功率提升 15.8 个点。[TOAST: Stochastic Robot Action Tokenization for Autoregressive Vision-Language-Action Models](https://arxiv.org/abs/2610.00899)
- **DynamicVLA**：针对动态物体操作中的延迟导致感知-执行不匹配问题，提出延迟感知 VLA，结合紧凑 0.4B 架构和连续推理调度，并引入 200K 合成 episode 的 DOM benchmark。[DynamicVLA: A Vision-Language-Action Model for Dynamic Object Manipulation](https://arxiv.org/abs/2601.22153)
- **UniWAM**：统一世界-动作模型，整合物理推理器、世界生成器和动作预测器，并在人-机器人数据混合预训练中发现对数线性 scaling law。[UniWAM: Unified World-Action Model](https://arxiv.org/abs/2610.02054)
- **FRAM**：138.7M 参数的小策略，通过预测未来末端执行器轨迹的像素坐标作为空间指针，读取局部视觉特征。LIBERO 四套件平均 92.2%，接近 3.3B 的 π₀（94.2%）。[FRAM: Trajectory-Guided Visual Feature Selection for Compact Language-Conditioned Robot Manipulation](https://arxiv.org/abs/2609.30965)

## 二、灵巧操作与多指抓取

- **DexPolicy**：在轨迹引导的灵巧操作 RL 中，将探索尺度设为训练步数的显式函数，从宽到窄退火。五个 YCB 物体上平均确定性 Target 成功率从 49.4% 升至 68.1%（FPO），真实机械臂上从 25.0% 升至 85.0%。[DexPolicy: Scheduled Exploration for Trajectory-Guided Dexterous Manipulation](https://arxiv.org/abs/2610.00360)
- **BORA**：离线到在线 RL 系统，将动作条件 critic 整合到一致性策略 VLA 中，仅更新轻量残差 actor。仅用每任务 20 条在线轨迹，标准物体成功率从 60.8% 升至 82.5%，held-out 物体从 52% 升至 70%。[BORA: Bridging Offline Reinforcement Learning and Online Residual Adaptation for Real-World Dexterous VLA Models](https://arxiv.org/abs/2605.30226)
- **DexHoldem**：基于 ShadowHand 的德州扑克灵巧操作 benchmark，含 1,470 条遥操作演示和 14 个操作原语。π₀.₅ 最高任务完成率 61.2%，场景保持成功率 47.5%。[DexHoldem: An Agentic Robotics Benchmark for Dexterous Manipulation in Texas Hold'em](https://arxiv.org/abs/2605.18727)
- **FlashDexRetarget**：基于 RL 的高成功率、高效灵巧运动重定向框架，结合物体点云观测、手-物距离特征和未来轨迹编码，50 个运动 benchmark 上达 90% 成功率，训练计算量比 RL baseline 少最多 100 倍。[FlashDexRetarget: Accelerating Dexterous Manipulation Data Generation through Multi-Motion Retargeting](https://arxiv.org/abs/2610.01849)
- **Dex-X**：从人类视频学习视觉-触觉灵巧操作，关键洞察是仿真可作为“触觉补全引擎”，从单目人类演示重建手-物交互获取触觉监督。真实机器人上立方体抓取 93% 成功，桌面清理 53%。[Dex-X: Learning Visual-Tactile Dexterous Manipulation From Human Videos with Simulated Interaction](https://arxiv.org/abs/2609.07747)
- **JAMB**：联合去噪双臂动作和未来 3D 点轨迹的扩散策略，在共享 Transformer 中让动作和轨迹假设共同演化。RoboTwin 2.0 的 16 个仿真任务平均成功率 83.4%，比最强 baseline 高 23.9 个点。[JAMB: Joint Action-Motion Diffusion for Bimanual Manipulation](https://arxiv.org/abs/2609.25322)
- **TacGooseBumps (TacGB)**：被动穹顶薄膜，通过压力图模式变化机械编码切向载荷，无需额外电子器件或力重建。四个模仿学习任务中插入成功率提升最多 36 个点。[TacGooseBumps (TacGB): Retrofitting Normal-Only Tactile Sensors with Shear Encoding for Learning Contact-Rich Manipulation](https://arxiv.org/abs/2609.34006)

## 三、触觉感知与多模态传感

- **TacDyn-WAM**：异构视觉-触觉世界动作模型，预测隐式触觉动态而非重建未来触觉观测。学习 TacRep 动态感知触觉目标空间，在 UniVTAC 上仅用给定演示达 81.5% 平均成功率，五个真实机器人任务上 71.0%，适度预训练后升至 85.0%。[TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model](https://arxiv.org/abs/2610.00638)
- **TouchTherm**：从真实物体构建仿真就绪的视觉-触觉-热学资产，结合结构光扫描与光度立体法获取法线图恢复微观高度场，热学重建达到 30s/45s 时 0.465°C/0.592°C 的表面温度 MAE。[TouchTherm: Building Multimodal Digital Twins of Objects for Tactile and Thermal Rendering](https://arxiv.org/abs/2610.01943)
- **Deformable In-Hand Slip-Aware Tactile Sensor**：首个在单一柔顺结构中集成速度传感、力/扭矩传感和压力图估计的触觉传感器，可稳健跟踪平面和曲面。[Deformable In-Hand Slip-Aware Tactile Sensor with Integrated Velocity Sensing, Force/Torque and Pressure Map Estimation](https://arxiv.org/abs/2606.11952)
- **External Photoreflective Tactile Sensing**：基于软体机器人机械柔顺性的外部可附着光反射模块，通过读取硅胶皮肤表面变形估计接触力，无需嵌入触觉换能器。[External Photoreflective Tactile Sensing Based on Surface Deformation Measurement](https://arxiv.org/abs/2511.06311)

## 五、仿真到现实迁移

- **Real2Sim2Real Co-Training**：区分世界接地和行为接地两个维度，动态灵巧 pick-and-sort 任务上完全接地的 co-training 将成功率从 52% 提升至 86%，世界接地平均贡献 18 个点，行为接地贡献 10 个点。[Getting Out and Getting Back: World and Behavior Grounding in Real2Sim2Real Co-Training](https://arxiv.org/abs/2610.00821)
- **Real-to-Sim 重建效果测量**：对比精心重建（度量尺度几何+作者物理参数+场景 splat）与默认开源配方，十个任务-策略单元中仿真与真实评分的 Pearson 相关分别为 r=0.90 和 r=0.51，平均评分误差降低 10.56 个点。[Measuring Asset and Scene Reconstruction Effects in Real-to-Sim Robot Evaluation](https://arxiv.org/abs/2610.00731)
- **multipanda_ros2**：开源 ROS2 多机器人控制架构，支持任意数量 Franka 机器人从单进程控制，维持 1kHz 控制频率，控制器切换延迟 ≤2ms，集成高保真 MuJoCo 仿真和运动学/动力学一致性定量指标。[Bridging the Sim-to-Real Gap with multipanda_ros2: A Real-Time ROS2 Framework for Multimanual Systems](https://arxiv.org/abs/2602.02269)
- **EIDA**：执行接口动力学适应，从目标平台执行数据拟合身体坐标系位姿增量和速度反馈模型，无需重建执行器动力学。Unitree Go2 上 20 次静态场景试验全部无碰撞到达目标（baseline 仅 4/20）。[EIDA: Execution-Interface Dynamics Adaptation for Real-to-Sim-to-Real Robot Navigation](https://arxiv.org/abs/2610.01219)
- **RPG**：自主改进机器人执行系统而无需更新模型权重，在仿真中识别操作能力并构建练习任务，通过执行反馈诊断失败并开发可复用符号技能。22 个操作任务上从 28.6% 提升至 95.0%。[Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents](https://arxiv.org/abs/2610.02204)

## 六、人形机器人与全身控制

- **λ₀**：全身人形视觉-语言-动作策略，通过三阶段训练从多样化自我中心数据集学习交互，再用 HumanVerse-500（500 小时人类 loco-manipulation 数据）协调身体和手部运动，最后适配下游任务和机器人本体。在 SIMPLE 和 4 个真实世界任务上达 SOTA。[Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining](https://arxiv.org/abs/2610.00438)
- **WholeBodyWAM**：人形世界-动作模型，从大规模异构运动数据（UniMotion-4K，4K+ 小时）学习全身动力学，再通过非对称 MoT 注意力与视频和动作专家集成进行机器人后训练。[WholeBodyWAM: Learning Whole-Body World Action Models with Scalable Motion Priors](https://arxiv.org/abs/2609.18197)
- **FAME**：力自适应 RL 框架，将站立策略条件化于学习到的潜在上下文（联合编码上半身关节构型和双手交互力），部署时交互力通过刚体逆动力学从关节扭矩和状态在线重建。150mm 容差下 38.9% 任务成功率。[FAME: Force-Adaptive RL for Expanding the Manipulation Envelope of a Full-Scale Humanoid](https://arxiv.org/abs/2603.08961)
- **TANGO**：首个用于语言条件下人形机器人在杂乱环境中穿行的全身视觉-语言导航框架，直接预测 29-DoF 关节空间动作，完全在仿真中训练后零样本部署到 Unitree G1。[TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model](https://arxiv.org/abs/2609.09158)
- **MASkillBlender**：去中心化多机器人全身协调的通用多智能体 RL 框架，在可复用的预训练单机器人技能上学习共享去中心化高层策略，仅需任务级奖励，无需任务特定运动参考。[MASkillBlender: Decentralized Whole-Body Coordination for Multi-Humanoid Loco-Manipulation via Skill Blending](https://arxiv.org/abs/2610.01102)

## 八、强化学习与策略优化

- **FERPO**：前向熵正则化策略优化，使用 critic 值进行策略改进而不对动作微分 critic，通过自归一化重要性采样估计前向-KL 目标拟合 actor。在 MuJoCo Playground 和 ManiSkill 上展现竞争性能和样本效率增益。[FERPO: Forward Entropy-Regularized Policy Optimization](https://arxiv.org/abs/2610.02198)
- **PARTS**：真实世界子任务 RL 框架，将训练集中在瓶颈子任务上，冻结预训练策略提供标称动作，agent 生成的选择器和成功验证器激活残差修正并提供局部结果奖励。双臂 YAM 上完整任务成功率从 32% 提升至 61%，Franka 上从 50% 提升至 95%。[From Pretraining to Proficiency: Real-World Subtask RL for Long-Horizon Manipulation with Minimal Human Intervention](https://arxiv.org/abs/2609.21788)
- **PReFlow**：结合基于 critic 的 proposal 选择和条件细化流的策略提取方法，在 50 个 OGBench 任务上在线微调后达最高聚合分数 91%。[Diffusion Policy Improvement with Proposal-Conditioned Refinement Flows](https://arxiv.org/abs/2609.36812)
- **OMAF**：在线多智能体 RL 框架，通过一步流模型结合表达性生成策略和高效一步动作生成，在 MPE 和 MAMuJoCo 的 10 个标准任务上比 baseline 最多高 3.4 倍回报和 10.5 倍样本效率。[Flowing Faster to Coordinate: One-Step Online Multi-Agent Flow Policies](https://arxiv.org/abs/2610.01882)

## 九、Benchmark 与评估

- **HumanoidToolBench**：18 任务人形工具使用 benchmark，跨越三种场景、三个执行级别和两种工具集模式，含 ToolBook 数据集（3.1K 仿真和真实 Unitree G1 演示）。七个策略仿真评估和三个真实机器人评估揭示工具选择与任务完成之间的显著差距。[HumanoidToolBench: Benchmarking Humanoid Tool Use from Selection to Mobile Execution](https://arxiv.org/abs/2610.02089)
- **Are Frontier VLM Agents Ready to Be Robot Generalists?**：Embodied Agent Arena，含 1,000 个案例，覆盖几何、空间推理、可供性、任务规划和操作。Astra 在精确估计和可用接触定位上优势最强，但完成协调目标导向动作仍是关键差距。[Are Frontier VLM Agents Ready to Be Robot Generalists? An Empirical Study with the Embodied Agent Arena](https://arxiv.org/abs/2610.00854)
- **DexHoldem**：已在灵巧操作部分介绍。
- **OpenMTB-Audit**：500 个合成 NSCLC 案例的分子肿瘤委员会安全评估 benchmark，识别出普遍的过度拒绝问题：所有 LLM 配置在 83.3-100% 的真实 Partially Supported 案例中未能保留该标签。[OpenMTB-Audit: Exposing Over-Refusal and Clinical Expert Perspectives in LLM-Based Molecular Tumor Board Safety Evaluation](https://arxiv.org/abs/2610.01497)

## 十、其他值得关注的方向

- **Screw Attention**：将刚体代数嵌入 Transformer 层，每个 token 是一个带位姿的 body，消息沿相对位姿传输。16,162 参数在 LIBERO-Spatial 上达 97.3%（无图像或语言），且在每链接坐标系约定变化下成功率不变。[Screw Attention: Rigid-Body Algebra Inside a Transformer](https://arxiv.org/abs/2610.00904)
- **World Motion Models (WMMs)**：通过稀疏 SE(3) 位姿轨迹捕捉动态 3D 世界的生成先验，统一关节物体、人体、手-物交互、分段刚体场景动力学、相机运动乃至机器人状态和动作，支持任意到任意的边缘条件化。[World Motion Models: Flexible Sequence Modeling of SE(3) Trajectories](https://arxiv.org/abs/2610.01742)
- **DeepJEPA**：将过渡深度视为内部测试时 scaling 轴，学习何时为每个候选和 rollout 步骤计算另一次循环更新。在五个视觉控制设置中平均每过渡仅需 1.00-1.26 次更新，额外计算集中在接触起始和持续物体交互处。[DeepJEPA: Scaling World Models from Within](https://arxiv.org/abs/2610.00368)
- **CF-JEPA**：将 JEPA 风格世界模型的潜在空间分解为可控和不可控子空间，在标称条件下性能可比，在干扰条件下是唯一不发生潜在崩溃的模型。[CF-JEPA: Improving Robustness of JEPA World Models via Controllability Factorization](https://arxiv.org/abs/2610.00727)
- **Recova**：agent 引导的失败恢复框架，在重建数字孪生中联合开发任务执行和恢复，通过真实世界经验验证和精炼。六个 LIBERO-Pro 设置和四个 MolmoSpaces 类别上分别达 78.8% 和 64.9% 平均成功率。真实机器人 DAgger 微调将平均成功率从 23.8% 提升至 77.5%，加入恢复技能后达 87.5%。[Recova: Agent-Guided Failure Recovery for Autonomous Robotic Manipulation](https://arxiv.org/abs/2610.01178)
- **TierCEM**：将严格约束优先级直接纳入交叉熵方法的精英选择，无需逐约束重要性权重，在 2D 导航和接触丰富推挤任务上验证。[Cross-entropy optimization with prioritized constraints](https://arxiv.org/abs/2610.01319)
- **Rewind-IL**：训练无关的在线保护框架，结合零样本失败检测器（TIDE）和状态重生机制，将机器人返回到语义验证的安全中间状态。[Rewind-IL: Online Failure Detection and State Respawning for Imitation Learning](https://arxiv.org/abs/2604.16683)
