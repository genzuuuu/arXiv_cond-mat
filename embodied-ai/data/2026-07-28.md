### Dexterous Manipulation & Multi-Stage Tasks
- **[Concurrent Prehensile and Nonprehensile Manipulation: A Practical Approach to Multi-Stage Dexterous Tasks](https://arxiv.org/abs/2603.11655)** - DexMulti: A sample-efficient approach for multi-stage dexterous tasks (e.g., Grasp + Pull). It decomposes demonstrations into object-centric skills and uses a retrieve-align-execute paradigm. Achieves 66% success across two hands and 1000+ real-world trials, outperforming diffusion policies by 2-3x.
- **[DexMulti / A Practical Approach to Multi-Stage Dexterous Tasks](https://arxiv.org/abs/2603.11655)** *Note: Duplicate paper with the same arXiv ID. See summary above.*
- **[One Hand Watches The Other: Dynamic Multi-Agent Cooperation for Sample-Efficient Bimanual Manipulation in Dynamic Environments](https://arxiv.org/abs/2607.22119)** - DynaMAC: A framework enabling multi-stream policies for bimanual manipulation without leader-follower relationships. It treats the opposite arm as a dynamic task parameter, enabling zero-shot generalization from static demos to dynamic environments, outperforming baselines by 35%.
- **[Try Once, Then Optimal: De-Redundified Procedure Memory for Cross-Episode Exploration Amortization](https://arxiv.org/abs/2607.23702)** - IOM: An object-centric memory that records a manipulation procedure from a single encounter (even failure) and reuses it upon seeing the same object again. Reduces manipulation operations by 16-30% without regressing success.
- **[Kinematic-Aware Interface for Data-Efficient Articulated Object Manipulation](https://arxiv.org/abs/2607.24493)** - KAI: Uses a structured intermediate representation capturing kinematic structure to provide a strong inductive bias. Achieves 82.9% success with half the demonstration data and generalizes to cluttered real-world scenes.

### Tactile Sensing & Visuo-Tactile Policies
- **[Pose-Aware Modeling to Mitigate Pose-Related Artifacts in Tactile Gloves](https://arxiv.org/abs/2607.22964)** - Introduces a glove-agnostic algorithmic framework that uses hand pose info to reduce pose-related artifacts in tactile gloves, lowering the minimum detectable force by 10-18%.
- **[N0-VTLA: Scaling Vision-Tactile-Language-Action Model with Latent Tactile Tokens](https://arxiv.org/abs/2607.23782)** - A foundation model for contact-rich manipulation. It uses large-scale visuo-tactile pretraining and an advantage-conditioned offline RL method (ALTER) to improve policies from deployment data, winning all nine real-robot tasks.
- **[N0-TWAM: Scaling Tactile-Native World-Action Model for Contact-Rich Manipulation](https://arxiv.org/abs/2607.23783)** - A world-action model that predicts future vision and contact. It uses a unified force-based tactile representation (NeoForce) and an asymmetric Mixture-of-Transformers architecture for real-time efficiency.
- **[FeelWorld: Visuo-Tactile World Model for Hierarchical Contact Prediction and Planning](https://arxiv.org/abs/2607.24267)** - A hierarchical visuo-tactile world model that predicts visual latents, contact state, and slip state. Uses a contact-gated attention mechanism and achieves 81.7% zero-shot planning success on contact-rich tasks.
- **[A Visuo-Tactile Data Collection System with Haptic Feedback for Coarse-to-Fine Imitation Learning](https://arxiv.org/abs/2605.08757)** - A data collection system using a direct-drive gripper with natural haptic feedback and temporal annotations from the operator, designed for coarse-to-fine imitation learning.
- **[Learning Touch-Augmented Vision-Language-Action Models from Future Visual Supervision](https://arxiv.org/abs/2607.24485)** - τ (Tau): Learns an action-conditioned spatiotemporal tactile representation from future visual supervision (JEPA-inspired) with no deployment overhead. Generalizes to unseen objects.

### Visuomotor & Action Models
- **[FLOW: PRISM: Polynomial Representations for Interaction-Structured Motor Control](https://arxiv.org/abs/2607.23473)** - PRISM: A policy representation that makes polynomial interactions among observable variables explicit. Improves performance in locomotion and contact-rich manipulation, yielding sensorless compliant behavior.
- **[WorldDiT: A Unified Diffusion Architecture for World and Action Modeling](https://arxiv.org/abs/2607.23909)** - A single diffusion transformer that generates action chunks and predicts future video frames. Achieves strong performance on LIBERO without a large pretrained VLM backbone.
- **[DeVA: Decoupled Video-Action Model with physical guidance for robot policy learning](https://arxiv.org/abs/2607.24159)** - Decouples video prediction and action prediction with multi-level feature transfer. Uses physically salient guidance (affordance/depth) for better generalization with limited data.
- **[Ordered Action Tokens for Visuomotor Policy Learning](https://arxiv.org/abs/2607.21670)** - OAT: A learned action tokenizer producing an ordered sequence of tokens where earlier tokens encode coarse control and later tokens refine detail. Offers an anytime tradeoff between inference cost and action fidelity.
- **[Emergent Compositional Skills in Mixture-of-Experts VLAs](https://arxiv.org/abs/2607.20771)** - Shows that a VLA trained with a MoE action head can emergently learn to decompose tasks into reusable primitives without explicit task decomposition.

### Sim-to-Real & Real2Sim
- **[A Replay-Constrained Simulation Framework for Personalization of Powered Knee-Ankle Prosthesis Controllers](https://arxiv.org/abs/2607.22858)** - A MuJoCo-based framework that replays recorded human kinematics for sim-to-real transfer of prosthetic controllers. Demonstrates strong predictive validity (Pearson r=0.96-0.997) with three participants.
- **[Real2Sim2Real for Vision-Language-Action Manipulation: An AMD ROCm-Based Pipeline](https://arxiv.org/abs/2607.22997)** - An end-to-end ROCm-accelerated pipeline for VLA manipulation. Includes a Real2Sim pipeline fusing 3D Gaussian Splatting with a physics engine.
- **[Sling2Sim2Real: One-Shot Elastic System Identification for Non-Destructive Slingshot Policy Learning](https://arxiv.org/abs/2607.23268)** - A one-shot Real2Sim2Real framework for elastic objects. Identifies elastic parameters from a single non-destructive interaction, enabling zero-shot sim-to-real transfer of a slingshot policy.
- **[Effective Parameters, Real Behavior: Renormalization for Robotics -- From Infinite Electron Mass to Sim-to-Real Gap](https://arxiv.org/abs/2607.24079)** - Proposes using effective, resolution-dependent parameters to absorb simulator omissions and reproduce real behavior, offering a complementary path across the sim-to-real gap.
- **[Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents](https://arxiv.org/abs/2607.19190)** - A framework using a VLM agent to convert a real-world recording of object-robot interaction into a simulatable episodic twin, spanning rigid, deformable, and humanoid domains.
- **[Can Context Bridge the Reality Gap? Sim-to-Real Transfer of Context-Aware Policies](https://arxiv.org/abs/2511.04249)** - Investigates how conditioning a policy on an estimate of dynamics parameters (context) improves sim-to-real transfer in a real-world pushing task.

### World Models & Planning
- **[WCM: World-Cognition Model for Generalizable Human-Robot Interaction](https://arxiv.org/abs/2607.22999)** - A human-centered agent with a human-in-the-loop teaching mode. Achieves a 73.8% success rate across nine real-world HRI tasks.
- **[LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments](https://arxiv.org/abs/2607.23969)** - Uses a Joint-Embedding Predictive Architecture (JEPA) to predict latent dynamics rather than pixel-level video. Achieves SOTA on LIBERO and zero-shot robustness to unseen environments.
- **[Action from Adjacent Set in Physical Space Outperforms the Best Prediction in World Models](https://arxiv.org/abs/2607.23602)** - Introduces ASAR, which selects action sequences based on density of similar proposals in the action space rather than solely on minimum predicted cost, significantly improving success in world model planning.
- **[NEO: NeRF It Once, Edit It Many Times for Continuous Object Manipulation](https://arxiv.org/abs/2607.24538)** - A framework for language-guided NeRF editing for manipulation, including object removal and pick-and-place, with a new benchmark for evaluation.

### General Robot Learning & Benchmarks
- **[The Curse of Precision: A Data Scaling Law for High-Precision Robotic Manipulation](https://arxiv.org/abs/2607.23108)** - Introduces a scaling law showing that required demonstrations grow super-exponentially as target precision approaches a system-specific limit `c`, which can be improved by better sensors or expert policies.
- **[ArmnetBench v0.1: Parallel Real-World Evaluation of Manipulation Policies on a Low-Cost Arm Farm](https://arxiv.org/abs/2607.24481)** - A benchmark run on a fleet of low-cost robot arms, comparing 7 policies across 12 tasks with 3,118 labeled episodes.
- **[Data Pyramid for Embodied Manipulation](https://arxiv.org/abs/2607.24744)** - A survey organizing the embodied data ecosystem into a "pyramid" of five sources (real-robot, UMI, egocentric/exocentric, simulation, vision-language) and analyzes how data composition relates to capabilities.

### Safe & Agile Locomotion & Flight
- **[Anticipatory Risk-Guided Reinforcement Learning for Safe Flight Through Dynamic Clutter](https://arxiv.org/abs/2607.23565)** - A framework for safe quadrotor navigation that uses privileged sim state to predict future collision risk. Achieves robust zero-shot sim-to-real transfer.
- **[BC-NMPC: Battery-Constrained NMPC with Propulsion Prediction and Replanning for High-Speed Flight](https://arxiv.org/abs/2607.23867)** - Integrates battery and propulsion models into NMPC to predict thrust loss, replanning trajectories to improve tracking RMSE and flight distance in drone racing.
- **[WARL: Wrench-Augmented Reinforcement Learning for Task-Agnostic Learning in Legged Robots](https://arxiv.org/abs/2607.24036)** - Introduces force/torque into the action space to expand exploration for legged robots. Uses a curriculum to phase out the wrench, enabling robust learning across diverse terrains.
- **[Learning Reusable Hybrid Motion Priors for Humanoid Locomotion from Motion Imitation](https://arxiv.org/abs/2607.24083)** - A three-stage pipeline to turn motion-imitation skills into a reusable hybrid motion prior for downstream tasks like velocity tracking. Deployed on a real Unitree G1 robot.

### Other Notable Papers
- **[Embodied GPT-5.1: Evidence of a World Model?](https://arxiv.org/abs/2607.23899)** - An exploratory study suggesting GPT-5.1 demonstrates emergent world-model-like behaviors (e.g., object permanence, reasoning about own movement) when controlling a physical robot without embodiment-specific training.
- **[The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents](https://arxiv.org/abs/2607.22520)** - Analyzes how adding procedural skills can cause "regressions" (tasks solved without skills, failed with skills). Finds gains are primarily from regressing less, not from more skill.
- **[A Note on the Motion Representation and Configuration Update in Time Stepping Schemes for the Constrained Rigid Body](https://arxiv.org/abs/2607.24317)** - A geometric analysis showing that SE(3) is the appropriate configuration space for numerically modeling constrained rigid bodies.
