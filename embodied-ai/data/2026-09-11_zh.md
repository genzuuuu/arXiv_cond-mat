# 今日 arXiv 机器人学与 AI 论文总结

## 一、具身智能与 VLA 模型

### 人类视频规模化预训练 VLA
- **HuRo**: 将异质人类视频机器人化为机器人对齐的观测和动作轨迹，构建约 63 万 episode 数据集，四个真实操作任务完成率从 51.5% 提升至 80.3%，OOD 场景从 34.9% 提升至 72.2%。[HuRo: Robotizing Human Videos for Scalable VLA Pretraining](https://arxiv.org/abs/2609.10706)

### 单步动作生成加速 VLA 推理
- **IMLE-VLA**: 用 cIMLE 训练的单步条件生成器替代扩散/流匹配动作头，推理频率提升 3.67 倍（55Hz vs 15Hz），LIBERO 平均成功率 98.0%，真实机器人加加速度降低 2.2-3.0 倍。[IMLE-VLA: Fast Single-Step Action Generation for Vision-Language-Action Policies](https://arxiv.org/abs/2609.10915)

### VLA 动作块时频几何建模
- **TFGCA**: 提出时频几何交叉注意力模块，用时频小波分解动作块并融合内积与楔积，可即插即用接入预训练 VLA。LIBERO +1.5，LIBERO-Plus +6.3，RoboTwin +28.5。[Time-Frequency Geometric Cross-Attention for Chunked Vision-Language-Action Models](https://arxiv.org/abs/2609.09925)

### VLA 微调中的视觉残差保持
- **FiberTune**: 针对动作等价状态下视觉结构坍塌问题，提出保持动作纤维视觉残差的训练目标，CALVIN ABC-to-D 提升 10.7 个百分点，SO-101 真机成功率从 72.7% 升至 78.1%。[FiberTune: Preserving Action-Fiber Visual Residuals in Vision-Language-Action Fine-Tuning](https://arxiv.org/abs/2606.08653)

### VLA 硬约束安全保障
- **ActSafeGuard**: 可微分、训练对齐的流匹配策略安全层，实现 100% 步级安全率，同时保持甚至提升任务成功率。[ActSafeGuard: Differentiable and Training-Aligned Constraint Enforcement for Flow-Matching Policies](https://arxiv.org/abs/2609.11697)

## 二、灵巧操作与多指抓取

### 手中操作：实时雅可比估计学习钢笔书写
- **DexPen**: 仅用笔记本电脑 CPU，约 18 秒初始化后即可在手中操作钢笔书写，无需仿真训练或预采集演示，亚毫米级精度（平均 0.6mm），在三种拟人手平台上验证。[Rapid Learning of Dexterous In-Hand Pen Writing through Real-Time Jacobian Estimation](https://arxiv.org/abs/2609.11775)

### 外骨骼共享实现一对一灵巧演示
- **SEED-UMI**: 人与机器人穿戴同一外骨骼，关节编码器成为物理共享测量，腕部相机同时观测。数据采集效率提升 3.0 倍，五项接触丰富任务平均成功率 70.0%。[SEED-UMI: Sharing the Exoskeleton between human and robot for onE-to-one Dexterous demonstration](https://arxiv.org/abs/2609.11753)

### 欠驱动多指手被动稳定性分析
- 提出新型三指差动弹簧滑块机构，建立准静态分析方法评估圆柱和球形抓取的稳定平衡构型。[Quasi-static analysis of passive stability in a novel underactuated multi-finger hand](https://arxiv.org/abs/2609.11579)

### 腱驱动绳索传输仿真
- **MuJoCable**: 在 MuJoCo 中加入降阶构型相关绳索传输，联合优化移动非圆面路由，Capstan 比率误差低于 0.5%，揭示摩擦驱动的负载增长和近端关节旋转重分布。[MuJoCable: Reduced-Order Surface-Routed Cable Transmission for Tendon-Driven Robots](https://arxiv.org/abs/2609.09612)

## 三、触觉感知与视触觉世界模型

### 视触觉世界模型用于提升任务
- **Compact Visuotactile World Model**: 65 万参数动作条件视触觉世界模型，将力动作效果 MAE 从 0.413N 降至 0.338N，模型辅助反馈将力预算成功率从 73.3% 提升至 93.3%。想象 RL 表现反而低于反应式 IQL。[Compact Visuotactile World Models for Lifting: Prediction, Reward Alignment, and Force Constraints](https://arxiv.org/abs/2609.09597)

### 触觉记忆与软腕机器人
- **TaMeSo-bot**: 集成软腕与触觉检索控制，MAT³ 模型联合建模动作、分布式触觉、力扭矩和本体感觉，通过掩码 token 预测学习时空表征，在多样 peg-in-hole 任务中优于基线。[Tactile Memory with Soft Robot: Robust Object Insertion via Masked Encoding and Soft Wrist](https://arxiv.org/abs/2601.19275)

## 四、视觉-运动策略与操作

### 障碍感知扩散策略
- **ObstaDiff**: 分解式扩散策略框架，提取目标-障碍物-背景结构化表征，在温室场景 366 次执行中平均成功率 75.41%，碰撞率 8.20%。[ObstaDiff: Generalizable Diffusion Policy Learning via Obstacle-aware Representations](https://arxiv.org/abs/2609.10918)

### 多智能体时序逻辑引导扩散策略
- **LTLDiff**: 结合有限线性时序逻辑规范学习与扩散策略，从自然语言指令学习 LTLf 公式，通过 AST 嵌入条件化数据收集和策略训练，改善多智能体协调操作成功率。[LTLDiff: Finite Linear Temporal Logic-Guided Data Generation and Diffusion Policies for Multi-agent Robotic Manipulation](https://arxiv.org/abs/2609.11043)

### 长时程操作中的 Agent 侧记忆
- **2AM**: 多模态 Agent 作为任务记忆唯一持有者，单一 RGB 无状态动作模型作为执行器。LIBERO-Mem 上平均完成率 76.3%，比最强基线提升 61.5 个百分点。[2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation](https://arxiv.org/abs/2609.11308)

### 记忆即计划的世界-动作建模
- **MaP-WAM**: 将记忆依赖的世界-动作建模分解为记忆锚定规划和计划条件执行，RMBench 成功率 83.3%，真实机器人 78.0%，执行器推理延迟近似恒定。[Memory as Plans: World-Action Modeling with Memory-Grounded Planning](https://arxiv.org/abs/2609.11561)

### 统一记忆-预测-动作模型
- **UniMPA**: 通过共享动作锚定转移接口解决转移歧义、预测-执行不匹配和经验-实现不匹配三个耦合问题。[UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling](https://arxiv.org/abs/2609.11875)

### 生成策略的双潜空间强化学习
- **DLSRL**: 同时预测初始噪声潜变量和动作表征潜变量，通过残差连接注入中间动作 token 隐藏状态，无需更新基策略即可加速在线适应。[Beyond Noise Steering: Dual-Latent Space Reinforcement Learning for Generative Robot Policy](https://arxiv.org/abs/2609.11270)

### 安全感知技能适应 RL
- **Dist-GPRL**: 基于高斯过程的技能参数化，顺序适稀疏轨迹通过点窗口，结合 HAP 安全子空间先验和动态距离场奖励，在动态物体操作任务中成功率更高、碰撞更少。[Safety-aware Skill Adaptation for Reinforcement Learning in Dynamic Environments](https://arxiv.org/abs/2609.11433)

### 虚拟模型控制实现稳健切割
- 用切换虚拟机制生成稳健节律性砍切运动，Franka 上五种蔬菜切割精度达亚毫米级（1-7mm 厚度），近每秒一刀，对刀具形状和砧板高度变化鲁棒。[Periodic robust robotic rock chop via virtual model control](https://arxiv.org/abs/2508.02604)

### 零样本动态绳索操作
- **Wiggle and Go!**: 两阶段框架，短暂安全 wiggle 动作预测绳索参数，条件化轨迹优化器实现零样本目标条件执行。3D 目标击打平均精度 3.55cm（基线 15.29cm）。[Wiggle and Go! System Identification for Zero-Shot Dynamic Rope Manipulation](https://arxiv.org/abs/2604.22102)

## 五、Sim-to-Real 与机器人学习

### 世界模型失败信号实时读取
- **FARM**: 仅训练 33,985 参数监督读出层于冻结 VLA-JEPA 预测状态上，七任务五折 AUROC 85.68/88.59，PIPER X、SO-101、Franka 真机迁移验证，CUDA 延迟仅 0.2256ms。[FARM: Reading Failure Signals from the Internal Predictive States of a Frozen Robotic World Model](https://arxiv.org/abs/2609.11445)

### 真实世界在线 RL 的 VLA 后训练
- **VLA-Precision**: 非对称协同引导算法 + 流式架构，九个高精度化学任务四类机器人平台平均成功率 98.3%，吞吐量提升 10.9 倍。[VLA-Precision: Asymmetric Co-Bootstrapping for Efficient Real-World Online RL of Vision-Language-Action Models](https://arxiv.org/abs/2609.04355)

### 操作策略要素诊断基准
- **EBench**: 26 个多样挑战性操作任务，5 个能力维度和 4 个泛化维度。π₀.₅ 测试成功率最高，π₀ 在灵巧固定基座和高精度任务领先，XVLA 和 InternVLA-A1 展现互补优势。[EBench: Elemental Diagnosis of Generalist Mobile Manipulation Policies](https://arxiv.org/abs/2606.18239)

## 七、多模态感知与导航

### 通用具身导航
- **LightNav-0**: 紧凑通用具身导航模型，通过双通道指向表达任务/场景/本体无关空间意图，残差 VQ 动作 tokenizer 映射到本体特定轨迹，10 个公开导航仿真设置 SOTA，真机零样本跨本体泛化。[LightNav-0: Eliciting VLM Spatial Intelligence for Generalist Embodied Navigation](https://arxiv.org/abs/2608.30935)

### 持续自适应感知盲人形运动
- **CAP**: 单阶段人形运动策略，感知世界模型编码器作为学习去噪器从损坏输入重建干净深度，Unitree G1 在间歇遮挡、传感器损坏和户外深度伪影下展示感知鲁棒运动。[CAP: Continuously Adaptive Perception-Blind Humanoid Locomotion via Learned Denoising](https://arxiv.org/abs/2609.11553)

### 对比专家混合地形适应
- **CMoE**: 单阶段 RL 框架集成对比学习优化专家激活分布，Unitree G1 穿越连续 20cm 台阶和 80cm 沟槽，超越现有方法极限。[CMoE: Contrastive Mixture of Experts for Motion Control and Terrain Adaptation of Humanoid Robots](https://arxiv.org/abs/2603.03067)

### 开放词汇 3D 物体检测的生成式场景合成
- **GIF**: 智能体框架生成交互式和功能性物体组合，CoGen 生成实例解耦网格，GPRM 在几何和物理引导下精化相对位姿，碰撞率降至 1% 以下。[GIF: Agentic Generation of Interactive and Functional Object Compositions for Robot Learning](https://arxiv.org/abs/2609.05927)

## 九、机器人基础模型与世界模型

### 自进化通用灵巧操作世界模型
- **Motus2**: 单一共享权重模型暴露三个控制接口（策略、模拟器、评估器），耦合形成闭环决策学习循环。从大规模单目自我中心数据到同步立体数据再到机器人域适应，集成触觉反馈，在仿生平台（立体视觉、双臂、双手、触觉）上实例化。[Motus2: A Self-Evolving General World Model for Dexterous Manipulation](https://arxiv.org/abs/2608.30237)

### 世界模型驱动的游戏地图生成
- **Valerant**: 无需训练，将预训练动作条件世界模型转化为 WAM，耦合预测视觉 rollout 与 SLAM 空间重建和探索驱动动作选择，从单张图像渐进构建持久 3D 游戏地图。[Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration](https://arxiv.org/abs/2609.09418)

### 语义地图补全实时化
- **FastMap**: 轻量两阶段框架，无查找 BitVAE 压缩语义地图为紧凑位 token，MAE 风格 transformer 单次前向重建，Gibson 34.10% mIoU，ObjectNav 83.8% 成功率。[FastMap: Real-Time Semantic Map Completion via Bitwise Masked Modeling](https://arxiv.org/abs/2506.07350)

### 操作策略验证器综述
- 综述约 150 个机器人策略验证器，沿可用性（verdict 成本、到达时机、密度）和可信度（高分对任务的指示程度）两个属性比较，发现可信度随可用性上升而下降——没有免费验证器。[No Free Checker: A Survey of Verifiers for Robot Policies](https://arxiv.org/abs/2609.09250)
