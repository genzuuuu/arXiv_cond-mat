## 一、灵巧手、抓取与手中操作

- **OpenDexGrasp**：开放词汇任务导向灵巧抓取，构建 OpenDexVerse 双源监督数据（自动合成 + 人手遥操作对齐），学习共享感知-动作隐空间，直接生成任务一致的抓取，无需显式 affordance→pose 两阶段。[OpenDexGrasp: Open-vocabulary Task-Oriented Dexterous Grasping](https://arxiv.org/abs/2609.18117)

- **TacBPM**：触觉条件的行为先验模型，用于手内重定向。将多尺度球面专家蒸馏为隐控制器，下游策略通过残差潜动作复用固定触觉先验，支持各向异性物体任意姿态迁移与 sim-to-real。[TacBPM: A Tactile-conditioned Behavior Prior Model for Dexterous Reorientation](https://arxiv.org/abs/2609.18174)

- **Primitive-Informed Sampling-Based MPC**：面向多指灵巧操作，用低维操作基元偏置采样分布，同时优化关节级残差；在 16-DoF Allegro 手上实现连续手内旋转，基元可跨物体尺寸迁移。[Primitive-Informed Sampling-Based MPC for Multi-Fingered Dexterous Manipulation](https://arxiv.org/abs/2609.14868)

- **Real-World RL with MPC Scaffolding**：用采样 MPC 为真实世界灵巧 RL 提供脚手架，软 Actor-Critic 从 MPC 经验与在线交互中学习，20 分钟在线学习后转速超 MPC 五倍，连续 1000 次旋转无掉落。[Real-World Reinforcement Learning with MPC Scaffolding for Dexterous Manipulation](https://arxiv.org/abs/2609.14878)

- **InterMASH**：统一的抓取几何表示，用球面固定锚点 + 低阶球谐编码手部几何、物体几何与接触，条件扩散 Transformer 联合生成手形与接触，支持跨手型联合训练与人手数据微调。[InterMASH: A Unified Geometric Representation for Grasp Synthesis](https://arxiv.org/abs/2609.18504)

- **Human-Centric Grasp State Assessment**：用 VLM 半自动生成监督 + 轻量抓取状态预测器，将人类对可变形物体的主观"抓得好不好"标准迁移到机器人，在线依时序触觉与抓取力自适应调整抓取力。[Human-Centric Grasp State Assessment: Toward Transferring Subjective Evaluation to Robots](https://arxiv.org/abs/2609.17540)

- **LUMO**：设计发光接触形貌，通过 LED + 柔性硅胶垫的光学响应实现整指接触位置观测，联合优化力学（低预载贴合、高负载限位）与光学（不同接触位置响应可分离），法向力 MAE 1.44 N。[LUMO: Designing Luminous Contact Morphology for Repeatable Whole-Finger Contact Observation](https://arxiv.org/abs/2609.18165)

## 二、触觉感知与力感知操作

- **TAO-Force**：力条件 VLA，提出 F-FiLM 把编码后的力反馈注入冻结 VLM 特征，并采用接触门控快慢控制（慢速位置分支 + 快速导纳分支）。[TAO-Force: Unifying Force-Aware Perception and Fast-Slow Control for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18497)

- **ForceDelta-VLA**：从冻结教师的力条件/无力条件双模式预测差中构造显式"力修正"目标，轻量策略用近期力历史与机器人状态调整参考动作，双臂/单臂九项接触密集任务平均成功率 82.2%。[ForceDelta-VLA: Distilling Force-Conditioned ActionCorrections for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18242)

- **TACO**：以触觉世界模型作为自校正器，遵循"识别—想象—标注"循环，联合生成视频与触觉序列，筛选运动学可行且触觉合理的修正动作，做迭代式策略后训练，任务得分 0.375→0.825。[TACO: TActile World Model as a Self-COrrector for Scalable Robot Policy Post-Training](https://arxiv.org/abs/2607.02840)

- **Learning Contact Dynamics through Touching**：动作条件图神经网络建模末端执行器与环境网格交互，自监督训练，反应力矩由逐顶点力场涌现；真实世界位置误差比辨识 MuJoCo 低 45%。[Learning Contact Dynamics through Touching: Action-conditional Graph Neural Networks for Robotic Peg Insertion](https://arxiv.org/abs/2509.12151)

- **EgoPHI**：从单目第一视角 RGB + 物体几何联合估计手与物体网格上的稠密接触图与 3D 力分布；构建基于物理仿真的逐顶点力监督增强管线，并录制真实物体交互数据验证 sim-to-real。[EgoPHI: Estimating 3D Hand-Object Contact and Force from Egocentric Vision](https://arxiv.org/abs/2608.13014)

## 三、VLA 模型与策略学习

- **Not All Layers Need Tuning**：在五种架构 VLA（OpenVLA-OFT、π₀、SmolVLA、DTP、Octo）上测量分区适应代价，发现外观偏移集中于视觉编码器、指令偏移于语言主干、新物体于视觉编码器+动作头；据此分配可变秩 LoRA 并冻结良好校准区，物理 xArm-7 上以 0.04% 可训练参数匹配全量微调。[Not All Layers Need Tuning: Diagnosing and Directing Adaptation in Vision-Language-Action Models](https://arxiv.org/abs/2609.18084)

- **A3P5 / DistAL**：DistAL 用嵌入空间距离作为奖励，构造信息量更高的价值函数与优势条件策略，在仿真与真机双臂灵巧任务上提升成功率。[DistAL: Distance-based Advantage Learning for VLA Fine-Tuning](https://arxiv.org/abs/2609.18392)

- **Real-Time EXPО-FT**：将慢速 VLA 动作生成与快速反应式"动作编辑"解耦，编辑策略依最新观测响应状态变化；Kinetix 10/10 环境最优，四项动态真机任务平均性能 42%→97%，在线数据不超过 10 分钟。[Reinforcement Learning for Real-Time Vision-Language-Action Policies](https://arxiv.org/abs/2609.18207)

- **M²Tok**：多头多码本离散动作 tokenizer，把头对齐到不同动作维度、各头独立码本，用码本组合大幅降低重建损失，RoboTwin/Simpler-Env 与三个零样本真机任务均提升。[M²Tok: Multi-head Multi-codebook Discrete Action Tokenization for Vision-Language-Action Models](https://arxiv.org/abs/2609.18259)

- **ActionPiece**：提出"物理秩一致性"（PRC）度量 tokenization 对动作相对关系的保真度，联合监督表示学习与量化，LIBERO 94.8%、未见 LIBERO-Plus 68.8%。[ActionPiece: Rethinking Action Tokenization for Autoregressive Vision-Language-Action Models](https://arxiv.org/abs/2609.18487)

- **One-Step Drifting Action Heads for GR00T N1.7**：把扩散 Transformer 动作头换成一步 drifting 动作头，动作头前向 45.3 ms→5.0 ms，但 LIBERO 成功率系统性下降，报告为速度-成功率权衡。[Technical Report: One-Step Drifting Action Heads for GR00T N1.7](https://arxiv.org/abs/2609.18108)

- **GeomVLA**：在机器人中心 3D 坐标系中统一场景、潜场景运动预测与动作生成，用 3D 场景轨迹去噪器产生运动 token 条件化 3D 流式动作去噪器，CALVIN SOTA。[GeomVLA: Unifying Scene, Motion, and Action in 3D](https://arxiv.org/abs/2609.13812)

- **Acting in Meters**：度量交互框架，物体级 ICT token 显式表示末端相对被操作物体的位姿轨迹，场景级 MAIF 用度量点云特征学习几何条件动作修正，LIBERO/RoboTwin2.0 与真机、OOD 均提升。[Acting in Meters: Learning Metric Interactions for Precise Robotic Manipulation](https://arxiv.org/abs/2609.18243)

- **Atomic Motion Coordinate (AMC)**：为每条臂定义 13 个由文本与正运动学 grounding 的带符号平移/旋转/保持原子，注入每个动作专家块，并由接触历史通过有界球面残差调制，实现语言可控与力响应。[Atomic Motion Coordinate for Language-Steerable and Force-Responsive Manipulation](https://arxiv.org/abs/2609.15012)

- **Decoupling Vision, Language, and Action (DEM)**：受控实验表明，微调 DINOv3 + 冻结 NeoBERT + MeanFlow 单步动作头的解耦策略，在 18 项仿真与 3 项真机任务上达到 VLM-backbone SOTA 相当成功率，推理频率快 8–17 倍、能耗低 6–15 倍。[Decoupling Vision, Language, and Action for Efficient Multi-Task Robot Policies](https://arxiv.org/abs/2609.18374)

- **UMI-Bridge**：以 UMI 为中间域，按"动作等价"而非像素相似对齐人手与机器人表征，用 UMI 动作监督锚定潜空间，冻结腕部教师与动力学模型来正则 VLA 后训练，真机 91.7% vs 73.3%。[UMI-Bridge: Action-Anchored Latent Alignment across Human and Robot Manipulation Data](https://arxiv.org/abs/2609.18232)

- **Knowing When to Stop**：发现动作专家中"动作-观测"交叉注意力随预测时域变长而熵升高并趋于平台，据此提出免训练截断机制，在 π₀.₅ 与 X-VLA 上改善自适应动作块长度。[Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs](https://arxiv.org/abs/2609.00908)

- **VLA-ULAP**：云 VLA 调用与约 7.4M 参数超轻量本地动作预测器交错执行，Jetson Orin Nano 上 19.9 ms/0.183 J（对比 GR00T 284.3 ms/50.55 J），减少 48.8–76.7% 的云调用。[VLA-ULAP: Interleaving Cloud VLA Calls with Ultra-Lightweight Local Action Prediction at the Edge](https://arxiv.org/abs/2609.18663)

- **rMuscle**：受肌肉记忆启发的 VLA 推理框架，用"上下文缓存"复用视觉 token 输出、"动作缓存"复用神经元激活模式，RTX 4090/Jetson Thor 上 1.29–1.42× 加速且保持成功率。[rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference](https://arxiv.org/abs/2609.19104)

- **RAF-VLA / FIVE-VLA / DiffAdapterVLA**：自动驾驶方向的 VLA 工作，分别用未来帧表征对齐、循环动作记忆、以及把轨迹 token 注入 VLM 后层的方式改善规划。[RAF-VLA](https://arxiv.org/abs/2609.17728)、[FIVE-VLA](https://arxiv.org/abs/2609.18623)、[DiffAdapterVLA](https://arxiv.org/abs/2609.15322)

## 四、世界模型、视频/数据生成与 Sim-to-Real

- **PointZero**：以"3D 点轨迹补全"为预训练目标学习可迁移 3D 动力学，无需机器人动作标签，贡献 290 万帧合成数据集（可变形/铰接/刚体），微调后在 PGND 与 6/7 仿真+真机操作任务上超过或持平基线。[PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics](https://arxiv.org/abs/2609.19142)

- **CSWAM**：在 FastWAM 上加入基于 V-JEPA 2.1 的因果语义专家，从稀疏历史学习语义状态变化与运动的未来演化，RoboTwin 2.0 Clean→Randomized 从 10.16%→45.18%，真机 OOD 平均提升 42.5 pp。[CSWAM: Better Causal Semantic Representations for Out-of-Distribution Generalization in World Action Models](https://arxiv.org/abs/2609.18462)

- **Function-Preserving Data Generation**：约束引导的网格变形 + 任务位姿与碰撞代理的物理一致迁移，实现零样本 real-to-sim-to-real，无需遥操作源轨迹与真机微调。[Function-Preserving Data Generation for Zero-Shot Real-to-Sim-to-Real Manipulation](https://arxiv.org/abs/2609.18293)

- **Agentic Real2Sim**：用视觉语言智能体把真实交互录像转成可仿真的"情景孪生"，涵盖刚体、可变形、人形运动三类场景，可用开源 VLM 后端驱动、成本远低于前沿模型，并支持策略微调与真机评测代理。[Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents](https://arxiv.org/abs/2607.19190)

- **DeformSmith**：从文本或单图分层智能体式生成可交互、物理可信的可变形资产，用共享物理 harness 逐步构建-测试-精修几何、物理模型、材质与机器人交互，视觉与物理合理性优于 PhysGen3D 等。[DeformSmith: Physics Harness-Guided Hierarchical Generation of Deformable Assets for Robot Manipulation](https://arxiv.org/abs/2609.18620)

- **EmboAlign**：用 VLM 从语言指令提取组合式约束，用于（1）约束引导的 VGM  rollout 筛选与（2）约束下的轨迹优化，六个真机任务成功率提升 43.3 pp，无需任务特定训练数据。[EmboAlign: Aligning Video Generation with Compositional Constraints for Zero-Shot Manipulation](https://arxiv.org/abs/2603.05757)

- **Dreaming the Sound of Contact**：用生成视频 + 生成音频（接触声响度）塑造有界时变期望力曲线，闭环力调节器跟踪该曲线执行，并在纯运动学基线失败的任务上成功，同时作为数据生成引擎。[Dreaming the Sound of Contact: Leveraging Video and Audio Generation for Zero-Shot Force-Aware Manipulation and Data Generation](https://arxiv.org/abs/2609.19137)

- **PACE**：以本体感觉为锚的跨模态预训练，通过预测本体状态转移来监督视觉与 F/T 时序表示，使光照、纹理、传感器偏置等静态域因素被抑制；四项接触密集装配平均真机成功率 93.3%，sim-to-real 仅降 2.7 pp。[Proprioception-Anchored Cross-Modal Pretraining for Zero-Shot Sim-to-Real Contact-Rich Assembly](https://arxiv.org/abs/2609.07534)

- **ForwardDLO**：面向无约束双臂可变形线性物体的循环潜动力学模型，预测基于观测绳态的逐段位移，无显式段-段操作因而批量候选评估廉价；真实绳运动开环预测误差比最强基线低 13%，仿真布线任务 30 Hz 下 98% 成功率。[ForwardDLO: Model-Based Bimanual Shape Matching of Unconstrained Deformable Linear Objects](https://arxiv.org/abs/2609.18455)

- **WeaveRL**：在数千并行仿真实例中 GPU 加速重建场景为 surfel 集合，使策略作用于传感器几何而非手工几何，配合几何 fabric；未见障碍下无碰撞完成率 35%→61%，并保持 sim-to-real。[WeaveRL: Weaving Reconstruction into Scene-Aware Fabrics for Perceptive Reinforcement Learning](https://arxiv.org/abs/2609.18685)

- **Adaptive-MHE**：在线采样式系统辨识（移动地平线估计）估计物体质量、摩擦等地形/物体参数，并与采样 MPC 耦合，仿真与硬件上持续优于基线、逼近具备真值参数的控制器。[Adaptive-MHE : A Sampling-Based Adaptive MPC for Legged Loco-Manipulation via Moving Horizon Estimation](https://arxiv.org/abs/2609.17832)

- **DetAug**：对自由空间数据集的"转运阶段"做障碍盲增广并记录增广参数为显式条件标签，推理时采样一批标签执行碰撞代价最低者；SafeLIBERO 上无碰撞成功率超次优方法 20 pp 以上。[DetAug: Obstacle-Blind Trajectory Augmentation for Zero-shot Obstacle Avoidance](https://arxiv.org/abs/2609.18395)

## 五、人形/四足全身控制与移动操作

- **WholeBodyWAM**：人形全身世界-动作模型，先在 4000+ 小时异构运动语料（人类视频、原生 3D 动作、异构人形平台）上预训练语言条件 Motion Expert，再通过非对称 MoT 注意力与 Video/Action Expert 集成；运动先验显著提升数据效率。[WholeBodyWAM: Learning Whole-Body World Action Models with Scalable Motion Priors](https://arxiv.org/abs/2609.18197)

- **Learning Holistic Whole-Body Loco-Manipulation**：RL 训练的全身控制器直接把 6-DoF 末端目标映射为双腿+机械臂协调动作，无需显式基座速度或步足指令；奖励门控平衡末端跟踪/行走/平衡，时序上下文估计器融合窗口 Transformer、GRU 与辅助动力学预测。[Learning Holistic Whole-Body Loco-Manipulation with a Bipedal Mobile Manipulator](https://arxiv.org/abs/2609.18930)

- **Learning Multi-Humanoid Pickup and Transport**：去中心化物体中心控制，每个人形在共享物体上分配局部附着区域，学习无夹爪双臂捏取实现搬运，单机策略已能非平凡迁移到协作场景，真机验证 sim-to-real。[Learning Multi-Humanoid Pickup and Transport via Decentralized Object-Centric Control](https://arxiv.org/abs/2609.17824)

- **KINO**：以运动关键帧作为 VLM 规划与 RL 控制之间的中间表示，VLM 从预定义关键帧库选帧并重定向到当前场景，关键帧条件全身策略生成关节动作；显著性关键帧采样把端到端成功率从 44% 提到 92%，Unitree G1 上验证。[KINO: A Keyframe Interface for VLM Planning and Whole-Body Control in Humanoid Loco-Manipulation](https://arxiv.org/abs/2609.18869)

- **PASSAGE**：感知条件规划-跟踪框架，用 VR+惯性动捕采集 100 小时、1500 场景的场景对齐人体运动，条件流匹配规划器生成短时参考、50 Hz 感知全身跟踪器执行；数据从 6h 扩到 100h 时无碰撞成功率 48.1%→68.9%，Jetson AGX Orin 全机载运行 50 个未见真实布局。[PASSAGE: Scaling Scene-Aligned Motion Learning for Perceptive Humanoid Traversal in Cluttered Environments](https://arxiv.org/abs/2609.18732)

- **LEAP**：不增广任务目标、仅靠任务压力让四足导航中涌现主动注视控制，把深度图整合为以自我为中心的信念图，成功率 92.7%（脚本化 74.2%、被动感知 34.5%）。[LEAP: Learning Emergent Active Perception for Quadruped Navigation](https://arxiv.org/abs/2609.17628)

- **RecMorph / Gated Residual Body-Hand Coordination**：前者用拓扑引导的空间循环架构实现跨肢体信息变换与广义形态控制，迁移到四平台四足并完成 40 次真机试验；后者用门控残差协调冻结的全身运动跟踪与灵巧手重定向模块，腕/指尖几何误差降低 39.2–56.3%。[RecMorph](https://arxiv.org/abs/2609.18359)、[Gated Residual Body-Hand Coordination for Whole-Body Humanoid Teleoperation](https://arxiv.org/abs/2609.18763)

- **Loco-Loco-RL**：用低成本 ToF 传感器提供紧凑 3D 局部地形表示，token 压缩的时序 Transformer 策略（自注意力 + 潜空间压缩 + 15 步滚动历史 + 交叉注意力）实现四足/人形地形行走的 sim-to-real。[Loco-Loco-RL: Low-Cost Terrain Mapping for Humanoid Locomotion with Reinforcement Learning](https://arxiv.org/abs/2609.19041)

- **Gimbal-Based Human Tracking**：云台相机 + 持续学习式行人重识别，主动调整视角保持目标在视野内，支持从行走到奔跑的实时跟踪。[Gimbal-Based Human Tracking for Companion Robots Using Continual Learning](https://arxiv.org/abs/2608.21388)

## 六、遥操作、数据采集与模仿学习

- **Project Kitchen / Game2Policy**：VR 游戏化第一视角数据采集平台，与具体机器人形态解耦；Game2Policy 从游戏轨迹提取接触点与子目标等形态无关 affordance 线索，预训练后再用少量真机演示联合微调，仿真 +10.0 pp、真机 +18.3 pp。[From Gameplay to Policy: Towards Scalable Robot Data Collection via Gamified Robot-Free Interaction](https://arxiv.org/abs/2609.18650)

- **Learning to Stack**：VR 数据采集管线（HTC Vive Pro 2 + Manus Quantum 手套 + OpenXR）为自定义 5-DoF 臂采集立方体堆叠演示，把演示采集与数据集构建解耦，可回放复用；30 分钟采集 200 条虚拟演示（对比真机 45 条）。[Learning to Stack: Cube-Stacking Imitation Learning from Virtual Reality Demonstrations](https://arxiv.org/abs/2609.19040)

- **Vision-Language Grounded Task-Context-Aware Imitation Learning**：面向机器人拆解，用语言提供任务上下文以缓解多有效目标与装配构型多样性，层级任务选择 + 任务上下文感知模仿学习，端到端成功率比扩散策略基线高 35 pp。[Vision-Language Grounded Task-Context-Aware Imitation Learning for Robotic Disassembly](https://arxiv.org/abs/2609.17714)

- **Learning While Deploying (LWD)**：机队级离线到在线 RL 持续后训练框架，用分布式隐式价值学习（DIVL）+ 通过伴随匹配的 Q 学习（QAM）在流式 VLA 动作生成器上做策略提取；16 台双臂机器人、8 项真机任务，单一通用策略平均成功率 95%。[Learning While Deploying: Fleet-Scale Reinforcement Learning for Generalist Robot Policies](https://arxiv.org/abs/2605.00416)

- **FIERCE**：以统一的任务自适应"进展-失败"评估器为核心，共享观测-语言表示，进度头 + 动作条件潜预测器 + 因果序列头估计失败；提供进度塑形与失败风险惩罚，无需目标域仿真器或人工密集奖励，仅保留紧凑专家策略。[FIERCE: From Generalist Robot Policies to Fast Specialists via Progress-Failure Feedback](https://arxiv.org/abs/2609.18651)

- **Missing Bridges (AALT)**：主动模仿学习，请求能最大化"起终点连通性"期望增益的演示，把已有演示组织成潜枢纽状态拓扑，识别高价值桥接演示；UR5e 72 任务从 42/72 → 72/72（仅用 3 条、5 个转移）。[Missing Bridges: Composition-Aware Active Imitation Learning](https://arxiv.org/abs/2609.18004)

- **LieSpline-DP**：在 SE(3) 上直接生成末端轨迹的李群 B 样条扩散策略，相邻计划共享边界控制位姿保证跨块 C² 连续；倒液与挂钩任务成功率 100%，DP 基线仅 10%/30%。[LieSpline-DP: Lie-Group B-Spline Diffusion Policy for Smooth Robot Manipulation](https://arxiv.org/abs/2609.15162)

- **The Latent That Never Was**：复跑 ACT 的 CVAE 消融实验，发现原论文报告的 35%→2% 成功率骤降未复现；采样潜变量在各非零权重下几乎无重建收益，推理时 ACT 本就置零未用，跳过编码器反而提升训练吞吐。[The Latent That Never Was: A Forensic Re-run of the CVAE Ablation in Action Chunking Transformers](https://arxiv.org/abs/2609.16745)

- **WetRobo**：面向生物实验室的可复现机器人套件（单臂 + 培养箱/试剂瓶/培养皿 + 代码 + 遥操作演示 + AGENTS.md），编码智能体观察本地实验室并自行编写执行程序；在 Lab X 与 Lab Y 均完成开盖任务，而在 Lab X 演示上微调的 VLA 迁移到 Lab Y 失败。[WetRobo: A Reproducible Robot Kit for Coding Agents in Biological Laboratories](https://arxiv.org/abs/2609.18435)

- **Hardware-Free Robotics Laboratories in Mixed Reality**：MR-Robotics LAB 把 MATLAB 生成的机器人轨迹按真实尺度在 Meta Quest 3 中回放，浏览器端做单位归一化与版本化 JSON 发布，Unity 端在物理场景中位置控制复现并联支持碰撞检测与末端抓取。[Hardware-Free Robotics Laboratories in Mixed Reality](https://arxiv.org/abs/2609.18434)

## 七、主动感知与视触觉/视运动策略

- **ActiveScale**：通过模型（历史视频 + 显式相机位姿监督）、数据（1000 小时第一视角与机器人数据的人-机 mid-training）、硬件（单操作者遥操作的 AMP 平台）三方面协同推进主动感知。[ActiveScale: Scaling Active Perception for Robots across Model, Data, and Hardware](https://arxiv.org/abs/2609.18514)

- **I-Perceive**：语言条件主动感知基础模型，给定查询图、上下文图与自然语言指令预测 6D 相机位姿；双通路（视觉-语言语义 grounding + 多视图 3D 几何推理）经多层语义融合连接，支持闭环主动感知。[I-Perceive: A Foundation Model for Vision-Language Active Perception](https://arxiv.org/abs/2603.00600)

- **FIERCE / HAP**：HAP 以手部运动为驱动预测第一视角头部 6-DoF 运动，从手部运动与物体几何推断目标置信度，构建动态预测性目标中心非模态遮挡图（P-TAOG），并发起 Bottle 第一视角 RGB-D 数据集。[HAP: A Hand-Driven Active Perception Framework for Egocentric Head Motion Prediction](https://arxiv.org/abs/2609.18548)

- **Active perception for robotic harvesting**：面向地中海温室簇生番茄，用 AgriSEE 下一最佳视角规划器采点云，经 SOR、区域生长分割、DBSCAN 恢复遮挡果实、3D 位姿估计；精度 >90%、召回 82.8%、mIoU 80.7%、质心 RMSE 4.2 mm。[Active perception for robotic harvesting: 3D reconstruction and localisation of tomatoes hidden within clusters in a Mediterranean greenhouse](https://arxiv.org/abs/2609.18738)

- **CLASP**：面向鲜食蓝莓的簇级选择性采摘机器人，软主动滚带夹爪（SARB-Gripper）用两条柔性带包裹果簇滚动摘取成熟果，闭环力调节控制在未成熟脱落阈值以下；现场 23/25 簇自主抓取成功，单元成本约 3326 美元。[CLASP: A Cluster-Level Autonomous Selective Picking Robot with a Soft Rolling-Band Gripper for Fresh-Market Blueberry Harvesting](https://arxiv.org/abs/2609.18051)

- **Language-Guided Grasping under Partial Observation**：腿足移动机械臂的语言引导抓取，开放词汇检测 + 可提示分割得到物体中心 RGB-D 点云，经深度补偿与点云补全后以碰撞/间隙/可达/接近约束选 6-DoF 抓取；杂乱桌面 9/10 成功（基线 3/10）。[Language-Guided Grasping under Partial Observation for Mobile Manipulation in Field Inspection and Maintenance](https://arxiv.org/abs/2603.07866)

## 八、操作任务的失败检测、恢复与安全

- **Causal-History Test-Time Scaling**：针对自回归世界-动作模型，把失败恢复重构为"因果历史上的测试时扩展"，三阶段：进展感知恢复触发、历史前缀恢复（检索匹配当前物理状态的历史锚点并重建因果 KV 状态）、假设验证。[Causal-History Test-Time Scaling for Failure Recovery in Autoregressive World-Action Models](https://arxiv.org/abs/2609.18016)

- **RAFAIL**：面向操作执行失败检测，用 VLM 离线标注成功演示的任务进度与关系重要性，学习基于点云的关系表示，运行时只用关系特定的 OOD 检测器；无需失败数据，三个真机任务平衡准确率 73.4%。[RAFAIL: Relationship-Aware Failure Detection for Robotic Manipulation](https://arxiv.org/abs/2609.18324)

- **Calibrated Probabilistic Obstruction Reasoning (CPOR-Grasp)**：校准并融合 VLM、深度与非模态掩码线索估计遮挡概率，在有效遮挡图上做边缘化，保留高概率图并给出被丢弃概率质量的全变差界，实现可认证决策与自适应停止；Gemini Robotics 骨干上校准误差 0.1416→0.0185。[Calibrated Probabilistic Obstruction Reasoning with Vision-Language Models for Grasping in Clutter](https://arxiv.org/abs/2609.18718)

- **CaSCo**：级联感知的软碰撞运动规划，VLM/LM 给物体分配语义风险，物理仿真预测候选动作后果，搜索使"被机器人直接或经级联碰撞间接位移的物体"总语义风险最小。[CaSCo: Cascade-Aware Soft-Collision Motion Planning](https://arxiv.org/abs/2609.18910)

- **ElastiQP**：面向约束机器人控制的"始终可行"QP 求解器，对每个不等式约束做精确 l1 松弛而等式（动力学）保持硬约束，通过解析折叠松弛变量保持系统尺寸不变；不可行问题上比最佳替代求解器快至多 40 倍返回可用解。[ElastiQP: An Always-Feasible QP Solver for Constrained Robot Control](https://arxiv.org/abs/2609.19080)

- **Timely Activation of Safety Filters**：指出基于 HJ 可达性的最小限制安全滤波器在离散时间执行下会"跳入"不安全 BRT，提出单步扩展 BRT 作为激活条件。[Timely Activation of Safety Filters via One-Step Reachability Expansion](https://arxiv.org/abs/2609.17904)

- **REVERSAL-BENCH**：用连续可逆性参数 ρ 与 reset oracle 衡量"无重置 RL 悬崖"，发现随 ρ 增大无重置智能体被系统性地吸收到不可恢复状态，而分幕智能体稳定学习；并评估在不可逆失败前干预的安全盾。[REVERSAL-BENCH: A Reversibility Axis and Reset Oracle for Measuring the Reset-Free RL Cliff](https://arxiv.org/abs/2609.17745)

- **RoboVAD**：机器人臂操作视频的大规模跨域异常检测基准，含未见任务与未见异常类型；所有方法在最难设置下微平均帧级 AUC 均低于 70%。[RoboVAD: A Large Cross-Domain Evaluation Benchmark for Anomaly Detection in Robotic Arm Manipulation Videos](https://arxiv.org/abs/2609.17843)

## 九、任务与运动规划、导航

- **Asymptotically Optimal Multi-Robot TAMP**：刻画多机器人 TAMP 中"不同任务转移涉及不同机器人子集"的转移结构，给出全局渐近最优的充分条件，并设计演化个体路图 + 隐式张量积搜索的高效算法。[Asymptotically Optimal Multi-Robot Task and Motion Planning](https://arxiv.org/abs/2609.18813)

- **HINT-Plan**：用 VLM 从第三人称图像预测高层人类意图并转为目标状态，结合分层场景图求解人-机联合任务规划，仿真成功率 69.71%，超基线最多 35.29 pp。[HINT-Plan: Human Intention-Aware Robot Task Planning in Context-Rich Environments using Vision Language Models](https://arxiv.org/abs/2609.17771)

- **Map2Route / Grounding2Route**：1000 集、40 场景的组合式语言 grounding 语义地图路径规划基准，含关系/比较/嵌套描述、必过区、必避约束与五类软偏好；Grounding2Route 用可执行"代码即 grounding"+验证引导修复+范围感知规划。[Map2Route: Benchmarking Compositional Language-Grounded Route Planning over Semantic Maps](https://arxiv.org/abs/2609.17910)

- **DynoFluxBench**：动态环境中运动动力学时空规划器的基准框架，配套提出 ST-Db-RRT、ST-GBRRT 与 KIST 三种规划器并分析其概率完备性。[DynoFluxBench: Benchmarking Kinodynamic Space-Time Planners in Dynamic Environments](https://arxiv.org/abs/2609.18549)

- **GroundingVLN**：以视觉 grounding 作为推理与动作之间的共享接口，先用 grounding 推理（把任务相关视觉证据锚定到精确图像位置），再通过 grounding 行动（预测进度对齐的像素目标交由几何规划器转为基元动作）；R2R-CE 69.9% SR，训练数据仅为最强基线的 0.9%。[GroundingVLN: Reasoning and Acting with Grounding for Vision-Language Navigation](https://arxiv.org/abs/2609.18581)

- **WAVE-Go**：轮腿机器人世界模型导航，把世界-动作预测与可中断指令执行分离，执行器自适应选择动作前缀并在观测失效时取消待执行指令，用条件风险形式化前缀选择。[WAVE-Go: World-Model Navigation with Adaptive Execution for Wheel-Legged Robots](https://arxiv.org/abs/2609.18193)

- **VCTP**：车辆条件化地形规划，在 8 个朝向下评估共享的高程与表面 ID 层，由车身几何约束可行性与载荷轮接触决定表面代价与预测俯仰/横滚。[VCTP: Vehicle-Conditioned Terrain Planning for Off-Road Navigation](https://arxiv.org/abs/2609.17834)

- **OmniPlanner**：跨空中、地面、水下机器人的统一探索与巡检规划框架，模块化整合体素探索、视点巡检与目标到达行为，配合平台抽象层捕捉形态相关的感知、可通行性与运动约束。[OmniPlanner: Universal Exploration and Inspection Path Planning Across Robot Morphologies](https://arxiv.org/abs/2603.04284)

- **DM³-Nav / HarnessVLN**：去中心化多智能体多模态多物体语义导航（无中心协调、无全局地图聚合、ad-hoc 成对通信）；HarnessVLN 则是零样本免训练的统一导航框架，通过共享 Agent Harness 协调感知、记忆与执行工具，在 R2R/RxR/HM3D-v2/HM3D-OVON 上超越此前免训练 SOTA。[DM³-Nav](https://arxiv.org/abs/2604.22014)、[HarnessVLN](https://arxiv.org/abs/2609.15195)

- **Visual Cue Guided Video Planning (CueNav)**：生成式视频导航框架，用 BEV 地图传达全局任务上下文、并在第一视角观测中保留部分机器人本体以
