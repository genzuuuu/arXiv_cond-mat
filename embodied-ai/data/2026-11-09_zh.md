## 一、视觉-语言-动作模型（VLA）与策略学习

- **Meituan-Robotics-0**：面向桌面操作的大一统 VLA（1.47 亿 VLM 样本 + 15,060 小时真机轨迹、12 种本体），三阶段训练（离散动作 token 预训练 → flow matching 跨本体中训 → 真机后训练）；提出 Rollback 为 CFG-DAgger 提供正负监督，统一末端执行器接口 + 异步 action chunk 合并；RoboTwin 2.0 达 93.6%。[Meituan-Robotics-0: A Vision-Language-Action Foundation Model for Desktop Manipulation](https://arxiv.org/abs/2611.08577)
- **VICTR**：用 progress-informed 上下文检索增强 VLA 的 in-context learning，基于 In-Context Value Function Estimator 估计任务进度以选演示片段；真实域外任务成功率 6.2% → 23.8%。[VICTR: Value-Informed In-Context Learning for Vision-Language-Action Models](https://arxiv.org/abs/2611.08698)
- **ActPrune**：训练后免训练视觉 token 剪枝，利用上一步 action chunk 的几何先验在视觉编码器前决定保留/剪枝区域（第三人称沿末端投影轨迹 + 腕部相机补偿运动差异）；最高 1.61× 加速、59.5% FLOPs 降低，成功率几乎无损。[ActPrune: Action-Grounded Visual Token Pruning for Efficient Vision-Language-Action Models](https://arxiv.org/abs/2611.08827)
- **VLA Handover**：机器人端跑小 VLA，仅在预测可能失败时切换到服务器大 VLA；LIBERO 上成功率 +11–22 个点，请求量减少 49–77%。[VLA Handover: Failure-Prediction-Based Switching from On-Robot to Server VLA Models](https://arxiv.org/abs/2611.08987)
- **PRISM**：将技能表示为参数级低秩 primitive 库，推理时用 VLM 条件路由按 chunk 组合；RoboCasa365 原子技能 56.43%、长程组合 20.00%（π0.5-LoRA 为 17.86%/17.50%），并在 AgileX PIPER 真机验证。[PRISM: Primitive Routing via In-context Skill Mixing for Retentive VLA Adaptation](https://arxiv.org/abs/2611.08917)
- **ODEAction**：用 ODE 演化动作场替代 action chunk 预测，消除 chunk 边界不连续；作为 action head 可插拔，LIBERO/EBench/RoboTwin/真机均优于 chunking 基线，精细操作提升明显。[ODEAction: From Predicting Chunks to Evolving Actions](https://arxiv.org/abs/2611.09672)
- **SURE**：面向 VLA 数据高效训练的时空不确定性建模，转置卷积概率动作解码器 + Soft-DTW 对齐监督；仅 10% 演示数据或 20% 训练步数即可匹配基线。[SURE: Spatiotemporal Uncertainty Representation for Efficient Vision-Language-Action Learning](https://arxiv.org/abs/2611.09684)
- **CompVLA**：联合预测运动与刚度矩阵的可变柔顺 VLA，增加 Compliance Expert 输出时变刚度/虚拟位移，经几何阻抗控制执行；接触密集任务成功率最高。[CompVLA: A Variable Compliance Vision-Language-Action Model for Contact-rich Manipulation](https://arxiv.org/abs/2609.23614)
- **STAR**：免训练推理方法，对后期层残差更新做 EMA 以继承物体感知方向，并用本体感知调节混合强度；平均成功率 +4.0 个点。[STAR: Steering Action Representations for Proprioception for VLA Inference](https://arxiv.org/abs/2610.41009)
- **OpenVLA 目标表征定位与编辑**：LIBERO-Goal 上否定指令几乎无效（79% 仍执行被禁任务）；activation patching 表明首个 action 主要依赖第 12 层前的指令 token、16 层后的最后 prompt token；第 8 层指令 token 加固定 steering 向量可改写 12/18 条轨迹。[Localizing and Editing the Goal Representation of a Vision-Language-Action Model](https://arxiv.org/abs/2611.08895)
- **实时执行与自回归策略**：论证自回归策略通过调整 tokenization horizon + 约束解码也能满足实时延迟，并在任务完成速度上优于同步推理。[Real-Time Execution with Autoregressive Policies](https://arxiv.org/abs/2606.13355)
- **MATE / LAG-Fusion**：面向异步多速率扩散策略的 latency-aware 引导融合，推导相对动作表示下的去噪变量重基规则，组合低频视觉策略与高频力策略。[MATE: Asynchronous Multi-Rate Diffusion Policy Composition](https://arxiv.org/abs/2607.17257)
- **Augmentron**：几何感知的多视角视觉增强流水线，渲染时间与视角一致的场景变化；替换一半真实数据后三类操作任务的分布外泛化均提升。[Augmentron: Scalable Multi-View Visual Augmentation for Robot Learning](https://arxiv.org/abs/2611.09145)

## 二、灵巧手、多指抓取与手中操作

- **DexHOT**：将灵巧操作形式化为“手-物构型迁移”，从合成可行构型对学习可复用的关系条件迁移 primitive，无需人类参考动作，闭环跟踪构型子目标组合长程行为；DexHOTBench 120 物体上 80.5%/69.4%（见过/未见），真手 200 次迁移成功率 61.5%。[DexHOT: Learning Hand-Object Configuration Transfer for Dexterous Manipulation](https://arxiv.org/abs/2611.05119)
- **RevoSim**：针对 BrainCo Revo3 灵巧手的可扩展多模态触觉仿真器，联合建模 285 个压阻 taxel 与 5 个视触觉指尖，同步生成压力/深度/RGB/标记位移；单张 RTX 5090 支持 4096 并行环境，纯仿真训练手中操作与抓取策略。[RevoSim: Scalable Multimodal Tactile Simulation for Dexterous Manipulation](https://arxiv.org/abs/2611.08939)
- **NoContactNoWorries**：用 RGB-D 视觉 + 本体感知推断二值接触状态作为伪触觉信号，支撑手中物体重定向 RL，并泛化到新物体；仿真与真机均验证。[NoContactNoWorries: Estimating Contact through Vision and Proprioception for In-Hand Dexterous Manipulation](https://arxiv.org/abs/2606.24450)
- **Grasp-TAGS**：将 PPO critic 蒸馏为轻量抓取效用网络，在接触前即按目标排序候选抓取；大物体重排成功率 89.84%（最佳单抓取策略 79.87%）。[Grasp-TAGS: Task-Aware Grasp Selection via Critic Distillation for Prehensile Loco-Manipulation](https://arxiv.org/abs/2611.09864)
- **HaNDF**：物体条件神经手部距离场，在黎曼几何框架下将可行手部关节表示为零水平集，可用于姿态精化、遮挡重建与物理合理操作合成。[HaNDF: Object-Conditioned Geometric Neural Hand Distance Fields](https://arxiv.org/abs/2611.08578)
- **BLaFA**：语言指令 → 3D 功能可供性 → 灵巧抓取，知识引导语言解析为语义六元组，3DGS 层级语义 + 三角功能点定位，再映射为腕部位姿与指关节/力指令；面向工具使用的功能抓取。[BLaFA: Bridging Language to 3D Functional Affordances for Dexterous Robotic Grasping in Tool Use](https://arxiv.org/abs/2604.08410)
- **抓取可行性预测器审计**：提出 planner-verified 反事实测试——固定抓取姿态、在接近走廊插入障碍并让规划器重标标签；8 个预测器 CF-pair AUROC 从 0.92–0.996 跌至 0.47–0.504，说明高准确率未必用到了规划器所检查的碰撞几何。[Auditing Grasp Feasibility Predictors with Planner-Verified Counterfactuals](https://arxiv.org/abs/2611.09130)

## 三、触觉感知与多模态触觉

- **MDF++**：视触觉 world-action model，端到端学习多感官潜在表示（而非冻结重建预训练编码器），多任务学习利用跨模态相关性避免特征塌缩；真实螺栓拧紧/螺母装配等接触密集任务上比冻结表示 WAM 提升最多 50%。[MDF++: Visuo-Tactile World Action Model with End-to-end Representation Learning](https://arxiv.org/abs/2611.09293)
- **时间域优化的交叉点阻性阵列读出**：面向高密度触觉传感，用时间域观测模型拟合完整波形而非仅频谱幅度；16×16 阵列仿真中读出误差均值降 20%，1000 次试验均值/标准差降 24.6%/77.6%。[Robust Readout of Cross-Point Resistive Arrays via Time-Domain Optimization](https://arxiv.org/abs/2611.09059)
- **光电软吸盘猕猴桃抓取力感知**：双组分猕猴桃专用软吸盘，通过光学信号估计交互力，留出果实上 R²=0.968、MAE=0.138 N；并探索软/硬二分类。[Mechanical Interaction Sensing for Robotic Kiwifruit Handling with an Optoelectronic Soft Suction Cup](https://arxiv.org/abs/2611.09468)

## 四、遥操作、人类干预学习与人演示数据

- **Q-OIL**：分析真人干预数据发现——人倾向于在进度停滞时介入且纠正动作常非最优；据此提出基于进度的干预模型，并在 RL 中对干预转移加乐观奖励、软引导探索，强调解耦 critic 以防奖励回传至干预前状态；仿真与真机成功率提升 10–50%，并改进两个双臂任务上的预训练 VLA。[Q-OIL: Optimistic Exploration in Learning from Human Interventions](https://arxiv.org/abs/2611.08576)
- **DexTeleop-0**：双臂灵巧遥操作 + 力感知，用指尖反馈的实时优化回路在人类跟踪指令上叠加机器人侧接触修正（接触刚度近似 + 运动学雅可比、逐接触力跟踪、软预测接触矩正则、有界关节残差）；仿真回放 Ball Assembly 91%、Stir in Cup 62%。[DexTeleop-0: Force-Aware Bimanual Dexterous Teleoperation with Ego-Centric Perception towards Shared Autonomy](https://arxiv.org/abs/2606.23431)
- **HOC2R**：从人类视频提取手-物接触轨迹用于机器人运动迁移，冻结 DINOv3 + SAM 2.1 特征 + 学习头；30 任务基准上接触计数准确率 58.1%→71.4%，定位距离 19.81→10.46 px；六段机器人评估中 3 个任务成功。[HOC2R: Hand-Object Contact Trajectories for Human-to-Robot Motion Transfer](https://arxiv.org/abs/2611.08920)
- **ToolDex**：面向创造性物理工具使用的大规模自我-外部视角（ego-exo）人类演示数据集，同步 1 个自我视角 + 8 个外部视角，含手/工具/目标物体及形变交互标注；并建立工具使用推理、稀疏视角 3D/4D 重建、机器人策略学习三类基准。[ToolDex: An Ego-Exo Human Demonstration Dataset for Creative Physical Tool Use](https://arxiv.org/abs/2611.09036)
- **VOMMI**：便携式移动操作演示采集与学习框架，仅用 RGB 即可，离线轨迹重建（R2-VO 稀疏几何锚点精化）+ 在线视觉-运动条件 token；仅用便携演示后训练的策略基座速度误差比用机器人演示训练低 18.2%，三任务平均成功率超 OpenPI 0.5 8.3 个点。[VOMMI: Collecting and Leveraging Portable Demonstrations for Mobile Manipulation](https://arxiv.org/abs/2610.08220)
- **Sketch-MoMa**：用手绘草图遥操作移动机械臂，VLM 解读叠加在观测图上的草图，推断形状与低层任务用于识别与运动规划；14 人用户实验验证可用性。[Sketch-MoMa: Teleoperation for Mobile Manipulator via Interpretation of Hand-Drawn Sketches](https://arxiv.org/abs/2412.19153)
- **可穿戴触觉 I/O 接口**：36 通道电触觉阵列 + 电容触摸传感，在同一身体参考坐标系内配准刺激与感知位置；建立人在回路校准框架学习个性化感知模型，实现遥操作中的个性化触觉渲染、视觉-触觉替代等。[A wearable input/output interface learns personalized models of haptic perception](https://arxiv.org/abs/2611.09708)

## 五、仿真、Sim-to-Real 与接触建模

- **Lodos-v2**：GPU 并行刚体仿真框架，通过在原对偶形式下顺序求解一簇凸松弛 + 外层近端最小化，求解精确摩擦接触问题（消除 lift-off、法向人工柔顺与切向蠕变），并把接触组重参数化扩展到完整仿真器约束（关节限位、焊接）。[Lodos-v2: An Efficient Primal Formulation of the Exact Frictional Contact Problem](https://arxiv.org/abs/2611.08868)
- **Lodos**：为精细网格网格碰撞场景从头设计的轻量仿真器，新的大/窄相碰撞检测与接触动力学例程，物理保真度与成熟仿真器相当，吞吐量约高一个数量级。[Lodos: A Lightweight Simulator Designed for Contact-Rich Interactions with Detailed Meshes](https://arxiv.org/abs/2611.08872)
- **ForPC**：人形机器人推购物车的力感知全身控制，两阶段 RL（负载/上身姿态变化的运动先验 + 从机载观测推断力/状态隐变量驱动残差策略），无需外部力传感器与人类演示；仿真中推车速度 RMSE 降 68.2%，仅仿真训练即零微调迁移到 Unitree G1，推动 30 kg 载荷 0.5 m/s。[ForPC: Force-Aware Whole-Body Control for Precise Humanoid Cart Pushing](https://arxiv.org/abs/2611.08664)
- **SUGARv2**：通过可复用任务模板合成机器人与物体协同运动参考，降低示教与逐任务奖励设计成本；先训特权教师再经蒸馏 + RL 得视觉策略，配合视觉域随机化；五类人形 loco-manipulation 任务仿真平均成功率 91.0%，真机完成全身操作迁移。[SUGARv2: Learning Diverse Visual Humanoid Loco-Manipulation Skills from Synthesized Interaction References](https://arxiv.org/abs/2611.09266)
- **STRIDE**：仅用机载 IMU 的人形运动学习，奖励跟踪指令加速度而非基座速度；离线 RL（XQC）+ 高增益关节位置控制 + 左右对称增强，Unitree G1/Booster T1 上 14 分钟样本内学会行走，训练摔倒减少 81%。[STRIDE: Learning Humanoid Locomotion in Minutes with Acceleration-Based Rewards](https://arxiv.org/abs/2611.08857)
- **DKWBC**：解耦运动跟踪与平衡的人形全身控制，逆动力学前馈 + 关节 PD 提供跟踪力矩，残差策略只学平衡修正；单一平衡策略跨运动数据集泛化，支持地面支撑、挂载负载与物理交互。[DKWBC: Decoupling Motion Tracking and Balancing for Humanoid Whole-Body Control](https://arxiv.org/abs/2611.09605)
- **EGT**：以“车辆-控制器对执行候选路径并满足跟踪/进度要求的概率”定义可通行性，用潜空间 flow matching 预测闭环轨迹分布；未见地形 650 次试验中安全路径误拒降至 2.2%，不安全误接受 7.7%，规划器集成后导航失败率降 24–44 个点，并零样本迁移到户外真机。[EGT: Execution-Grounded Traversability through Learned Closed-Loop Trajectory Distributions](https://arxiv.org/abs/2611.09270)
- **VLD**：解耦感知与策略学习的图像目标导航框架，用约 3000 小时视频自监督训练距离预测器，RL 策略在仿真中用 GeoNoise 模拟预测器视角/重叠相关误差训练，部署时零样本使用；真机 88% 成功。[VLD: Visual Learned Distance as an Interface for Reinforcement Learning Navigation](https://arxiv.org/abs/2512.07976)
- **Autonomous PIV**：把 PIV 相机位姿规划建模为序列决策，RL 智能体控制 6-DoF 机械臂定位/取景/分辨水洞中的水翼尾流，仅通过速度场与不确定度观测；光子真实感仿真训练后零样本迁移真机，约半次全扫描时间完成且误差更低。[Autonomous Particle Image Velocimetry Using Zero-Shot Sim-to-Real Reinforcement Learning](https://arxiv.org/abs/2611.09679)
- **ForPC、SUGARv2 之外的真机迁移**还见 **真实制造产线部署**（可变形线缆插入 + 焊接，<20 分钟真机数据/任务，连续 5 小时 10 分产 108 台电机、99.4% 质检通过率）。[Learning-augmented robotic automation for real-world manufacturing](https://arxiv.org/abs/2604.22235)

## 六、World / Action Model 与世界模型驱动的操作

- **Open-HumanWAM**：首个完全开放的自中心人类视频预训练配方，规模扩至 5 万小时（Open-HumanWAM-50K 语料，含手部运动与自然语言标注）；发现预训练时长与下游成功率的对数线性 scaling law；HumanWAM-Vanilla 后训练后 RoboTwin 2.0 Clean2Clean 92.08%，HumanWAM-Goal（视觉目标条件）达 92.70%/Clean2Random 84.60%，并在真机展现涌现的具身 in-context learning。[Open-HumanWAM: An Open Recipe for Scaling Human and Robot Experience for Embodied Foundation Models](https://arxiv.org/abs/2611.06817)
- **FRED**：通过自蒸馏 + 时序上下文改进 WAM 单步去噪所得未来视频表示质量，从噪声预测未来表示、以真实未来观测表示为目标；长程与零样本环境泛化提升显著，人类视频到机器人技能迁移达 50.0%（最佳对比 WAM 19.4%）。[Self-Distilling Future Video Representations for World Action Models](https://arxiv.org/abs/2610.30320)
- **WorldBridge**：分离视频专家与动作专家、经结构化注意力与联合 flow matching 训练，研究视频泛化与动作泛化的互补作用；RoboTwin 2.0 全数据 96.23%、clean→random 80.9%，RoboCasa GR1 TableTop 82.8%，DOMINO L1 57.6%。[WorldBridge: Bridging Video and Action for Task Generalization in World Action Models](https://arxiv.org/abs/2610.40748)
- **LeWAM / Diffusion-Steering MPC**：在无解码器的 JEPA 潜空间上端到端训练双向 Transformer 做前向/逆向动力学与策略预测；线性探针读状态优于重建式 WAM 且同样忽略视觉干扰；MPC 在策略头噪声空间规划优于直接采样原始动作。[Diffusion-Steering-Based MPC with a JEPA World Action Model](https://arxiv.org/abs/2610.12407)
- **CLAW**：从无动作视频中端到端联合学习潜动作表示与扩散世界模型，用对抗式潜正则防止潜变量编码未来观测；支持从观测模仿学习与目标导向规划。[CLAW: Continuous Latent Action World Models via Adversarial Regularization](https://arxiv.org/abs/2606.04130)

## 七、推理/测试时约束下的操作策略

- **CS-Pi**：推理时施加演示中未出现的约束（如避障），提出 draw-project-renoise 采样器——对每个 draw 投影到最近安全动作、按投影距离回加噪声、再跑未修改策略直至安全；兼顾 projection 的效率与 rejection 的合理性，货架抓放 81% 安全成功率、真机 Franka 55%（纯投影 55%/40%）。[CS-Pi: Constraint-Satisfying Flow Policy Sampling](https://arxiv.org/abs/2611.08654)
- **Horizon-Coupled Obstacle Guidance**：针对预训练相对动作扩散策略的推理时避障引导，将累积相对动作展开为工作空间轨迹、用 SDF 评估障碍交互，并把每个障碍响应传播到所有贡献动作增量；七类障碍场景 105/140 无碰撞成功（绝对动作逐点引导仅 8/140）。[Horizon-Coupled Obstacle Guidance for Relative-Action Diffusion Policies](https://arxiv.org/abs/2611.09340)
- **HiMEM**：面向 3D 场景 VLA 的海马体启发记忆机制——情景记忆巩固为紧凑语义记忆、冗余情景记忆剪枝、灵活组合多记忆；π0 在 LIBERO 上从 91.88% 提升至 98.20%。[HiMEM: Hippocampus-Inspired Memory Consolidation, Pruning, and Composition for Vision-Language-Action Models in 3D Scenes](https://arxiv.org/abs/2611.09355)
- **任务条件化可操作空间信念基准**：提出 “Seeing What Matters” 基准（860 冻结评估用例、>11.5 万评估回合），衡量视角选择是否获取当前指令真正需要的证据；参考流水线 98.8%/98.9%，七个 VLM 仅 26–43%。[Seeing What Matters: Benchmarking Task-Conditioned Actionable Spatial Belief for Manipulation](https://arxiv.org/abs/2611.09794)
- **CLOI**：非抓取操作的闭环物体知情控制，分解为物体级长程位姿规划与机器人级动作规划，用 MPPI 求解并以 ADMM 在物体位姿上达成共识；xArm6 平面推物任务仿真 +35%、真机 +43%。[Closed-Loop Object-Informed Control for Non-Prehensile Robot Manipulation](https://arxiv.org/abs/2605.30778)
- **Tangram 多智能体装配**：把每个零件视为智能体、学习共享策略，GNN 表示零件/目标位姿/空间关系并预测平移与角速度，per-agent PPO + 集中式 graph critic；仿真并发装配、真机顺序执行。[It Takes Two to Tangram: Multi-Agent Object Centric Reinforcement Learning for Assembly](https://arxiv.org/abs/2611.08814)

## 八、Agentic 操作与通用智能体系统

- **A2-MEAS / A2-WLA**：以“代码作为扩展接口”的具身多智能体框架，学习式纠正代码融合纠正语言、空间证据、执行历史与动作提议；BEHAVIOR 2026 公开 100 任务 Q-score 0.6411、成功率 45.40%，RoboTwin 2.0 95.05%，12 个真机任务 57.92%（π0.5 26.67%），长程手冲咖啡失败后恢复率从 14%→94%。[Toward the Era of Agentic Embodied Intelligence](https://arxiv.org/abs/2611.09124)
- **Agentic Manipulation Policies (AMP1)**：让通用 AI 模型直接指挥机械臂并随任务推进调整动作，同一 harness 跨单臂/双臂/移动操作；RoboLab-120 零样本 85.6%（领先 VLA 49.2%、WAM 42.9%），108 次真机试验成功 104 次，失败率相对强 VLA/WAM 基线降 20×/15×；加持久记忆后在 RoboDojo 双臂任务失败率再降 4.6×。[On Agentic Manipulation Policies](https://arxiv.org/abs/2611.09892)
- **Agentic Robotics 受控研究**：9 个操作任务、631 种实验配置、2.8 万 coding agent rollout，系统变化模型能力、技能先验、反馈结构与课程；结论是瓶颈常不在信息获取，而在把信息转成正确的策略更新（失败归因、空间几何推理、选择性重构代码）。[A Controlled Study of Models, Skills, Feedback, and Curriculum in Agentic Robotics](https://arxiv.org/abs/2611.09030)
- **Flex-RSI**：评测前沿智能体在固定预算下的递归自我改进（vision 与机器人任务），区分“改进任务解”与“改进 harness 本身”。[Flex-RSI: Benchmarking Recursive Self-Improvement of Frontier Agents](https://arxiv.org/abs/2611.08946)
- **Computer-Use Agents Are Embodied Generalists**：主张将具身任务表述为与数字软件交互，同一 CUA 设计通过换软件在四个 ECCV workshop 竞赛获第 1/2/3/6 名。[Computer-Use Agents Are Embodied Generalists](https://arxiv.org/abs/2611.09847)
- **Can LLMs Debug Robots by Editing Their Weights?**：用 GPT-6 Astra 在权重空间修复 π0.5 的词汇指令接地，仅编辑 65 行 token embedding，765 条留出改写成功率 86.3%→92.0%；证据支持“精确词汇修复”而非获得新能力。[Can LLMs Debug Robots by Editing Their Weights?](https://arxiv.org/abs/2611.09376)
