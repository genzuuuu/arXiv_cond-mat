# 今日 arXiv 机器人学与人工智能相关论文总结

## 一、具身智能与 VLA 模型

**1. 世界模型与行动模型 (WAM)**

- [Selective Cross-View Consistency for World Action Models](https://arxiv.org/abs/2608.21402)：提出 SCVC，仅在视图不变坐标上施加一致性约束，避免损伤视图特有内容。在 LIBERO-Plus 相机轨迹上，对训练范围外的视角提升了12.2个点的闭环成功率。
- [Inferring Action from Future Latent State for Robotic Manipulation](https://arxiv.org/abs/2608.22067)：提出 DELE-w0.5，从紧凑的未来潜状态推断动作，而非预测逐帧视频。在480次真实机器人实验中，相比最强基线成功率提升47.5个百分点。
- [GeoWAM: Visual Geometry World Action Models for Autonomous Driving](https://arxiv.org/abs/2608.23486)：用点云几何替代像素作为世界模型的预测空间，在开放和闭环评估中均优于基于图像的世界模型。
- [TacWAM: Anchor-Guided World Action Model with Mechanics-Aware Tactical Prediction](https://arxiv.org/abs/2607.28391)：将触觉预测（力、形变、滑动）融入世界行动模型，平均成功率比最强基线高37.5个百分点，覆盖脆弱抓取、持续接触和手中动态操作。
- [LD4WAM: Learning Latent Dynamics from Human Videos](https://arxiv.org/abs/2608.22403)：从人类视频学习与运动对齐的潜动力学，用混合Transformer架构实现跨本体视觉-动作泛化。
- [Where World Models Break: Natural-Input Failure Discovery](https://arxiv.org/abs/2608.22421)：提出 BasinLens 发现世界模型在罕见条件下的灾难性预测失败。
- [WAM-OPD: On-Policy Distillation for World Action Models](https://arxiv.org/abs/2608.22364)：通过在线策略蒸馏修复视频优先WAM学生模型，在 RoboTwin 2.0 上 HANDOVER MIC 从0提升至58.3%成功率。
- [Beyond Instance Slots: Semantically Rich World Models](https://arxiv.org/abs/2608.22294)：提出 SR-WM，围绕五类功能角色（夹爪、目标、目标状态、关系、阶段）构建语义丰富的世界模型用于物理交互规划。
- [τ0-WM: A Unified Video-Action World Model](https://arxiv.org/abs/2606.01027)：统一视频-动作世界模型，集成策略学习、视频预测和动作评估。用约27,300小时真实机器人数据训练。
- [ForeTime-VLA: Causal Future-Token Distillation](https://arxiv.org/abs/2608.20735)：从冻结的Fast-WAM教师蒸馏未来感知表示，在传送带动态抓取中比 pi0.5 多完成44次抓取。

**2. 视觉-语言-动作模型 (VLA) 改进**

- [AECNav: Active Evidence Consolidation for Efficient Zero-Shot Open-Vocabulary Object Navigation](https://arxiv.org/abs/2608.10817)：无训练管线，通过证据门控感知和簇级对数几率信念，在HM3D-v2上达到84.7%成功率。
- [CounterAlign: Counterfactual Supervision for Vision-Language-Action Models](https://arxiv.org/abs/2608.21740)：通过指令重标注合成反事实样本，无需额外数据收集即提供密集纠错信号。在 LIBERO-PRO 和真实机器人上均优于基线。
- [Pointing-VLA: Typed Spatial Grounding Interfaces](https://arxiv.org/abs/2608.23138)：用类型化隐藏状态空间读出替代文本坐标，在 Bridge/WidowX 上平均72.9%成功率，推理速度快6.7倍以上。
- [UniMem: Unifying Multimodal Memory and Control for VLA](https://arxiv.org/abs/2608.22869)：统一记忆与控制，在模拟中93.4% vs 68.2%，硬件上80.0% vs 43.5%。
- [Mamba-based Selective State Space Modeling Improves SmolVLA](https://arxiv.org/abs/2608.21407)：用Mamba替代因果自注意力，执行50步动作时比Transformer基线高7.8%，参数减少24%。
- [CloudEdgeVLA: Latency-Tolerant Cloud-Edge Collaborative VLA](https://arxiv.org/abs/2608.00569)：云边协同策略，在40步随机延迟下仍保持63.8-78.0%成功率。
- [Guardian: Detecting Robotic Planning and Execution Errors with VLMs](https://arxiv.org/abs/2512.01946)：自动生成多样失败数据（GuardianFail-36k），训练多视角推理VLM用于规划与执行验证。
- [Ludi₀.₁: An Agentic System for Socially Intelligent Robots](https://arxiv.org/abs/2608.22035)：融合交互语音、多模态推理、记忆与学习操作的社会智能机器人系统。
- [Think Only When Needed: Prompt-Authority Control for VLA](https://arxiv.org/abs/2608.23224)：提示权限控制接口，物理臂成功率从52.7%提升至78.7%。
- [Robust Bimanual VLA via Modality Masking](https://arxiv.org/abs/2608.22419)：M3训练时随机屏蔽模态通道，双手机器人任务成功率提升21.7%。
- [Latent Reward Steering for Reasoning LLMs](https://arxiv.org/abs/2606.00726)：隐藏奖励引导，隐式促进推理LLM的认知行为。
- [Learning While Deploying: Fleet-Scale RL for VLA](https://arxiv.org/abs/2605.00416)：车队级离线到在线强化学习，16台双臂机器人上达到95%平均成功率。

## 二、灵巧操作与触觉感知

- [Force/Torque-Based Kinematic Adaptation for Robotic Manipulation](https://arxiv.org/abs/2608.21592)：仅用关节角度和腕部力/力矩传感器在线估计未知工具运动学，推导可证明稳定的自适应律，插销-孔实验验证。
- [GhostTac: Manipulating Tactile Sensors without Physical Contact](https://arxiv.org/abs/2608.20817)：首次发现可通过电磁干扰无接触操纵触觉传感器，在多样化灵巧手上验证，威胁触觉抓取、滑觉检测等任务。
- [An Interpretable Deep Learning Framework for Material Perception from Multisensory Tactile Data](https://arxiv.org/abs/2608.21894)：深度学习方法将触觉信号映射到材料感知，热感线索最为关键。
- [TacWAM](https://arxiv.org/abs/2607.28391)（见上）：机械感知触觉世界行动模型。

## 三、遥操作与全身控制

- [Safety-Critical Bilateral Teleoperation for Omnidirectional Aerial Manipulation](https://arxiv.org/abs/2608.21735)：基于控制屏障函数的层级安全滤波器，实现无力传感器触觉反馈的空中操作遥操作。
- [TONAV: Task-Oriented Navigation and Action-Velocity Chunk Learning](https://arxiv.org/abs/2608.22296)：四足移动操纵统一框架，位置-速度耦合遥操作+动作-速度块学习。
- [GigaBrain-WBC-0.5: A Behavior World Model for Whole-Body Control](https://arxiv.org/abs/2608.18234)：首个行为世界模型用于人形全身控制，地形交互成功率4.3倍于最强基线。
- [Athena-WBC: Capability-Aligned Policy Experts for Long-Tail Humanoid WBC](https://arxiv.org/abs/2607.04837)：能力对齐策略专家，解决长尾人形全身控制。
- [Whole-Body Bilateral Teleoperation with Multi-Stage Object Parameter Estimation](https://arxiv.org/abs/2508.09846)：轮式人形全身遥操作，多阶段物体惯性参数估计（视觉+VLMs+分层采样）。
- [RPL: Learning Robust Humanoid Perceptive Locomotion](https://arxiv.org/abs/2602.03002)：两阶段训练框架，深度相机感知，在20°斜坡、不同阶梯和踏脚石上稳健行走。
- [DreamMimic: Learning Visuomotor Whole-Body Loco-Manipulation via World Model](https://arxiv.org/abs/2608.22278)：通过世界模型辅助蒸馏，将特权教师策略迁移到视觉人形控制器。

## 四、sim-to-real 与仿真

- [Enhancing Sim2Real Transfer for Torque-Controlled Robots](https://arxiv.org/abs/2608.22629)：Real2Sim2Real管线，用遗传算法辨识动力学参数后训练TQC-RL策略，平滑迁移到真实Franka Panda。
- [Physics Filtering Favors the Generalization of Robot Learning](https://arxiv.org/abs/2608.22701)：PhyFilter轻量模型无关模块，用物理学滤波校正学习残差，在四足、无人机、空中机械臂上提升泛化。
- [Betting for Sim-to-Real Performance Certificates](https://arxiv.org/abs/2608.21572)：利用大规模仿真结果下注，给出随时有效的性能证书，证书宽度收窄51.6%。
- [MADR: MPC-guided Adversarial DeepReach](https://arxiv.org/abs/2510.18845)：用MPC引导的双人零和微分博弈值函数近似。
- [Model-Free Adaptive Parameter Tuning for Multi-Robot Warehouse Operations](https://arxiv.org/abs/2608.21533)：用极值搜索控制自适应调节仓库多机器人规划参数，吞吐量提升5-8.4%。

## 五、抓取与操作

- [UNCLE-Grasp: Uncertainty-Aware Grasping of Leaf-Occluded Strawberries](https://arxiv.org/abs/2601.14492)：通过蒙特卡洛dropout生成多种形状补全，聚合力闭合评分进行风险感知的抓取/放弃决策。
- [Vision Guided Target Conditioned Control for Autonomous Excavation](https://arxiv.org/abs/2608.21778)：图像对齐目标掩码作为视觉空间指令，掩码条件化 Action Chunking Transformer 输出操纵杆命令。
- [Diffusion Policies for Robotic Assembly under Fabrication Uncertainty](https://arxiv.org/abs/2511.17774)：在工业建筑机器人上部署扩散策略，最严公差下75%平均成功率。
- [Safety-Critical Bilateral Teleoperation](https://arxiv.org/abs/2608.21735)（见上）用于空中操纵。
- [GCS-Bridging: Restoring Connectivity for GCS Motion Planning](https://arxiv.org/abs/2608.22326)：通过无碰撞点路径和凸区域膨胀恢复断开的凸集连接，在Franka平台上验证。

## 六、自主导航与路径规划

- [ODG-NoMaD: Overhead-Camera Direction-Guided NoMaD](https://arxiv.org/abs/2608.21395)：用顶部深度相机引导NoMaD探索方向，残差距离比无引导探索降低一个数量级。
- [Social Graph Mamba: Forecasting Pedestrian Movements](https://arxiv.org/abs/2608.21411)：用选择性状态空间模型替代二次复杂度注意力，社交三元组分解+社区感知模块。
- [RiskWorld: Object-Centric Latent World Modeling for Driving Risk Identification](https://arxiv.org/abs/2608.21414)：物体为中心的潜世界模型，RiskBench上F1=63.0%，最低误报率2.1%。
- [Active Interaction-Aware MPPI via Ego-Conditioned Generative Predictions](https://arxiv.org/abs/2608.21400)：自我条件生成预测模型结合MPPI，实现主动交互感知驾驶。
- [MomADv2: Reliable Temporal Memory for End-to-End Autonomous Driving](https://arxiv.org/abs/2608.23405)：选择性状态空间规划记忆查询+流匹配轨迹残差精化，碰撞率降低15.6%。
