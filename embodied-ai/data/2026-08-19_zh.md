# 今日机器人学与人工智能论文摘要

## 一、灵巧操作与手中物体操作

**[ReTouch: Empowering Contact-Rich Dexterous Manipulation with Online-Refined Tactile Prediction](https://arxiv.org/abs/2608.01824)**
- 提出 ReTouch，一种视觉-语言-动作模型（VLA），通过在线细化的触觉预测实现接触丰富的灵巧操作。利用 Tactile-Patch Encoder 保留手指身份和局部接触结构，并通过高频动作模块联合预测未来触觉状态和动作块，在 XHand–UR7e 平台上 7 项任务中平均成功率比最强基线高 18.4 个百分点（标准条件）和 23.8 个百分点（挑战条件）。

**[Physics-Informed Sliding-Window Particle Filtering for Tactile-Only In-Hand 6-DoF Object Pose Refinement](https://arxiv.org/abs/2608.17601)**
- 面向静态和短准静态手中操作场景，提出物理信息粒子滤波方法，利用全手触觉测量进行 6-DoF 物体姿态细化。结合滑动窗口对数似然融合和多模态保持重采样，在 Allegro Hand V5 实验中归一化 ADD-S 优于触觉几何、粒子滤波和学习基线。

## 二、灵巧抓取与操作策略

**[Robust Brachiation on a Life-Sized Dual-Arm Robot Using Waypoint-Guided Reinforcement Learning](https://arxiv.org/abs/2608.17320)**
- 提出航点引导强化学习（WGRL）框架，通过稀疏指定末端执行器轨迹航点引导灵长类摆荡动作学习，无需模仿学习数据。在仿真和真实生命尺寸双臂机器人上验证了鲁棒性，包括失败恢复行为。

**[Iterative Grasp Pose Refinement: A Deep Reinforcement Learning Approach for 2D Vision](https://arxiv.org/abs/2608.17628)**
- 提出基于深度 Q 网络（DQN）和关键点物体表征的抓取姿态迭代细化框架，在 Dex-Net 数据集 300 个物体上实现几何方法无法抓取物体的 100% 成功率，并在 Delta 并联机器人上验证了 sim-to-real 迁移。

## 三、视觉-运动策略与 VLA 模型

**[FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated Experiences](https://arxiv.org/abs/2608.17027)**
- 提出端到端 sim-to-real 流水线，结合行为克隆和 Flow-GRPO 强化学习训练人形机器人视觉移动操作策略。在 150,000+ 场景上训练，单物体到达-抓取策略在真实 Unitree G1 上未见场景零样本成功率达 73.3%。

**[VLCP: Vision Language Control Policy Closed-Loop Code Replanning for Robot Manipulation](https://arxiv.org/abs/2608.16978)**
- 保持 VLM 冻结，将其输出的 Python 控制函数作为策略，并在情节内每 K 步从多视角 RGB、本体感知和状态增量重新观察场景，重写控制代码。在 57 任务 MuJoCo/RoboVerse 基准上达到 35.1% 成功率（单次查询基线仅 3.5%），失败抓取的恢复率达 27.3%。

**[UniReflex: Plug-and-Play Force Control for Pretrained Generative Policies via Fast-Slow Reflex](https://arxiv.org/abs/2608.17432)**
- 提出即插即用框架，为冻结的生成式策略配备可变阻抗控制，通过拦截动作头的深层潜表征驱动快速反射网络实现接触调节。双手机器人实验显著提高接触稳定性，评估骨干上每步后向延迟较联合训练降低 25-66 倍。

**[EATR-Stereo: Embodiment-Aware Routing of Paired Stereo Evidence for Humanoid Vision-Language-Action Control](https://arxiv.org/abs/2608.17453)**
- 提出具身感知的孪生立体证据路由框架，保留主视图 token，构建主视图对齐的跨视角辅助 token。在 33-DoF 真实人形机器人上实现 60.0% 全任务成功率、100% 抓取成功率和 80% 阶段成功率。

**[PRISM: Precision and contact-rich Real-world Industrial Skill dataset with Multimodal sensing](https://arxiv.org/abs/2608.17962)**
- 发布大规模多模态工业操作数据集，涵盖 25+ 操作任务（电子元件插拔、传送带分拣等），包含 5,000+ 轨迹（45 小时），同步多视角 RGB-D、力/力矩、触觉和机器人状态测量。

## 四、Sim-to-Real 与策略优化

**[Prism-GRPO: Faster VLA Policy Optimization via Splitting Same-outcome Groups](https://arxiv.org/abs/2608.17423)**
- 提出 Prism-GRPO 方法，用加权轨迹级执行质量分数增强二元结果奖励，将同结果组拆分。在四个 RoboTwin 任务上以匹配的推出预算提高成功率和质量，达到目标成功率所需推出减少 56%。

**[Efficient Dynamic Shielding for Parametric Safety Specifications](https://arxiv.org/abs/2505.22104)**
- 提出参数化安全规范的动态屏蔽机制，离线设计针对安全参数集，运行时自适应调整。比暴力在线重计算快 5 倍。

## 五、操作任务规划与推理

**[PDDL-ART: Autonomous Symbolic Abstraction From Demonstration For Long-Horizon Robotic Manipulation Using Vision-Language Models](https://arxiv.org/abs/2608.17146)**
- 基于 VLM 的框架，从单个专家演示、自然语言任务描述和高层动作名称库自动生成 PDDL 领域和问题描述。多阶段校正流水线在引擎维护和家庭领域平均成功率达 93.3%（基线 VLM 规划器为 78.3%）。

**[Teach and Grow: An Agent-Centered Architecture for General Robot Learning](https://arxiv.org/abs/2608.17209)**
- 提出以智能体为中心的通用机器人学习架构，将少量成功演示转化为可复用的技能块，在 LIBERO 基准上达到 SOTA 性能，新任务获取无需特定任务策略重训练。

**[ORPA: Online Residual Policy Adaptation for Robot Manipulation Control with Human Feedback](https://arxiv.org/abs/2608.17323)**
- 提出在线残差策略适应框架，用轻量级反馈条件模块预测关节空间的残差调整，无需修改底层策略参数即可运行时纠正 ACT 等策略。在 ALOHA 平台精密操作任务中提高成功率和扰动恢复能力。

## 六、安全与评估基准

**[MANIGUARD: A Benchmark and Data Suite for Specification-Grounded Safety Evaluation and Improvement of Robotic Manipulation](https://arxiv.org/abs/2608.17386)**
- 提出规范基础的机器人操作安全评估框架，包含 200 个基础任务、1,000 个锁定场景和 8,000 条安全标注演示。发现 6-21% 的成功 rollout 违反安全规范，强调安全评估必须独立于任务成功。

**[LIBERO-VIFO: Benchmarking the Capability and Safety of Visual Cue Following in Vision-Language-Action Models](https://arxiv.org/abs/2608.17600)**
- 引入 LIBERO-VIFO 基准，评估 VLA 模型的视觉提示跟随能力与安全性，定义八个视觉提示族、四个协议。发现当前 VLA 能够在没有语言指令的情况下执行提示指示的任务，暴露未经授权的视觉提示跟随风险。

**[Calibrated Predictive Safety for Heterogeneous Robots: An Action-Conditioned JEPA Framework with Model-Based Safety Shields](https://arxiv.org/abs/2608.17496)**
- 提出动作条件 JEPA 世界模型预测任务进展和物理风险，与确定性模型安全护盾结合，在 LIBERO-Long 基准上提高成功率并减少碰撞漏报。
