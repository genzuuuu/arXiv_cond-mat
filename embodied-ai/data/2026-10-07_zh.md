*   **[Learning Grasp Targeting from Point Clouds for Log Pile Clearing on a Hydraulic Crane](https://arxiv.org/abs/2610.07613)**
    提出一种从无分割点云中学习抓取目标的方法，用于液压林业起重机在木材堆场中抓取原木，结合了行为克隆和强化学习。

    提出RAGrasp，一种检索增强的平面平行夹爪抓取方法，利用少量本地采集的RGB-D模板，无需端到端重训练即可适应新部署。

    研究通过夹爪内物体重定向来修复抓取后的运动学可行性，以完成机器人插入任务，避免奇异点和关节限制。

*   **[Seeing Through the Displaced Frame: Privileged Noise Distillation for Vision-Force Precision Assembly](https://arxiv.org/abs/2610.07745)**

    提出一个可信物理AI的框架，整合了安全性、行为可理解性和感知对齐，旨在机器人进入人类空间时建立信任。
*   **[Navigation with RF Cues: Embodied Perception Action under Multipath Uncertainty](https://arxiv.org/abs/2610.08105)**
    构建了Habitat Sionna RT基准，并提出一个不确定性感知的多模态导航框架，联合估计目标方向及其不确定性，以应对多径传播带来的射频信号失真。
*   **[GeoAlign: Beyond Semantics with State-Guided Spatial Alignment in VLA Models](https://arxiv.org/abs/2606.03240)**
    提出GeoAlign，一种状态引导的空间对齐架构，通过离线机器人领域RGB-D监督后训练RGB几何分支，生成几何增强特征，提升VLA模型的可执行操作能力。
*   **[Safe Multi-Robot Collaborative Transport Using Density Functions](https://arxiv.org/abs/2610.08441)**
    提出一个分层密度模型预测控制框架，用于多四足机器人安全协作运输，通过集中式盒子级MPC和分布式机器人级全身MPC，实现无预计算参考轨迹的推物任务。
*   **[Communication-Free Obstacle Localization from Aggregate Wrench Measurements in Leader--Follower Cooperative Transport](https://arxiv.org/abs/2610.08324)**
    研究了在无显式通信的领导者-跟随者协作运输中，领导者如何通过测量跟随者施加的合力/力矩来定位障碍物。
*   **[SC3BF: Shifted Collision Cone Control Barrier Function for Dynamic Obstacle Avoidance](https://arxiv.org/abs/2610.08332)**
    提出“偏移碰撞锥CBF”（SC3BF），通过向碰撞锥条件中添加状态依赖的“允许量”，使机器人能以随距离和自身速度增长的速率接近障碍物，实现更高效的动态避障。

### 六、 仿真到现实迁移 (Sim-to-Real) 与世界模型 (World Models)

本方向研究如何利用仿真数据训练模型并迁移到现实世界，以及如何构建预测未来的世界模型。

*   **[Smart: Zero-Shot Sim-to-Real Articulated Object Manipulation via Large-Scale Synthetic Pretraining](https://arxiv.org/abs/2610.07652)**
    提出SMART系统，通过大规模合成演示预训练VLA模型，实现了铰接物体操作的零样本sim-to-real迁移和可扩展性能。
*   **[AIM: Adaptive Interaction Modeling Networks for Real-to-Sim Soft-Body Simulation](https://arxiv.org/abs/2610.07116)**
    提出AIM框架，将real-to-sim软体仿真视为局部-全局交互建模问题，通过自适应粒子关系和几何条件化全局通信，提高形变物体操作的预测精度。
*   **[Mask2Real-WM: Controllable Dexterous World Models via Segmentation Masks as a Sim-to-Real Bridge](https://arxiv.org/abs/2607.04546)**
    提出Mask2Real-WM，一个两阶段世界模型，通过将像素预测解耦为动力学模型（预测分割掩码）和渲染模型（生成RGB图像），在有限的真实数据预算下提升灵巧手的可控性。
*   **[DepthWorld: 3D World Model for Robot Manipulation](https://arxiv.org/abs/2610.08780)**
    提出DepthWorld，一个基于Stable Video Diffusion的世界模型，通过空间潜在平铺联合预测多视角RGB和深度，提升RGB预测质量和下游几何推理能力。
*   **[ROLLING-WAM: World Action Models with Rolling Imagination](https://arxiv.org/abs/2609.30247)**
    提出Rolling-WAM，将联合去噪过程分布到连续的重规划周期中，实现流式推理和稳定长时程开环部署，稳态重规划速度提升4.5倍。
*   **[OPENSplatGraph: From Dense Semantic Maps to Structured Scene Graphs for Open-Vocabulary Robot Perception](https://arxiv.org/abs/2610.07569)**
    提出OpenSplatGraph，一个从在线高斯开放词汇语义地图直接构建3D场景图的统一框架，支持语言引导的物体定位和结构化关系推理。
*   **[Fluorescence-enhanced Whisker Array with Vision-based Deformation Analysis for Underwater Source Localization](https://arxiv.org/abs/2610.07275)**
    提出一种荧光增强的须状阵列传感系统，通过局部光学读出而非直接源成像，定位水下流体动力源，适用于水下机器人。
*   **[Learning Force-Regulated Robotic Manipulation with a Low-Cost Tactile-Force-Controlled Gripper](https://arxiv.org/abs/2602.10013)**
    介绍TF-Gripper，一个低成本、力控的平行夹爪，并提出了RETAF框架，通过高频触觉反馈和腕部图像调节抓取力，实现力调节的机器人操作。
*   **[SURGE: Sonar-fUsed Reconstruction and localization via image-gated Graph Estimation](https://arxiv.org/abs/2610.07472)**
    提出SURGE框架，通过在因子图中集成视觉和声学观测，联合估计ROV轨迹和目标位置，并使用恢复的度量位姿进行声呐高斯溅射。
*   **[Video2World: Benchmarking Coding Agents for Interactive World Modeling from Embodied Videos](https://arxiv.org/abs/2610.04432)**
    提出Video2World，一个评估编码智能体从具身视频端到端构建交互式模拟器的基准，衡量几何保真度、动态保真度和功能正确性。
*   **[EulerESG: Automating ESG Disclosure Analysis with LLMs](https://arxiv.org/abs/2511.21712)**
    提出EulerESG，一个LLM驱动的系统，用于自动化ESG披露分析，结合双通道检索和LLM驱动的披露分析，并能自动填充标准对齐的指标表。
*   **[Supervised Fine-Tuning of VLA Models in a Smart Home: An Industry Case Study](https://arxiv.org/abs/2609.03603)**
    通过一个工业案例研究，探讨了在智能家居场景中对VLA模型进行监督微调以执行工具操作任务的实践。
