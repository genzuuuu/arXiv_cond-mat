## 一、灵巧手、多指抓取与手中操作

- **[Design and Validation of an Antagonistic Tendon-Driven Dexterous Robotic Hand with Bidirectional Operation](https://arxiv.org/abs/2609.36241)**：17 自由度、200mm/220g 拟人腱驱动灵巧手，拮抗式布线使各关节可越过中立位，实现掌侧/背侧双向抓取，传动误差 3.0%、指尖力 29N、Kapandji 评分 8，完整覆盖 33 种 GRASP 抓取类型。
- **[FINGR: Learning Dexterous Hand Control for Real-World Rubik's Cube Solving](https://arxiv.org/abs/2609.33973)**：用指尖相对几何 + 未来交互预测（接触力变化、层转进度）监督流策略，单只灵巧手 300 次转层尝试成功率 99.0%（基线 79.7%），配合抓取与桌面重抓完成全部 10 个 2×2×2 魔方复原。
- **[Unified Visual-Tactile-Action Modeling from Human Demonstrations for Dexterous Manipulation](https://arxiv.org/abs/2609.34182)**：搭建触觉动作捕捉系统采集人手数据，构建 UVTA 数据集（5 类接触密集任务、1000 条人类演示），统一视觉-触觉-动作模型将人手与机器人映射到对齐的触觉/动作表征，真实任务平均成功率 70%（最强视觉-触觉基线 29%），且随人类演示增加仍未饱和。
- **[ContactExplorer: Contact Coverage-Guided Exploration for General-Purpose Dexterous Manipulation](https://arxiv.org/abs/2603.10971)**：以"哪根手指接触物体哪个区域"为接触模式，用接触计数奖励 + 能量型到达奖励引导探索，在 7 个接触密集任务、5 种灵巧手上提升样本效率与成功率，并可迁移到真机。
- **[Kinematic Nonlinear Spatio-Temporal Trajectory Warping for Contact-Rich Dexterous Manipulation Demonstrations](https://arxiv.org/abs/2609.36676)**：利用接触分布对已有手-物轨迹做非线性时空 warp，支持中间路点、障碍、不同起止构型，在 12 种变体上验证并泛化到不同机械手。
- **[Manifold-Constrained MPPI: Real-Time Sampling-Based Control for Nonlinear Equality-Constrained Robotic Systems](https://arxiv.org/abs/2605.24813)**：VAE 学习约束流形的低维潜空间做规划 + QP 执行级修正，14 自由度闭链双臂系统实现 100Hz 规划 / 500Hz 执行，40 次真机试验成功率 95%（闭链操作相关）。

## 二、触觉感知与力/触觉反馈策略

- **[HACo: Learning Haptic Active Compliance for Force-Aware Dexterous Manipulation](https://arxiv.org/abs/2609.36596)**：把顺从遥操作产生的"指令-状态偏差"作为辅助监督，结合指尖触觉与关节力矩反馈（覆盖触觉盲区），用门控触觉交叉注意力做闭环力调节；真实接触密集基准平均成功率 83%（最强基线 35%）。
- **[TaRL: Learning General and Physical Rewards from Tactile Demonstrations](https://arxiv.org/abs/2609.36785)**：从触觉形变图序列回归任务进度，作为 RL 塑形奖励，显著提升抓稳与施力方向；仿真螺母穿线 34%→56%，真机方块抓取 37%→97%，并可与视觉奖励叠加。
- **[TacForcing: Streaming Action Generation with Execution-Time Tactile Feedback](https://arxiv.org/abs/2608.25798)**：把动作专家改成流式生成器，逐块生成并保留中间状态，执行后用新触觉反馈续生成；执行感知触觉注意力限制每次触觉更新只影响下一块，仿真/真机平均成功率 65%/66%。
- **[Wrench-ACT: Enhancing Robot Policies for Contact Rich Behavior Using Direct Wrench Control](https://arxiv.org/abs/2609.37552)**：直接以力旋量作为动作输出、交由纯力控制器执行，配合双边力反馈遥操作采集数据；5 个接触密集任务上匹配或超过位置基线，将公开 1000+ 条力旋量演示。
- **[A robust single-sensing-element tactile sensor for concurrent pressure and tackiness detection with real-time signal decoupling capability](https://arxiv.org/abs/2609.36558)**：单传感元件（霍尔 + 软磁复合材料）同时检测压力与黏附/剥离力，靠表面下陷与回撤凸起产生全过程可追踪、基线分离的信号，实现实时解耦。
- **[A Disk-Shaped Magnetoelastic Torque Sensor for Robotic Joints Using Permanent Magnetization](https://arxiv.org/abs/2609.33542)**：约 1cm 轴向厚度的盘式磁弹性关节力矩传感器，四磁强计结构 + 定制磁屏蔽抑制交叉力，50Nm 量程下精度 1.34%FS。
- **[TaRL…]** 及 **[S2A2: Audio-Visual Imitation Learning for Manipulation Tasks Using Acoustic Spatial Information](https://arxiv.org/abs/2607.26047)**：把声源定位与音色信息引入模仿学习，提出 Spatial-Spectral Audio Action 框架并接入 ACT、Diffusion Policy、VQ-BeT、π0，真机验证可用于需区分位置与音色的操作任务。

## 三、视觉-运动策略与 VLA（含长程、记忆、鲁棒性）

- **[SkillWeaver: Agentic Exploration over Neural Interaction Skills for Scalable Robot Data Generation](https://arxiv.org/abs/2609.36171)**：以 RL 学到的闭环"神经交互技能"为原子，VLM 智能体做验证器引导的树搜索探索，自主生成 39.1K 演示 / 14.1K 场景，蒸馏出的视觉运动策略在仿真与真机上实现零样本/少样本 sim-to-sim、sim-to-real 泛化。
- **[FineART: Fine-grained Annotated Robotic Trajectory Dataset and Vision-Language-Action Model for Bimanual Manipulation](https://arxiv.org/abs/2609.36416)**：40,543 条双臂演示、1,718 小时、533,913 个子任务的密集标注数据集；FineART-VLA 自预测下一子任务，空间消歧任务 32%→100%，未见长程任务在人工子任务引导下 16%→76%，新机器人上仅需十分之一数据。
- **[Rho: A Foundation for Efficiently Adaptable VLA Models](https://arxiv.org/abs/2609.38164)**：开源双臂操作 VLA 家族（YAM Box / UR AI Trainer / FR3 Duo），系统性消融 action expert 架构与训练配方，证明"embodiment midtraining"改善下游适配；内置潜策略可用 15 条纠正回合在线适配。
- **[LIBERO-MAX: Do Robot Policies Adapt When the World Changes?](https://arxiv.org/abs/2609.36518)**：8,000 对"任务中途事件"配对样本，覆盖几何/观测/外观/杂乱/路径等 8 类变化；14 个 VLA/混合/世界-动作策略成功率下降 11.0–25.7 个百分点，且相机查询频率调整不能消除差距。
- **[CoRe-VLA: Preserving Cross-View Coordination in VLAs under Camera Shifts](https://arxiv.org/abs/2609.37150)**：指出相机位移下"跨视图协调崩塌"（过度依赖腕部视角导致子任务顺序错误），用点云重建并渲染回训练视角，即插即用无需微调；PI0.5 在 1.6m 位移下真机成功率 13.3%→83.3%。
- **[Do LLM Agents Execute the Plans They Declare? …]** 之外的 **[ActMem-VLA …]** 与 **[Remember What You Did: Action-History Memory with Dual-Expert Denoising for Long-Horizon VLA](https://arxiv.org/abs/2609.37307)**：冻结底座 VLA + Mamba 动作历史记忆 + 轻量 PreAction Expert，双专家交接去噪；LIBERO-Mem 平均 80.8%（π0.5 65.2%），真机较 π0.5 提升 28.8 个百分点。
- **[T$^2$Mem: Learning Test-Time Memory for Robotics](https://arxiv.org/abs/2609.36720)**：用测试时训练把观测历史编码进紧凑 fast weights，无需外部记忆模块；RoboMME 16 任务平均成功率 17.93%→56.83%，推理比显式记忆方法快 3 倍以上。
- **[Simple Agentic Memory for Generalist Robot Policies](https://arxiv.org/abs/2609.36595)**：免训练记忆层，从指令指定"监控什么"，冻结感知工具在线维护紧凑类型化状态，仅在子目标依赖历史时检索；RoboMME 67.17%（最强非 oracle 44.51%）。
- **[DRAM: Delta-rule Recurrent Associative Memory for Robot Manipulation Policies](https://arxiv.org/abs/2609.32453)**：即插即用记忆模块，用门控 delta-rule 线性注意力维护定长关联记忆，主干冻结只训记忆与动作专家，为多种预训练策略带来长程记忆能力。
- **[TaskAnchor: Grounding Task State in Reactive VLAs for Long-Horizon Manipulation](https://arxiv.org/abs/2609.23580)**：把执行阶段表示为"里程碑监督坐标"前置到语言指令，并对当前视觉 token 做残差更新注入历史证据；RMBench 上约为 π0.5/X-VLA 的 6 倍成功率，RoboMemArena 上翻倍。
- **[Spotter: Let the Embodied Model Lead, and the VLM Reflect for It](https://arxiv.org/abs/2609.36808)**：反转 VLM 主导范式——具身模型持续执行，VLM 并行监控、仅在检出错误时反思纠错；RoboCasa +5.6/+7.5 个百分点，真机 53%→83%，且延迟开销小。
- **[Taming VLAs under Robot Execution Errors: Self-Compensation and Stress Testing](https://arxiv.org/abs/2609.37334)**：用"指令动作 - 实际执行"残差在线更新 VLA 以预补偿执行误差；提出 RoboStress 仿真基准（摩擦、回差、柔顺、重力补偿误差），两台不同磨损状态真机臂平均成功率提升 30+ 个百分点。
- **[Test-Time Adaptation of Manipulation Policies Under Actuator Degradation](https://arxiv.org/abs/2609.36182)**：TeAR 用温度/电流/电压等遥测信号，通过轻量 Transformer 修正冻结策略的输出动作；18 组策略-任务对上退化失配时成功率 31.8%（基线 25.6%），真机加热场景提升 10–15%。
- **[Scouting the Dynamics Gap: Test-Time Policy Adaptation via Action-Outcome Feedback](https://arxiv.org/abs/2609.36107)**：SCOUT 通过共享 belief 潜空间耦合动作策略与前向动力学模型，用动作-结果失配在线更新 belief 实现快速适配，仿真提升明显并实现稳健 sim-to-real。
- **[Executor-aware Candidate Selection via a Feasibility Certificate](https://arxiv.org/abs/2609.36597)**：针对规划器与执行器硬约束不一致问题，构造"命令见证"证书筛选候选；5,085 次几何可行评估中 795 个无可执行命令，证书为充分但保守。
- **[Disentangling Spurious Correlations in VLA Models via Predicting Domain-Invariant Latent Lookahead](https://arxiv.org/abs/2609.37165)**：DILL 用任务-域编码器 + 对比与高斯解耦正则学习域不变未来潜变量，作为 VLA 前瞻监督；LIBERO-Plus 平均 69.1%，比最强基线高 11.4 个百分点。
- **[Beyond Token Importance: Preserving Spatial Scaffolds for Efficient VLA Inference](https://arxiv.org/abs/2609.36967)**：诊断出 VLA 剪枝需保留"空间脚手架"（空间覆盖半径与成功率强相关），提出免训练 GeoScaffold，仅保留 20% 视觉 token 仍保持 93.2% 成功率。
- **[Decoupled Early Exits for Task-Dependent Compute Allocation in Flow-Matching VLAs](https://arxiv.org/abs/2609.29382)**：把主干深度 V、动作专家深度 A、去噪步数 D 作为三条可联合配置的计算轴，配合 KV Cache 合成，延迟降 79.2%、FLOPs 降 31.8% 且成功率 +5.6%。
- **[Urgent Actions Go First: Urgency-Aware Denoising for Real-Time VLA Control](https://arxiv.org/abs/2609.37772)**：利用滚动时域中动作"紧急度异质"的特点，对时间紧迫动作少步去噪、尾部动作后台精修，平均动作可用延迟最高加速 1.89 倍。
- **[Don't Throw Away the Tail: Action Upcycling for Policy Acceleration](https://arxiv.org/abs/2609.34911)**：免训练地复用被丢弃的动作尾部，按"动作速度开始波动"处延长执行视界，减少策略调用 1.2–1.7 倍而无成功率损失，正交于少步采样等方法。
- **[Where Predictive Supervision Goes Shapes What VLA Policies Learn](https://arxiv.org/abs/2609.36645)**：控制变量研究未来预测监督的"接口位置"如何影响 VLA 表征与分布外鲁棒性，指出直接、场景匹配的未来监督效果更好。
- **[Rethinking Representations for World-Action Modeling](https://arxiv.org/abs/2609.38163)**：基于 DINO 特征构建表征中心的世界-动作模型 ReWAM（特征校准 + 时间表征瓶颈 + 动作锚定表征塑形），无需生成式视频预训练，RoboTwin 2.0 达 93.6%。
- **[MVG-WAM: Multiple View Geometry-Aware World-Action Modeling for Robotic Manipulation](https://arxiv.org/abs/2609.37793)**：把多相机观测组织为同一物理世界的相关投影（对极约束全局状态 + 视图几何状态 + 相机感知路由 + 未来深度监督），LIBERO 99.1%、RoboTwin 2.0 92.07%，真机 150 次试验 91.3%。
- **[One from Infinity: Actualizing Futures from Pretrained World Models into Robot Actions](https://arxiv.org/abs/2609.36413)**：主张冻结视频世界模型、只训练极小的"actualizer"（60M 参数、两张 DiT 专家、单卡 32GB），在 LIBERO/LIBERO-Plus/RoboTwin 2.0 及两个真机平台取得好成绩，延迟 39ms。
- **[V-JEPA Policy: Building Effective World-Action Models on Predictive Visual Latents](https://arxiv.org/abs/2609.37250)**：在冻结 V-JEPA 2.1 潜空间上从零联合训练未来潜预测器与流匹配动作专家（0.9B，0.6B 可训），在 LIBERO 系列与 RoboCasa-GR1 上与代表性 WAM/VLA 竞争，分布偏移下更强。
- **[What Makes World Action Models Generalize? An Empirical Study of Test-Time Future Modeling](https://arxiv.org/abs/2609.34981)**：发现潜式 WAM 在分布外泛化上丢失了显式 WAM 的优势，差距几乎全部来自第一个去噪步；提出 Simple-WAM（一次前向的"全噪声"未来建模）兼得泛化与效率。

## 四、世界模型、潜空间规划与控制

- **[Bilinear World Models: Learning Representations with Structured Dynamics for Efficient Control](https://arxiv.org/abs/2609.36305)**：JEPA 风格世界模型将潜动力学限制为双线性参数化，结构上保证动作可恢复性以防表征崩塌，2D/3D 控制任务上规划时间降低近三个数量级。
- **[Anisotropic Representations Improve Planning in JEPA World Models](https://arxiv.org/abs/2609.37441)**：指出现有各向同性高斯正则给出的潜几何与任务代价不匹配，提出可学习对角协方差（固定迹 + 各向异性约束）的 ΛReg，四个视觉控制环境上规划成功率全面提升。
- **[ATLAS: Aligned Transport of Latent Structure for Reliable World Model Planning](https://arxiv.org/abs/2609.36333)**：显式保持规划潜空间中的关系几何（归一化成对结构迁移 + Wasserstein 边缘校准），在 PushT、TwoRoom、OGBench-Cube 上提升目标达成率，新异性越高收益越大。
- **[Interactive-Policy Distillation …]** 之外的 **[Simple-WAM]** 与 **[Two-Fidelity Best-Action Identification for Stochastic Minimax Tree](https://arxiv.org/abs/2606.01708)**：2FFS 把多保真度臂机思想引入博弈树，廉价有偏评估 + 昂贵精确评估自适应切换，给出固定置信正确性证明与多项式深度代价上界（与 MCTS/LLM 长 rollout 的规划取舍相关）。
- **[Two-fidelity]** 及 **[Aim Short to Reach Far: Your Frozen World Model Can Plan Better Than You Think](https://arxiv.org/abs/2609.30036)**：指出用"到最终目标的距离"评分会拒绝先远离目标的正确首步，提出 Anchored Planning，复用世界模型自身离线轨迹检索中段作为瞄准点，无需训练即大幅改善冻结 LeWM 规划。
- **[Dual-Latent World Model]**（见 **[Beyond a single latent space: a dual-latent world model for long-horizon planning](https://arxiv.org/abs/2609.37644)**）：把局部执行与长程规划分离为低层动作条件动力学与高层宏动作动力学，配 LoRe 加权 rollout 训练；偏移 50/100 步时平均成功率 75.9%→84.4%、61.4%→69.5%。
- **[Hydra: A Navigation World Action Model with Discrete Latent Planning and Continuous Flow-Matching Execution](https://arxiv.org/abs/2608.28995)**：在统一潜流形上用模态特定 VQ 瓶颈得到"动觉意图"与"视觉状态"离散词表，离散潜空间内做 Kinematic-Perceptual 代价排序，再用流匹配映射到连续执行轨迹。
- **[Learning to Explore Hidden Kinematics for Articulated Object Manipulation](https://arxiv.org/abs/2609.36553)**：不依赖接触/惯性动力学前向模型，在训练中摊销动作选择：把关节类型与参数的 belief 渲染为逐点"关节流场"作为策略条件，RL 奖励后验熵的下降；PartManip 与新建 ArticuRiddle 数据集上 61.7% vs 44.4%。
- **[From Sky to Soil…]** 之外，**[RoboChrono: A Real Robot Benchmark for Streaming Task Understanding](https://arxiv.org/abs/2609.36605)**：39 个场景、34,713 个实例的流式任务理解基准，18 个 VLM 零样本评测显示"视觉匹配强 ≠ 时序排序强"。任务理解评测相关。
- **[iTeach: In the Wild Interactive Teaching for Failure-Driven Adaptation of Robot Perception](https://arxiv.org/abs/2410.09072)**：MR 头显 + 视线/语音交互，单次约 20 秒交互产出 150–300 帧密集标注，机载微调并回滚保留更优模型；分割从 26.1 提升到 80.7，下游抓放 72/100，12 人用户研究中非专家达到专家标注水平。

## 五、人形机器人与全身运动/遥操作

- **[Passive-Dynamic-Walking-Inspired Dynamics Guidance for Energy-Efficient Humanoid Locomotion](https://arxiv.org/abs/2609.35935)**：借鉴被动动态行走，在训练早期施加"等效斜坡"倾斜重力场辅助经济步态发现，并在名义动力学优化前移除全部引导；Unitree G1 上机械运输代价降低 6.8–15.2%，真机前向 CoT 下降 16.3%。
- **[HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers](https://arxiv.org/abs/2606.06493)**：把运动跟踪、行走、跌倒恢复三类教师用动作切片上的上下文条件 KL 与软专家混合蒸馏进单个 29 自由度策略，接受 10 维任务空间指令而非稠密运动学流，无需运行时切换策略。
- **[EgoHumanoid-V2: Human-to-Humanoid Transfer of Coordinated Whole-Body Skills for Loco-Manipulation](https://arxiv.org/abs/2609.37181)**：首个以自我中心人类演示做全身协调 loco-manipulation 技能迁移的框架，"粗到细动作对齐"结合运动学参考修正与动力学感知精修；四项真机任务上零样本技能迁移，成本低于遥操作数据。
- **[EgoAlign: Bridging the Human-Humanoid Gap for Long-Range Loco-Manipulation](https://arxiv.org/abs/2609.38046)**：以目标机器人模型与仿真器引导人类演示采集，保留行走参考、通过尺度对齐与"控制器在环"精修上半身交互几何，因果重放重建机器人状态与 motion-token 标签。
- **[OTRetarget: Joint Robot and Object Motion Retargeting via Optimal Transport](https://arxiv.org/abs/2609.36602)**：用带熵最优传输在人/机器人/物体几何之间迁移表面交互量（符号距离、最近点、相对方向），并入约束逆运动学联合优化机器人与物体位姿；OMOMO 上 Jaccard 87%、深度误差 8.7mm，并在 G1 真机上验证双手搬运箱子等动作。
- **[Learning Expressive and Compositional Motion Representation via Spectral Skills](https://arxiv.org/abs/2609.37677)**：用"谱技能"作为规划器-控制器之间的接口潜表征，通过预测后续运动而非重构输入学习；29 自由度人形上全局跟踪误差降低 62%，可链式衔接并可正交组合出新行为。
- **[CrossBFM: Distilling a Shared Latent Behavior Space Across Humanoid Embodiments](https://arxiv.org/abs/2609.38087)**：把行为潜空间本身作为可迁移资产，用无机器人特定参数的统一编码器 <1 GPU 小时蒸馏出跨形态共享行为空间，+10 GPU 小时训练潜条件跟踪器；三种提示模式均可迁移，训练集外形态可恢复最高 89% 跟踪性能。
- **[Counterfactual Video Generation Enables Scalable Humanoid Loco-Manipulation](https://arxiv.org/abs/2609.38172)**：PRISM 用 video-to-video 把少量真实视频扩增为数百条"反事实"人-物交互视频，经接触锚定的 real-to-sim 重建人手与物体运动并重定向为物理合理轨迹；真人形机器人仅用机载深度即可抓取搬运箱子、桶、球。
- **[Track-and-Complete: Learning Humanoid Skills from a Single Failed Human Video](https://arxiv.org/abs/2609.36924)**：把失败人类视频中"可用运动前缀"作为先验、依据推断出的任务目标设计完成奖励，在 Oops! 数据集六个真实失败任务上验证——失败视频也可作为人形技能学习监督。
- **[HANDOFF/EgoHumanoid/EgoAlign 之外的]** **[AeroManip-VLA](https://arxiv.org/abs/2609.36915)**：面向空中机械臂的可扩展 VLA 基准，GPU 加速并行仿真 + 复用 RL 策略与专家规则自动生成演示（无需遥操作），含自动事件标注与轨迹分类，用于系统评测模仿学习与 VLA 基线。

## 六、数据采集、遥操作与 sim-to-real 平台

- **[AeroManip-VLA: Scalable Vision-Language-Action Learning for Aerial Manipulation with RL-Generated Demonstrations](https://arxiv.org/abs/2609.36915)**（另见上）。
- **[SkillWeaver](https://arxiv.org/abs/2609.36171)**（另见上）。
- **[RoboCompile…]** 之外的 **[RoboCompiler: Graph-Native Compilation of Closed-Chain Robots for Consistent Modeling, Control, and Simulation](https://arxiv.org/abs/2609.35717)**：把机构图编译为共享机械接口（闭合路径与解析残差雅可比、切空间提升、约束曲率修正），在挖掘机、Go2、Franka、Kangaroo、六-UPS Stewart 上验证，Kangaroo 上残差与雅可比求值时间减少 96.7%。
- **[RynnWorld-Teleop: An Action-Conditioned World Model for Digital Teleoperation](https://arxiv.org/abs/2607.06558)**：提出"数字遥操作"——操作者手部姿态流驱动以机器人为中心的生成式世界模型，从单张参考图合成高保真自我中心视频，姿态流即embodiment 无关的动作标签；可在单卡 H100 上 40+ FPS 流式生成，纯生成数据训练的策略实现零样本 sim-to-real。
- **[RynnWorld-4D: 4D Embodied World Models for Robotic Manipulation](https://arxiv.org/abs/2607.06559)**：统一扩散过程联合生成未来 RGB、深度与光流（RGB-DF）的 4D 世界模型，三支架构 + 帧级 3D RoPE；构建 2.544 亿帧的 Rynn4DDataset 1.0，并用逆动力学头单次前向输出闭环动作。
- **[F4R: Failure-Driven Recognition, Reconstruction, Refinement, and Redeployment for Continual Robot Self-Improvement](https://arxiv.org/abs/2609.35575)**：把真实失败重建为物体中心可交互仿真环境，做失败条件 sim-real 协同训练 + 定向 RL，循环回灌新失败；4 项真机任务 ID 93.75%、OOD 90.0%，比预算匹配的 Targeted BC 高 18.75 个百分点。
- **[RoboFin3D: A Sim-to-Real Platform for Robotic Surface Finishing](https://arxiv.org/abs/2609.37560)**：基于 Isaac Sim + Newton 的打磨/砂光仿真平台，用 SDF 表示工件几何变化、独立表面场表示外观演变，并用 WeldGen 为 8,918 个真实工件网格生成焊缝；仿真数据微调 SAM2 使未打磨区域分割 IoU 77.15%→84.47%。
- **[RoboChrono](https://arxiv.org/abs/2609.36605)**（另见上）。
- **[LIBERO-MAX](https://arxiv.org/abs/2609.36518)**（另见上）。
- **[RoboHarn-Evo: Evolving Hierarchical Physical Knowledge for Self-Improving Robotic Manipulation](https://arxiv.org/abs/2609.37583)**：不更新基座模型，通过双层 harness 从物理经验中演化"分层物理知识"（任务知识 + 动作知识），RMBench 平均成功率最高提升 24.2 个百分点，并可零样本迁移到 RoboDojo。
- **[SkillGym: Training Skill-Use Agents with Automatic Verifiable Environment Generation](https://arxiv.org/abs/2609.37539)**：从互联网爬取技能、保留可离线复现的执行流程，用 builder-reviewer 流水线构造难度可控任务与可执行验证器，6.8k 环境 + 19k 验证成功轨迹用于 SFT。

## 七、基准、评测与鲁棒性

- **[RLE-Bench: A Qualifying Exam for Coding Agents as Robot Learning Engineers](https://arxiv.org/abs/2609.34210)**：覆盖交互控制、策略学习、感知估计、机械设计四类机器人开发流程的编码智能体基准，输出统一 RLE Index 与分工作流能力画像。
- **[Faster and Better? Benchmark Bugs and Design Limitations Distort the Evaluation of VLA Acceleration](https://arxiv.org/abs/2609.37771)**：审计 RoboTwin、LIBERO-Plus、VLABench 等七个基准，识别 22 个 bug 与 4 项设计缺陷；修复后方法排名可反转（某任务上基线从最后升至第一），提示"加速带来的收益"可能是基准假象。
- **[LIBERO-MAX](https://arxiv.org/abs/2609.36518)**（另见上）。
- **[Beyond Symmetric Agents…]** 之外，**[Benchmarking Vision-Language Models on Synapse Detection and Proofreading in Connectomics](https://arxiv.org/abs/2609.36492)**：19 个开源 + 2 个闭源 VLM 在电镜突触检测与校对上的系统基准，LoRA 后开源模型可追平专用模型。
- **[World4Scorer: Outcome-Grounded World Modeling for Autonomous Driving](https://arxiv.org/abs/2609.36438)**：用模拟器为所有候选轨迹打标签、以轨迹条件 JEPA 预测状态并读出分数，NAVSIM-v2 达 SOTA，并在 OGBench-Cube 上改善操作规划（与"世界模型做打分/规划"同源）。
