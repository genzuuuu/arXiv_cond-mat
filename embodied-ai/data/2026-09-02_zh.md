### 一、 具身智能与人形机器人

1.  **[Blind Dexterity: Whole-Body Humanoid Manipulation via Pure Proprioception](https://arxiv.org/abs/2608.29487)**：这项研究展示了仅依靠本体感觉（关节编码器），不使用任何视觉或触觉传感器，Unitree G1人形机器人也能完成推土、接球、提箱子等全身操作任务。作者认为，在主动柔顺接触下，关节编码器的读数变化形成了一种全身触觉通道，使得任务相关的物体状态可以从短期的本体感觉历史中被解码出来。

2.  **[Learning Agile Perceptive Traversal of Sparse 3D Structures for Humanoids](https://arxiv.org/abs/2608.29769)**：针对猴子杠穿越等稀疏3D结构，提出了一种基于强化学习的感知控制系统。该系统利用头部固态激光雷达的原始点云数据，通过注意力编码器提取任务相关几何信息，并结合相位调度的教师-学生策略，实现了跳跃、攀爬和下落的全套动作，在真实机器人上完成了14/15次的成功率。

3.  **[FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated Experiences](https://arxiv.org/abs/2608.17027)**：提出了一种从模拟到现实的端到端流水线，用于训练人形机器人的视觉移动操作策略。文章发现，直接克隆合成演示效果不佳，而通过Flow-GRPO强化学习进行精炼可以突破性能瓶颈。该策略在真实Unitree G1上实现了零样本的跨场景步行和抓取。

4.  **[SOLO: Stable Omni-terrain Long-Horizon Perceptive Humanoid Locomotion](https://arxiv.org/abs/2608.26583)**：针对长时程感知运动中的脆弱性问题，提出了SOLO框架。该框架包含一个查询重建器（Query Reconstructor）来保留地形细节，以及一种轨迹感知MSE蒸馏方法来解决时间信用分配问题。该策略在压力测试地形上取得了97.5%的成功率，并能在户外完成1.5公里的连续行走。

5.  **[T-GMP: Terrain-conditioned Generative Motion Priors for Versatile and Natural Humanoid Locomotion](https://arxiv.org/abs/2606.06944)**：提出了一种地形条件生成运动先验（T-GMP）模块，用于捕捉地形条件下的潜在运动流形，使策略能够根据不同地形平滑地调整步态风格。与固定运动先验的方法相比，该方法在运动自然度、多样性和穿越成功率上均有提升。

### 二、 灵巧操作与触觉感知

1.  **[$N_0$-Foundation: Towards the Age of Tactile Intelligence](https://arxiv.org/abs/2608.29601)**：介绍了一个名为$N_0$-Foundation的触觉具身操作范例，包括硬件、数据、表征学习和基准测试。项目构建了包含超过3万小时同步视觉-触觉演示的NeoData数据集，并提出了NeoForce视觉-触觉表征模型。实验表明，策略能从物理接触状态中获益，而非特定传感器外观。

2.  **[The Potential of Haptic Foundation Models](https://arxiv.org/abs/2608.28664)**：一篇观点文章，探讨了触觉基础模型（HFMs）的发展潜力。文章指出现有触觉模型因硬件异质性和数据采集限制而过于特定，并概述了从被动LLM/VLM向主动HFM转变所需的四个核心维度，包括动作耦合、物理动力学表征空间、连续时间序列数据粒度和动作条件下的未来状态预测。

3.  **[SpectraTac: A Compact Camera-Free Optical Tactile Sensor with Distributed Color Sensing](https://arxiv.org/abs/2608.30368)**：提出了一种名为SpectraTac的紧凑型、无摄像头的光学触觉传感器，通过分布式颜色传感来感知接触。其成本低于5美元，能同时估计3D力和接触区域，在九区域接触分类中达到99.9%的准确率，为低成本触觉感知提供了新选择。

4.  **[Learning to infer and manipulate through distributed whole-arm interaction in a soft robot](https://arxiv.org/abs/2608.30773)**：探讨了软体机器人通过分布式全身交互来推断和操作物体的“物理智能”。研究利用强化学习训练了一个基于记忆的控制策略，使混合刚软机械臂仅凭嵌入的内置IMU本体感觉，就能在“盲操作”情况下识别并抓取不同物体。

5.  **[Anomaly Detection on Small Industrial Components via Vision-Based Tactile Sensing](https://arxiv.org/abs/2608.30506)**：系统评估了基于视觉的触觉传感器（GelSight Mini）用于小型工业部件异常检测的性能。研究比较了四种无监督方法，并针对触觉传感的部署约束（如凝胶磨损、接触位置变化等）设计了三种验证方案，为工业质检提供了实践指导。

### 三、 视觉-运动策略与世界模型

1.  **[Hydra: A Navigation World Action Model with Discrete Latent Planning and Continuous Flow-Matching Execution](https://arxiv.org/abs/2608.28995)**：提出了Hydra，一个用于导航的世界动作模型。它将规划器嵌入到模型内部，通过离散的潜在意图词汇表和视觉状态来解决生成模型与规划器之间的表征错位问题，并采用流匹配将选定的意图映射为连续的机器人轨迹，实现了实时控制。

2.  **[RoboPhys-3D: A Comprehensive Embodied World Model Evaluation via 3D Reconstruction](https://arxiv.org/abs/2608.28718)**：提出了RoboPhys-3D，一个基于3D重建的具身世界模型评测基准。该基准覆盖50个操作任务，通过3D重建流水线区分重建误差和生成误差，其提出的RoboPhyscore评分与人类评估结果高度一致。

3.  **[DELE-w0.5: Inferring Action from Future Latent State for Robotic Manipulation](https://arxiv.org/abs/2608.22067)**：挑战了世界动作模型（WAMs）必须依赖视频生成的假设，提出了DELE-w0.5模型。该模型直接从预测的紧凑未来潜在状态中推断动作序列，跳过了视频生成的中间步骤，在640次真实机器人试验中取得了最佳性能。

4.  **[TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks](https://arxiv.org/abs/2608.24101)**：提出使用视觉轨迹作为机器人与世界模型之间的中间接口。TrAct框架将视觉轨迹与动作预测结合，并通过一个轨迹条件下的世界模型来评估未来结果，从而在视觉上选择最佳行动。在模拟和真实实验中，其成功率均优于$\pi_{0.5}$等基线模型。

5.  **[DriftingVLA: Native One-Step Vision-Language-Action Generation via Per-Dimension Temporal Drifting](https://arxiv.org/abs/2608.29749)**：针对基于流匹配的VLA模型推理延迟高的问题，提出了DriftingVLA。它通过分布漂移目标和逐维度时间漂移（PDTD）来学习从噪声到动作序列的直接映射，实现了单步生成完整动作块，在保持性能的同时显著提升了推理速度。

6.  **[CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding](https://arxiv.org/abs/2608.30289)**：旨在提升VLA模型的物理常识理解。通过构建Embodied物理VQA语料库CometData，并引入全局动作先验（GAP）Token，将物理常识注入策略模型，从而提升下游操作任务的性能。

### 四、 抓取、操作策略与Sim-to-Real

1.  **[DREAM: Deployment-Time Demonstration Generation via Real-to-Sim for Scalable Policy Adaptation](https://arxiv.org/abs/2608.29078)**：提出DREAM框架，用于在部署环境中自动生成用于微调VLA模型的数据。它通过重建工作空间、LLM规划、以及任务规划生成机器人轨迹，并在模拟环境中进行数据增强和验证，以减少新工作空间对人力的依赖。

2.  **[Teaching Robot Policies to Humans Using Erroneous Examples](https://arxiv.org/abs/2608.29023)**：研究了如何通过展示“错误示例”来向人类传授机器人策略。研究发现，让参与者观看错误演示并纠正动作，能提高他们对策略的长期记忆保持，这与课堂教学中的效果类似。

3.  **[Learning Agile Perceptive Traversal of Sparse 3D Structures for Humanoids](https://arxiv.org/abs/2608.29769)**：**(重复，已在人形机器人部分提及)** 聚焦于人形机器人在稀疏3D结构上的敏捷感知穿行，如猴子杠。提出了基于RL的感知控制系统，能直接从固态激光雷达的原始点云中学习操作策略，并通过教师-学生流程成功部署到真实机器人上。
