# 今日 arXiv 机器人学与 AI 论文总结（重点方向）

## 一、具身智能 / VLA 策略

- **Spatial-UMI-Dream**：5B 空间世界动作模型，用 RGB-D UMI 数据两阶段预训练，联合预测未来 RGB、度量深度与动作；提出 RoboTwin-UMI 基准。[链接](https://arxiv.org/abs/2611.07229)
- **Concertina**：把连续轨迹表示、分块生成与物理坐标监督直接放在共享扩散 VLM 主干上，动作投影仅占 0.21% 参数。[链接](https://arxiv.org/abs/2611.07513)
- **JADE（VLM 作为联合去噪器）**：VLM 在每个去噪步读取带噪动作并经门控交叉注意力引导动作专家。[链接](https://arxiv.org/abs/2611.01215)
- **SLA**：把隐式空间对齐扩展到持续预训练，并对齐冻结 3D 感知模型的空间表示。[链接](https://arxiv.org/abs/2611.08373)
- **La-JEPA**：紧凑世界动作模型，在 V-JEPA 2.1 特征空间从零训练策略 Transformer，推理只生成动作。[链接](https://arxiv.org/abs/2611.08156)
- **HITCH**：让 VLM 通过全身"挽具"接口操作人形机器人，感知返回 3D 点位、执行转成全身运动。[链接](https://arxiv.org/abs/2611.08039)
- **VREgo**：用消费级 VR 头显（PICO 4 Ultra）采集第一人称示教训练操作策略。[链接](https://arxiv.org/abs/2611.07272)
- **AffectiveVLA**：意图门控 VLA，用于人形机器人握手/击掌/拥抱等社交接触，带合规阻抗与安全停止。[链接](https://arxiv.org/abs/2611.07712)
- **T3R**：免训练两阶段 token 精炼（分割引导剪枝 + 显著性注意力偏置），减少 85% 场景相机 token。[链接](https://arxiv.org/abs/2611.08413)
- **VLA-Tug**：对 VLA 隐层做轻量探针，实现校准的早期失败预测与失败类型分类。[链接](https://arxiv.org/abs/2611.08425)
- **OopsieRecover**：用少量纠正示教 + 溯因推断意图，编码为稠密空间代价以泛化纠错。[链接](https://arxiv.org/abs/2611.08462)
- **Event-Grounded SAE**：以行为事件（而非文本）锚定 SAE 特征分析，用于 VLA 可解释性。[链接](https://arxiv.org/abs/2605.17204)
- **CAG / LIBERO-CF**：反事实基准揭示 VLA "视觉捷径覆盖语言"，提出双分支反事实动作引导。[链接](https://arxiv.org/abs/2602.17659)
- **ActQuant**：动作引导的 sub-4-bit 权重量化（含 2.5bpw），配 C/C++ 运行时，真机 UR3 验证。[链接](https://arxiv.org/abs/2605.24011)

## 二、灵巧手 / 灵巧操作 / 多指抓取 / 手中操作

- **TactileLab**：基于 IsaacLab 的可扩展触觉仿真，用光流式"仿真触觉流"表征剪切，配 real-to-sim 触觉翻译，实现双臂与手内操作 sim-to-real。[链接](https://arxiv.org/abs/2611.07881)
- **VTAM**：视觉-触觉世界动作模型，无需触觉预训练；冻结 VAE 共享 RGB/触觉，推理比 N0-TWAM 快约 6×，触觉编码器跨传感器零样本迁移。[链接](https://arxiv.org/abs/2603.23481)
- **Latent RL Priors**：特权 RL 预训练流匹配动作解码器，再用纯动作监督学视觉接口；双臂任务用 5–10× 更少示教超过全数据基线。[链接](https://arxiv.org/abs/2611.08458)
- **AnyDexRT**：标定高效的灵巧手重定向，自监督指尖对应 + 少样本人类引导 + 接触分类器精修捏合姿态。[链接](https://arxiv.org/abs/2607.08341)
- **Evo-DexBench**：30 任务/6 功能族/1,248 条 VR 遥操作多模态示教（Shadow Hand，123 taxel），最优策略平均成功率仅 24.4%。[链接](https://arxiv.org/abs/2610.21180)
- **RoboTryOn**：把人类视频转成目标机器人视频（"虚拟试穿"），IDM 推断动作标签，新任务成功率 2%→60%。[链接](https://arxiv.org/abs/2611.05163)
- **GraspBench**：MuJoCo 中跨 4 种机器人的 6-DoF 抓取生成执行级评测（含 IK 过滤、规划、固定执行），GraspGen 最高 73.1%。[链接](https://arxiv.org/abs/2611.07651)
- **OpenTac**：可定制 3D 触觉皮肤生态，结构化形变覆盖层解码剪切/法向，含 CAD 工具、仿真器与跨传感器迁移。[链接](https://arxiv.org/abs/2610.31661)
- **柔性压电触觉识别**：32 传感器 + 时空热图 2D-CNN，F1 达 0.9903，端到端延迟约 101 ms。[链接](https://arxiv.org/abs/2611.07779)
- **FAH**：快速准确单目手部估计，同时输出 2D/3D 关节与表面点并拟合 MANO，ViT-L 达 65 fps。[链接](https://arxiv.org/abs/2611.07711)

## 三、触觉感知与多模态触觉接口

- **多模态触觉接口**：粒子阻塞 + 冷热水热传递，刚度提升 300%，10–50°C，闭环误差 0.2°C。[链接](https://arxiv.org/abs/2611.08398)
- **VTAM / TactileLab / OpenTac**：见上节（触觉仿真、触觉-视觉世界模型、可扩展触觉皮肤）。

## 四、遥操作与示教采集

- **AnyDexRT**、**VREgo**、**EgoKit**（统一低成本第一人称采集，6 类设备，含 XR 头显 26 关节手部追踪）、**AffectiveVLA**（VR 遥操作采集约 1,300 条社交互动回合）、**Evo-DexBench**（VR 遥操作）。[EgoKit 链接](https://arxiv.org/abs/2605.16797)
- **MOMASPLAT**：用 3DGS + 前馈 3D 基础模型 + 运动学动作重定向，为移动操作合成新视角动态示教，显著提升未见基座位姿鲁棒性。[链接](https://arxiv.org/abs/2611.08372)
- **CubeDAgger**：动态任务交互式模仿学习，专家-智能体切换改为多动作候选最优共识 + 自回归有色噪声探索，30 分钟交互从零学舀取。[链接](https://arxiv.org/abs/2505.04897)

## 五、接触丰富操作、力/触觉控制与 sim-to-real

- **S2C（Semantics-to-Contact）**：VLM 定位任务相关区域 + 人在回路残差 RL 学接触行为，6 项真机接触丰富任务提升视觉鲁棒性。[链接](https://arxiv.org/abs/2611.07532)
- **自适应混合力-视觉控制**：用 EMG 映射期望握力作参考，挤压瓶分液 MAE 6.54 mL（纯力控 15.92 mL）。[链接](https://arxiv.org/abs/2611.07235)
- **DLO 关键点定位 RL 实证研究**：GPU 并行 MuJoCo Playground 收敛更快；观测噪声/延迟/域随机化后 sim 成功率 96.4%/98.0%/88.8%，无真机微调零样本迁移 9/10、10/10、8/10。[链接](https://arxiv.org/abs/2611.07261)
- **TactileLab**（见上）：剪切敏感触觉 sim-to-real 端到端框架。
- **CRISP**：分层 NMPC 将人形双臂协同建模为 SRB + 浮动基子系统 + 完整约束，在线优化交互力旋量，G1 真机验证。[链接](https://arxiv.org/abs/2611.07268)
- **Dual-Arm 桌面重排**：可移动堆叠 + 间隙感知推递（Gap-Aware Push Transfer）+ MCTS 规划，密集场景优于固定交接。[链接](https://arxiv.org/abs/2611.07726)
- **Wedge-Jamming**：线驱动阻塞机构引入楔形接触面，外楔抗竖向扰动、内楔抗扭转载荷。[链接](https://arxiv.org/abs/2611.07748)
- **RoboImagine**：通过候选未来比较 + 语义/视觉反馈后训练自回归机器人世界模型，RT-1 上 PSNR +1.26 dB、LPIPS −11.93%。[链接](https://arxiv.org/abs/2611.07850)
- **GPWM**：3D 粒子运动生成式世界模型，单一权重覆盖刚体/形变/布料/颗粒；噪声空间规划在推与抓取上优于动作空间搜索。[链接](https://arxiv.org/abs/2611.08338）

## 六、操作任务的世界模型 / RL 后训练

- **WoVR**：用可控动作条件视频世界模型做 VLA 的 RL 后训练，关键帧初始化 rollout + 世界模型-策略共演化。[链接](https://arxiv.org/abs/2602.13977)
- **RoboCurate**：动作验证的合成机器人数据（在仿真中执行 IDM 预测动作并与生成视频比对运动一致性）。[链接](https://arxiv.org/abs/2602.18742)
- **DenseReward**：自动合成物理真实失败轨迹，训练帧级稠密奖励模型。[链接](https://arxiv.org/abs/2607.13033)
- **LARBRID**：隐噪声线性 MDP + Bridge Equation 解决"噪声混叠"，扩散/流策略 RL 微调提速 2–3×。[链接](https://arxiv.org/abs/2611.07275)
- **测试时搜索审计**：Cosmos Policy/RoboCasa 上学习价值选择器比随机差 1.66pp，oracle 仅 +1.40pp，82% 状态候选结果相同；并发现并修复静默渲染污染。[链接](https://arxiv.org/abs/2610.41970)
- **MAC-v2**：像素离线 RL 的长时程模型价值展开，无重建隐世界模型 + 动作分块。[链接](https://arxiv.org/abs/2611.07245)
- **VIGOR**：模型型 RL 的零样本视觉泛化，弱-强非对称增强 + 动力学级一致性，Robosuite 超次优基线 43.6%。[链接](https://arxiv.org/abs/2610.02801)
- **SHORE**：在线 3D 装箱，学习稳定性概率 + on-policy 回报，Isaac Gym 60 箱集利用率 0.734（GOPT 0.588），真机演示。[链接](https://arxiv.org/abs/2611.08364)

## 七、人形 / 全身控制（与操作相关）

- **GigaBrain-WBC-0.5 / InterTrack**：行为世界模型做跨地形全身跟踪，地形交互成功率 81.3%、跌倒恢复 99.3%，首个实时跨地形全身遥操作演示。[链接](https://arxiv.org/abs/2608.18234)
- **WholeBodyMem**：对象引导的感知记忆保留动作前物体事件历史，真机成功率 36.7%→88.3%。[链接](https://arxiv.org/abs/2610.31166)
- **Social Humanoid**：29-DoF G1 上与人类伙伴 socially responsive 全身运动生成，含 260 小时 HHI 基准。[链接](https://arxiv.org/abs/2611.08407)
- **STEP / 地形索引运动先验**：感知人形运动，STEP 在 23-DoF Noetix E1 上 100 次硬件试验成功 98 次；parkour 框架 30 项障碍完成 29 项。[STEP](https://arxiv.org/abs/2611.08097) · [Parkour](https://arxiv.org/abs/2611.08056)
- **CTS-MoE**：感知门控稠密 MoE + 任务特定 critic，避免地形边界切换瞬态，动作 jerk 降约 1/3，Go1 户外 10/10。[链接](https://arxiv.org/abs/2606.19633)
- **PFM-HR**：在无序姿态数据上训练流匹配先验，提出 Pose Geometry Score 调制跟踪奖励。[链接](https://arxiv.org/abs/2608.03227)
- **LMGN**：四足 loco-manipulation 的"最后一英里"抓取-导航统一策略（基座放置、接近方向、抓取执行）。[链接](https://arxiv.org/abs/2611.07515)
