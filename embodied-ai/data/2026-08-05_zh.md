# 今日机器人学与人工智能相关论文总结

## 具身智能与灵巧操作

**[Light-Loco-Parkour: Versatile Perceptive Whole-Body Locomotion via Multi-Skill Distillation](https://arxiv.org/abs/2608.02653)**
提出LLP系统，一个端到端的感知全身运动控制系统，仅依赖机载深度和速度指令，即可在步行、平衡、攀爬、下阶和撑越之间自主切换，无需参考输入或技能标签。在仿真和真实环境均展现出高成功率，并支持零样本迁移到室内外硬件。

**[DexMani: Human-Derived Manipulability Guidance for Dexterous Rotation](https://arxiv.org/abs/2608.00554)**
提出DexMani框架，将人类演示作为接触条件可操控性演化先验，引导强化学习在多指手上（Shadow Hand、Allegro Hand、XHand）学习灵巧物体旋转技能，在见过和未见物体上均取得最高成功率。

**[GraspMeanFlow: SE(3)-Equivariant MeanFlow for Few-Step 6-DoF Grasp Generation](https://arxiv.org/abs/2608.03295)**
提出SE(3)等变的MeanFlow框架，实现少步6-DoF抓取生成。单次函数评估即可达到迭代SE(3)流模型五步的效果，同时在ACRONYM数据集上表现出较高抓取成功率。

**[GraRe: Grasp Candidate Re-Ranking for Frozen 6-DoF Grasp Detectors](https://arxiv.org/abs/2608.00946)**
针对现有6-DoF抓取检测器置信度与抓取质量对齐不佳的问题，提出GraRe重排序方法，在不改变检测器的情况下优化候选排序，在GraspNet-1Billion数据集上平均AP提升最多13.60点。

**[MANGO-Grasp: Mahalanobis Fields over Geometry-Oriented 3D Gaussians for Cross-Embodiment Dexterous Grasping](https://arxiv.org/abs/2608.02014)**
提出跨实体灵巧抓取框架，利用几何导向3D高斯原语表示物体，Mahalanobis场作为交互预测目标，实现零样本迁移到未见机械手，真实实验成功率86%。

**[Grasp Execution Without a Planner: Configuration-Space Grasp Distance Fields with Certified Safety & Guaranteed Quality](https://arxiv.org/abs/2608.00600)**
提出Grasp Distance Fields（GDFs），直接在手臂-手配置空间通过梯度下降执行抓取，无需规划器或预存轨迹，通过CBF-CLF QP滤波器保证安全性，对50个测试物体中46个成功抓取。

## 触觉感知与遥操作

**[Semantic Haptic Feedback Enhances Dexterous Robotic Teleoperation](https://arxiv.org/abs/2608.02780)**
提出语义触觉反馈概念，用抽象触觉模式传达机器人状态关键信息，通过气动和振动腕带实现。在双手任务中优于感觉触觉和视觉反馈，降低工作负荷并提升情境意识。

**[A Wearable Stiffness-Rendering Haptic Device with a Honeycomb Jamming Mechanism for Bilateral Teleoperation](https://arxiv.org/abs/2608.03002)**
设计20g轻量可穿戴触觉设备HJ-Haptic，利用蜂窝堵塞机制实现1.15至2.64 N/mm的刚度渲染，增强遥操作中操作者对物体刚度的感知。

**[Stiffness Copilot: An Impedance Policy for Contact-Rich Teleoperation](https://arxiv.org/abs/2603.14068)**
提出基于视觉的共享控制策略，操作者控制位姿，策略在线调整机器人阻抗。在接触丰富的任务中同时达到低刚度的安全性和高刚度的效率。

**[MVP-Tac: A Miniaturized Dual-Modal Vision and Photoelastic Tactile Sensor for Robot-Assisted Minimally Invasive Surgery](https://arxiv.org/abs/2607.18660)**
开发紧凑型视觉-触觉双模态传感器，利用反射式光弹性成像实现视觉和触觉感知切换，在肿瘤触诊分类中达到97%准确率（暴露肿瘤）。

## 视觉-运动策略与VLA模型

**[How Should Vision-Language-Action Models Use Proprioceptive State?](https://arxiv.org/abs/2608.03052)**
系统研究VLA模型中本体感知状态的接入方式，比较五种代表性接口，探究状态历史长度的影响，提炼出状态感知VLA的可测试设计原则。

**[ValueFormer: A Causal Transformer Value Function with Stage-Aware Labels for Semi-Autonomous Vision-Language-Action Policies](https://arxiv.org/abs/2608.02958)**
提出紧凑的因果Transformer价值函数，通过阶段感知标签提供逐帧信号，用于优势估计和在线错误检测。在真实双臂三明治装配任务中将成功率从70%提升至85%。

**[Track4Action: Distilling World-Centric 3D Tracker into Vision-Language-Action Policies](https://arxiv.org/abs/2608.03727)**
将世界中心3D追踪器特征蒸馏到VLA策略中，利用动作对齐的3D追踪特征作为特权监督，在LIBERO-Plus零样本达到82.3%，真实双臂任务67.5%成功率。

**[Structure-Aware Robust Fine-Tuning: Defending Vision-Language-Action Robots Against Physical Attention Hijacking](https://arxiv.org/abs/2608.03231)**
揭示VLA策略对物理对抗补丁的脆弱性，提出SARF防御方法，通过特征锚定和注意力校正将LIBERO上的失败率从100%降至14.2-56.8%。

**[VLAGuard: A Framework for Evaluating and Mitigating Physical Attention Hijacking in Vision-Language-Action Robots](https://arxiv.org/abs/2608.01028)**
提出评估和缓解VLA机器人物理注意力劫持的框架，APFT防御将OpenVLA失败率从100%降至25.9%，真实实验中成功率从23.0%提升至67.4%。

**[Continue or Replan? Bernoulli-Continuation Policy Learning for Adaptive Horizon Execution](https://arxiv.org/abs/2608.03483)**
提出BCP框架，将执行视界选择分解为继续或重规划的序列决策，通过强化学习训练。在RoboTwin 2.0上平均提升11.08%，真实机器人任务成功率从74%提升至92%。

**[CloudEdgeVLA: Latency-Tolerant Cloud-Edge Collaborative Vision-Language-Action Models](https://arxiv.org/abs/2608.00569)**
将云边VLA部署中的时间错位视为表示学习问题，通过训练使云表示保留任务级信息，边缘提供状态敏感修正，在LIBERO上40步延迟窗口下保持63.8-78.0%成功率。

**[Jetson-PI: Towards Onboard Real-Time Robot Control via Foresight-Aligned Asynchronous Inference](https://arxiv.org/abs/2607.12659)**
提出Jetson-PI方法，通过前瞻对齐异步推理实现在Jetson Orin上高效部署VLA模型，控制频率提升8.66倍，LIBERO平均成功率比VLASH高14.8%。

**[The Gate, Not the Cache: Gate Provenance Bounds the Closed-Loop Reliability of Training-Free VLA Token Skipping](https://arxiv.org/abs/2608.00391)**
揭示VLA令牌跳过的门来源决定闭环可靠性，提出执行松弛刷新方法，通过离关键路径的密集前向来更新门，在LIBERO上恢复至0.98成功率。

**[Gated Memory Policy: In-Context Memorization and Adaptation](https://arxiv.org/abs/2604.18933)**
提出GMP视觉运动策略，学习何时回忆记忆和回忆什么，通过门控机制和交叉注意力构建潜在记忆表示，在非马尔可夫任务上比长历史基线提升30.1%。

## Sim-to-Real与运动控制

**[Shooting for Contact: Contact-Implicit Multiple Shooting for Dynamic Motion Retargeting](https://arxiv.org/abs/2608.03116)**
提出接触隐式直接仿真多步射击框架，将运动重定向转变为动态可行的全身轨迹，在Unitree G1上实现零样本sim-to-real迁移的爬行和180度跳转。

**[Rapid Embodiment Adaptation for Quadrupedal Locomotion](https://arxiv.org/abs/2608.01506)**
提出四足机器人在线实体适配框架，从短交互历史推断实体参数（关节范围约束和躯干质量变化），在真实Unitree Go2上实现半秒内识别并维持稳定运动。

**[RobotDancing: Residual-Action Reinforcement Learning Enables Robust Long-Horizon Humanoid Motion Tracking](https://arxiv.org/abs/2509.20717)**
提出RobotDancing单阶段强化学习方案，通过预测参考条件的残差关节目标实现人形机器人长时间高动态运动跟踪，在Unitree G1上执行8个LAFAN1舞蹈动作。

**[When Replanning Becomes the Bottleneck: Budgeted Replanning for Embodied Agents](https://arxiv.org/abs/2608.01428)**
提出BRACE控制器，将重规划形式化为预算控制循环，配合E-RECAP渐进令牌剪枝，在Meta Habitat、RoboFactory和AirSim上将重规划令牌数减少62-92%。

**[The Key Role of Contact in Humanoid Locomotion: Passive Safety Analysis](https://arxiv.org/abs/2608.02809)** *(实质为工业人形机器人功能安全)*
分析工业人形机器人的功能安全认证缺口，指出“失效-被动”假设不适用于行走双足机器人，通过认证外部安全链定位残余不可认证元素。

## 操作任务的Sim-to-Real

**[PACE: Physics Augmentation for Coordinated End-to-end Reinforcement Learning toward Versatile Humanoid Table Tennis](https://arxiv.org/abs/2509.21690)**
提出乒乓球人形机器人强化学习框架，利用轻量学习预测器估计未来球状态，结合物理引导密集奖励，在仿真中命中率≥96%，零样本部署到真实Booster T1人形机器人。

**[FACT: Contact-Rich Tasks](https://arxiv.org/abs/2608.01402)** *(实质为Contact-Rich任务失败分析)*
识别VLA模型在接触丰富任务中的两类失败模式：精度失败源于流匹配策略训练不匹配，力失败源于力信号结构特性，提出FACT组合机制达到66%平均成功率。

**[Few-Shot Concept Prompt Learning for Segmentation Foundation Models via Visual Grounding](https://arxiv.org/abs/2608.01663)**
提出FS-CPL，从少量图像-掩码对学习连续概念提示嵌入，使SAM3和Medical SAM3在不重训练的情况下性能提升最多+0.62 Dice。

**[ProtoAct: Turning Wet-Lab Protocols into Embodied Robotic Actions](https://arxiv.org/abs/2608.01690)**
提出ProtoAct结构化协议接地框架，将生物湿实验室协议转换为状态感知的机器人可执行动作序列，支持仿真和真实机器人执行。

## 世界模型与规划

**[EmbodiedVAE: Disentangled Video VAE for Efficient and Controllable Embodied Manipulation](https://arxiv.org/abs/2608.02990)**
提出EmbodiedVAE视频VAE，通过双编码器单解码器架构和非对称时空压缩模块，自动解耦机械臂运动与背景环境，提供明确的具身潜在支持细粒度动作控制。

**[ProWorld: Progress-Aware Hyperbolic World Models for Long-Horizon Visual Goal Reaching](https://arxiv.org/abs/2608.01926)**
提出ProWorld双曲视觉世界模型，利用目标条件进度排序组织潜在动力学，双曲蕴含学习保持轨迹方向性，在四个视觉目标到达任务中平均成功率提升9.67。

**[DriftWorld: Fast World Modeling through Drifting](https://arxiv.org/abs/2607.15065)**
提出基于漂移生成模型的动作条件世界模型，单次前向即可生成未来帧，比扩散基线快17倍，在Bridge-V2等操作基准上实现SOTA决策性能。

**[Faster-WAM: Do World Action Models Need Deep Action Modules?](https://arxiv.org/abs/2608.02365)**
提出视频中心的设计原则，将单层动作头对接30层视频骨干，无需额外实体预训练，在LIBERO和RoboTwin 2.0上性能竞争力强，推断延迟低至66.5ms（比Fast-WAM快3.2倍）。

**(医疗机器人)**：包括手术机器人主动约束策略（FRAC）、触觉传感器（MVP-Tac）、导管-组织交互控制等。

**(人形机器人控制)**：包括全身运动控制、运动先验学习（PFM-HR、CMP）、疲劳建模等。
