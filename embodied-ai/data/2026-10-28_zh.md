# 今日 arXiv 机器人学与具身智能论文总结

## 一、世界模型 / 世界-动作模型（WAM）

这一方向今天非常密集，核心争论是：**世界模型应该预测什么，以及这种预测是否真的帮助控制**。

- **E0.5**：以 3D 基础模型为主干，将 3D 几何作为世界建模与动作预测的原生表征，显式预测未来 3D 状态。在 RoboTwin 2.0 上干净/随机设置分别达到 89.90%/50.09%，AgiBotWorld 预训练后真机提升约 15/7 个百分点。[E0.5: From Reconstructive to Future-Predictive 3D Foundations for Robotic World-Action Modeling](https://arxiv.org/abs/2610.36011)
- **Rollback**：把世界模型当作反事实引擎，回滚到关键决策点分支探索，将结果蒸馏为动作级监督。三个真机任务成功率提升 10.67%/11.11%/11.85%，8 小时内超过人类玩家平均水平。[Rollback: Experience Backtracking in World Models for Policy Improvement](https://arxiv.org/abs/2610.36068)
- **Trace-WAM**：在视频-动作学习之外加入未来 3D 运动预测作为辅助目标（点对应 + 图像位移 + 深度变化），在数据有限和分布偏移下对 Fast-WAM 增益明显。[Trace-WAM: Learning to Act via 3D Motion Prediction for World Action Models](https://arxiv.org/abs/2610.36840)
- **GAWM**：紧凑型潜在世界-动作模型，在冻结 DINOv3 潜在空间预测未来观测，参数量 <100M、无机器人/视频预训练，在 RoboTwin 2.0 超过十亿参数 WAM，LIBERO 与十亿参数 VLA 相当。[GAWM: A Compact Latent World-Action Model for Multi-Task Robot Manipulation](https://arxiv.org/abs/2610.37091)
- **JAM（Just Action Model）**：把"backbone 初始化 / 未来观测目标 / 推理时是否保留未来损失机制"三者解耦，指出 VLA 与 WAM 的差距不能归因于单一选择。仅用未来特征预测（无视觉生成），LIBERO/LIBERO-Plus 超过匹配的 FastWAM，训练 FLOPs 降低 73%。[Vision-Language-Action or World-Action? Just Action Models](https://arxiv.org/abs/2610.37219)
- **TAPESTRY**：把机器人动作当作视频模型潜在空间中的单 patch token，共享同一 DiT 主干，推理时单步 DDIM 生成动作块（84ms），无需测试时视频生成。[TAPESTRY: A Single Backbone for Video Generation and Robot Control](https://arxiv.org/abs/2610.36823)
- **RynnWorld-Latent**：以 3D-grounded 通用潜在动作为跨具身条件接口，在 23 个数据集（约 5.5 亿帧）上预训练，支持数字遥操作与潜在动作合成两条数据生成路线，提升 LIBERO/LIBERO-Plus 及真机策略成功率。[RynnWorld-Latent: A Cross-Embodiment World Model Conditioned on Universal Latent Actions](https://arxiv.org/abs/2610.36791)
- **World Dreamer v5-lite**：多机器人世界-动作模型，用共享世界状态（工作空间坐标下的校准特征）+ 每机器人一条 query，掩码视图协同训练；RoboFactory 74.0%（+23.7pt），四个真机任务 78.8%。[World Dreamer v5-lite: A Multi-Robot World Action Model with One Dreamer](https://arxiv.org/abs/2610.37518)
- **SWIM**：用逆动力学模型从离线轨迹学习状态特征权重，替代均匀加权来监督 JEPA 世界模型，五个仿真操作任务上规划成功率稳定提升。[SWIM: Learning What Matters from Behaviors for JEPA World Models](https://arxiv.org/abs/2610.36662)
- **Best-of-N 选择头room 分析**：提出去噪反事实协议测量"可选增益"，发现标准估计高估；结构化动作扰动可创造最多 16 点可选增益；失败门控选择器把闭环成功率从 76.9% 提到 81.6%（未见任务 62.6%→69.8%）。[How Much Can Best-of-N Help a World Action Model? Measuring Selectable Headroom and Realizing It in Closed Loop](https://arxiv.org/abs/2610.37196)
- **"世界建模到底改善了动作学习的什么"**：在 FastWAM/OpenWAM 上做控制消融，预测监督在已见任务干净条件下提升 24.38/72.91 个百分点，但在分布偏移下收益不稳定；把未来视频预测作为 π0.5 辅助目标可从 82.94% 提到 89.19%。[What Does World Modeling Actually Improve in Robot Action Learning?](https://arxiv.org/abs/2610.34593)
- **潜在世界模型的忠实性**：提出"忠实潜在世界模型"= 环境转移映射与学到的潜在动力学之间的等变性条件，并给出 latent rollout consistency 指标；结论是现有 SOTA 潜在世界模型没有一个真正忠实建模环境动力学。[Understanding the limits of latent world models](https://arxiv.org/abs/2610.37588)
- **MoGAP**：发现 WAM 中视觉监督应集中在动态区域，提出运动引导的非对称预测（动态区域加更多噪声、静态区域作上下文），Fast-WAM GR-1 从 38.8%→47.5%，Cosmos3-Nano 52.3%→62.3%。[Adapting Video Models for Robot Control via Motion-guided Asymmetric Prediction](https://arxiv.org/abs/2610.36624)
- 语义世界模型（VQA 式未来语义预测，而非像素重建）与动作相关表征分析（时间视频预训练而非重建保真度才是动作相关性的主因）也值得关注。[Semantic World Models](https://arxiv.org/abs/2510.19818)、[What Makes Video World Model Latents Action-Relevant: Prediction over Reconstruction](https://arxiv.org/abs/2606.07687)
- **R2A（Retrieve to Act）**：测试时把 OOD 鲁棒性转化为运动基元图检索问题，用 GNN 定位当前执行并检索兼容的未来运动基元，门控修正冻结 VLA 的动作；GR00T N1.7/π0.5/StableVLA 上仿真最高 +12%、真机 +40%，无需微调。[Retrieve to Act: Motion Primitive Graph Retrieval for Robust VLA Execution](https://arxiv.org/abs/2610.37215)

## 二、灵巧手 / 灵巧操作 / 手中操作

- **Torch-Hand**：21 自由度全连杆驱动仿人灵巧手（5-DOF 拇指 + 四指各 4-DOF），全连杆传动（非腱驱动），兼顾抓取力、负载与紧凑外形，完成工作空间、33 种抓取分类、负载与任务级操作评测。[A fully articulated humanoid dexterous hand with human-level joint structure enabled by linkage-based actuation](https://arxiv.org/abs/2610.36789)
- **手中物体姿态到达（In-Hand Object Pose Reaching）**：LEAP 手在仿真中无人类数据训练，通过多样重置/目标生成、自适应摩擦课程实现零样本真机迁移；13.3 小时、4800 个未见目标上基于状态策略达 95.2%（2cm/0.4rad 内），学习残差安全滤波器将掉落减少 75%。可用腕部深度相机作为便携技能（如拧灯泡）。[Pushing Dexterity and Safety for In-Hand Object Pose Reaching That Works Remarkably Well](https://arxiv.org/abs/2610.37652)
- **CARD**：接触锚定的重定向框架，从视频/mocap/触觉手套统一到共享手-接触表征，显式生成接触力目标并用触觉跟踪控制器在硬件上复现。接触帧保持率 43–78%（运动学方法 <10%、物体感知方法 22.5%），GRAB 上物理重定向成功从 12%→32%。配套 Vid-HACO 视频到接触模型。[CARD: Contact-Anchored Retargeting for Dexterous Manipulation](https://arxiv.org/abs/2610.36539)
- **从抓取到灵巧**：用 35.5 万条大规模灵巧抓取轨迹预训练低层目标条件控制器，再在下游 articulated tool use 任务微调；提出 DexCraft 基准（6 个工具使用任务），真机比 DP3 提升 33.3 个百分点。[From Grasps to Dexterity: Large-Scale Grasp Pretraining for Dexterous Manipulation](https://arxiv.org/abs/2606.30749)
- **BiDex-100**：双臂灵巧操作仿真基准，106 个任务、五条能力轴（泛化/指令跟随/少示教/长程/记忆）+ OOD 变体，两种具身、8,080 条验证过的遥操作示教（625 万帧），统一评测 7 个 VLA。[BiDex-100: A Comprehensive Benchmark for Bimanual Dexterous Manipulation Across 100+ Simulation Tasks](https://arxiv.org/abs/2610.25459)
- **EgoThumb**：视觉驱动的超数机器人拇指，双腱驱动、执行器移至前臂，用第一人称掌心相机图像直接映射到连续关节位置，开源硬件软件。[EgoThumb: A Vision-Driven Supernumerary Robotic Thumb for Autonomous Grasp and Holding Assistance](https://arxiv.org/abs/2610.37582)

## 三、触觉感知与接触丰富操作

- **FTP-1**：首个跨触觉传感器的通用触觉基础策略，用异构编码器把图像/阵列/状态型触觉信号投影到统一形态感知潜在 token，约 3000 小时、26 个数据源、21 种传感器预训练；已见传感器配置 +17.2%，两个未见传感器配置 +31%。[FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation](https://arxiv.org/abs/2606.13102)
- **FAWAM**：力感知世界-动作模型，在感知（编码 6 轴力/力矩）、预测（联合预测未来动作与末端力旋量）、执行（以预测力旋量轨迹为参考的残差在线修正）三个层面使用力；接触丰富任务平均成功率比纯视觉基线 +36.25%，比现有力感知基线 +21.25%。[FAWAM: Force-Aware World Action Models for Closed-Loop Contact-Rich Manipulation](https://arxiv.org/abs/2606.08555)
- **DreamTacVLA**：高分辨率触觉图像作为"微视觉"输入，与腕部局部视觉、第三人称全局视觉组成层级感知，用 HSA 损失对齐触觉 token 的空间对应，并用触觉世界模型预测未来触觉信号；接触丰富任务最高 95% 成功率。[Learning to Feel the Future: DreamTacVLA for Contact-Rich Manipulation](https://arxiv.org/abs/2512.23864)
- **主动硬度分类**：用视觉触觉传感器（VBTS）+ 信息论不确定度驱动的主动采样，准确率 90%，远高于人类 48%。[Investigating Active Sampling for Hardness Classification with Vision-Based Tactile Sensors](https://arxiv.org/abs/2505.13231)
- **双臂非抓取操作保持接触**：用有符号摩擦距离定义摩擦裕度，从平衡枢轴力矩偏差推导任务自适应裕度，嵌入一系列 SOCP；真机验证优于固定裕度/无裕度。[Keeping Contact: Task-Adaptive Friction Margins for Bimanual Non-Prehensile Manipulation](https://arxiv.org/abs/2610.36961)
- **ActiveAlign**：以主动感知对齐 Real2Sim 差距——挥手做手眼标定（可微渲染）+ 触摸用触觉反馈做毫米级物体对齐，在 Unitree G1 上实现按按钮、移滑块等毫米级精细操作。[ActiveAlign: Aligning Egocentric Manipulation via Active Perception](https://arxiv.org/abs/2610.36859)
- **时序触觉 + 柔顺控制的双臂人-机器人交接**：VLA + 柔顺控制器，触觉时间编码捕捉持续"拿取意图"；人类被试研究显示两组件互补、显著优于基线。[Temporal Tactile Encoding and Compliance for Intent-Aware Robot-to-Human Bimanual Handover](https://arxiv.org/abs/2609.05282)

## 四、视觉-运动策略 / VLA 与模仿学习

- **RoboAuto**：Code-as-Policy 式机器人程序搜索，显式组织物体/场景/交互三级物理理解（层级知识库 + 场景 grounding + 多阶段自设计实验）；LIBERO-PRO 短程 89.1%，长程与 LIBERO-Plus 平均成功率超 ASPIRE 两倍以上，三个长程真机任务优于 ASPIRE 与 π0.5。[RoboAuto: Autonomous Robot Program Search through Multi-Level Physical Understanding](https://arxiv.org/abs/2610.36533)
- **TOPS**：按任务重塑 flow 源先验与插值调度（反向映射专家动作构造多模态源 + 基于协方差失配的调度），不改网络结构；LIBERO-10 单步 53.44%→69.67%，推理时间约 1/6，迁移到 π0.5 也有一致增益，真机开上抽屉 20%→80%。[TOPS: Reshaping Flow Source and Transport for Multi-Task Robot Manipulation](https://arxiv.org/abs/2610.36694)
- **PDRVLA**：轻量物理动力学模块从视觉-语言特征提取物理 token 来条件化动作生成，无需在线视频生成；用未来 RGB/深度/光流特征预测 + 冻结视频世界模型辅助监督；LIBERO 99.3%、LIBERO-Plus 89.9%、RoboTwin 2.0 93.6%、SimplerEnv 81.5%。[PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations](https://arxiv.org/abs/2610.37381)
- **AFIL（ Adaptive Failure-Informed Learning）**：用预训练 VLA 在线生成失败 rollout，共享视觉-语言主干联合训练成功/失败双动作生成器，采样时按逐步分布距离自适应引导远离失败区域。[Tokens of Motion: Primitive Motion Learning for Human-Humanoid Skill Transfer](https://arxiv.org/abs/2610.37330)（注：标题与内容不一致，请以摘要为准）
- **RePO-VLA**：恢复驱动策略优化，区分成功/恢复/失败轨迹：Recovery-Aware Initialization 切片纠正后缀、Progress-Aware Semantic Value Function 打标签、Value-Conditioned Refinement 偏好高进展动作；提出 FRBench，对抗成功率 20%→75%（真机最高 80%）。[RePO-VLA: Recovery-Driven Policy Optimization for Vision-Language-Action Models](https://arxiv.org/abs/2605.09410)
- **VLA-Stem**：不微调 VLA，把动作块转成运动参考，用 RL 训练的 Stem 策略结合本体感受与局部障碍信息在执行时自适应修正；六个受限仿真设置平均无碰撞成功率 52.8%（最强安全基线 23.7%）。[VLA-Stem: A Lightweight Safety Mechanism for Vision-Language-Action Models via Reinforcement Learning](https://arxiv.org/abs/2610.37378)
- **ARC（Adaptive Residual Correction）**：用稀疏人类纠正决定"何时"启用残差、纠正几何决定"何处"探索、任务奖励决定"做什么"，真机三个精细操作任务平均成功率 33.3%→75.0%。[When, Where, and What to Correct: Human-Guided Adaptive Residual Correction for Robot Policies](https://arxiv.org/abs/2610.37547)
- **HIDRA**：无回放的终身模仿学习，层级双注意力把指令级专家检索与上下文相关细化解耦，并加入 key 级几何正则；LIBERO 多个套件上 AUC 与前向迁移优于无回放和有回放基线。[HIDRA: Hierarchical Dual-Routing Attention for Replay-Free Lifelong Imitation Learning](https://arxiv.org/abs/2610.36374)
- **SCRIM**：把模仿学习中的"状态关键性"形式化为专家动作有界扰动导致的下游价值最坏退化，用对抗扰动策略 + 价值 critic 估计，用于重加权 BC 损失与数据筛选。[Where Small Mistakes Matter: Quantifying State Criticality for Imitation Learning](https://arxiv.org/abs/2610.17709)
- **ACT / Diffusion Policy / SmolVLA / π0.5 数据规模实证**：在 SO-101 上 1340 个计分回合，ACT 从 12 条示教的 1/40 提升到 100 条的 37/40；π0.5 在少数据时最好（12 条 16/40），100 条后 ACT 领先；SmolVLA 47% 回合机械臂根本没启动；π0.5 的微调配方比数据量更重要（LoRA 4/110 vs 动作专家 130/200）。[From 12 to 200 Demonstrations: How ACT, Diffusion Policy, SmolVLA and $\pi_{0.5}$ Scale on a Low-Cost Arm](https://arxiv.org/abs/2610.37170)
- **QCP（质量可控策略）**：推理时可控制执行速度/平滑度等质量属性及其组合，并用迭代 hindsight relabeling 扩展可控范围；真机传送带吞吐与端酒杯稳定性验证。[Learning Quality-Controllable Robot Policies with Iterative Hindsight Relabeling](https://arxiv.org/abs/2610.37393)
- **离散 vs 连续动作参数化**：在单任务/多任务 VLA、仿真与真机上系统比较，发现朴素均匀分箱的离散动作预测可匹配甚至超过连续策略，瓶颈是 factorization error 而非精度；配合离散 flow / CFG 可化弱为强。[When Do Discrete Actions Make Good Continuous Controllers?](https://arxiv.org/abs/2610.20429)
- **Ego-CEVR**：分层视觉表征学习——全局模块在第一人称视频上做未来预测学物体关系/任务状态/时序进度，交互模块用腕部观测 + 机器人动作监督学局部对齐与接触线索，两条残差路径分别进入策略。[Ego-CEVR: Learning Cross-Embodiment Visual Representations from Human Egocentric Videos](https://arxiv.org/abs/2610.37509)
- **ThinkWorld**：把动作思维表示为 Chain-of-Dynamics（离散运动 token 序列）作为跨具身共同动作表征，用世界想象 RL 强化预测更贴合观测结果的 CoD，使无动作标注的人类视频可提供直接监督。[ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning](https://arxiv.org/abs/2610.37666)
- **Semantic-Geometric 双臂任务表征**：语义-几何图编码物体身份、物体间语义关系与每物体运动历史，MPNN 编码器 + Transformer 解码器，部署时结合 ProMP，两个真机双臂任务全成功，优于图消融、Transformer、仅解码器和微调 VLM 基线。[Semantic-Geometric Task Representations for Bimanual Manipulation from Human Demonstrations to Robot Action Planning](https://arxiv.org/abs/2601.11460)
- **RoboSTD**：零样本单臂→双臂迁移，用矢状面镜像构造对侧伪示教，再用 LLM 生成结构化时空协调约束重构伪双臂监督；RoboTwin + 真机 ALOHA，杯子收集任务平均收集数为单臂基线 2.11 倍。[RoboSTD: Zero-Shot Single-to-Dual Transfer via Sagittal Mirroring for Bimanual Learning](https://arxiv.org/abs/2610.36685)

## 五、遥操作与数据采集接口

- **OpenJaws**：全开源硬件+软件的传感器化 UMI 框架，模块化 3D 打印夹爪（ISO 标准转接）+ 低成本双目相机恢复度量尺度轨迹；提出 UMI-Loc-Bench-v1 定位基准，显示双目显著优于单目；策略可在真机多任务部署。[OpenJaws: An Open Hardware UMI Framework with Stereo Localization for Generalist Manipulation](https://arxiv.org/abs/2610.36598)
- **MILD + AprilVINS**：面向 UMI 式示教采集的定位数据集与基准（Insta360 X5 / Insight9，15 个桌面任务，86 条序列）+ Isaac Sim 子集；AprilVINS 结合鱼眼 VIO 与序列局部 AprilTag 几何，在统一协议下达到毫米级 TCP 相对 APE 并保持高时间覆盖率。[Towards Accurate End-Effector Localization for UMI-Style Robotic Manipulation Teaching](https://arxiv.org/abs/2610.09857)
- **HumiTransfer / HumiMimic**：从野外人类-人类交互视频迁移到人-人形交互，先用脚-地接触一致重建 3D 人体运动，再用加权关节相对方向与解剖偏移做交互建模，后处理优化保证平衡/接触/避碰；对 1200 段视频生成约 50 万帧数据，用于 26-DoF Unitree R1 Edu 与 23-DoF Mini-hi，真机验证可执行。[Mimetic Embodiment Transfer of Human-Humanoid Interaction from In-the-Wild Videos](https://arxiv.org/abs/2610.36615)
- **多相 loco-manipulation（相位条件策略优化）**：扩展 PPO 用相位条件 critic、相位门控奖励、多相重置课程，解耦层级控制分离低层平衡与高层相位执行；在 Unitree G1 与带臂 Spot 上验证蹲伏/抓取/移动的长程任务。[Learning Multi-Phase Robot Loco-Manipulation via Phase-Conditioned Policy Optimization](https://arxiv.org/abs/2610.36270)

## 六、Sim-to-Real 与仿真基础设施

- **IDTD**：信息解耦轨迹设计用于 sim-to-real 系统辨识，基于 Fisher 信息的 Schur 补分数构造探索目标，并做逐参数归一化与对数聚合；Go2/G1/Crazyflie 等上参数辨识误差平均降低 39.6%，并在真实 K1 人形上验证。[Informationally Decoupled Trajectory Design for Sim-to-Real System Identification](https://arxiv.org/abs/2610.10905)
- **ActiveAlign**（见触觉部分）同时也是 real2sim 对齐的代表工作。[ActiveAlign: Aligning Egocentric Manipulation via Active Perception](https://arxiv.org/abs/2610.36859)
- **BiDex-100**、**DexCraft**、**RoboTwin 2.0 相关评测**均为操作任务 sim-to-real / sim 评测的重要基础设施（链接见上）。
- **DeFM**：纯深度图像自监督（DINO 式自蒸馏）的机器人基础表征，6000 万深度图训练，提出输入归一化策略保留多尺度度量感知，并蒸馏为紧凑模型；深度分类/分割/导航/行走/操作基准 SOTA，可开箱即用。[DeFM: Learning Foundation Representations from Depth for Robotics](https://arxiv.org/abs/2601.18923)
- **cuArms**：GPU 并行冲突式多臂规划器，用可复用多模态 roadmap + 惰性搜索解冲突与死锁，结合高层调度器联合优化任务分配/调度/运动/操作技能；实时初始解 + anytime 改进，无需领域训练。[cuArms: GPU-Accelerated Conflict-Based Planning for Multi-Arm Manipulation](https://arxiv.org/abs/2610.36250)
- **Mobile manipulation 非刚性基座效应**：以打磨为案例，在两种轻量轮式平台上联合测量接触力、工具运动与基座振动；低基座-地面阻力下 100N 指令只实现 54–70%，TCP 误差达 100mm。[On Shaky Ground: Characterising Non-Rigid Base Effects in Mobile Manipulation](https://arxiv.org/abs/2610.36725)
- **混合软-刚空间机械臂状态估计**：末端为腱驱动连续体，MAP 推断 + 因子图融合关节编码器与视觉，采用 GVS 最小阶参数化，仿真闭环轨迹验证。[State estimation for a hybrid rigid-continuum space manipulator system](https://arxiv.org/abs/2610.37043)

## 七、人形 / 腿足运动与全身控制（与操作相关部分）

- **GRAFT**：冻结人形行为基础模型（BFM），只加轻量几何感知残差适配器修正下肢执行目标，用任务与足部几何奖励训练并从特权地形蒸馏到机载深度；四个冻结 tracker 上验证楼梯/沟壑/平台，Unitree G1 真机部署。[GRAFT: Geometry-Aware Residual Adaptation for Foundation Trackers](https://arxiv.org/abs/2610.36507)
- **REACH**：RL 分层框架让 Unitree G1 通过变高双足行走（1.27–0.50m）与爬行（0.50–0.20m）穿越受限空间，历史条件潜在表征处理接触丰富爬行，双向过渡策略连接两种模式，配合 LiDAR 规划器。[REACH: An RL-based Hierarchical Humanoid Crawling Framework for Adaptable Confined Space Traversal](https://arxiv.org/abs/2610.36546)
- **HC2Robot**：可部署感知人形跑酷，Predicted Foresight Module 从可部署观测预测下一次触地的时间/位置/支撑质量（把特权监督转成可部署潜在表征），Hyper-Connection Transformer 增强时序推理；楼梯/沟壑/高台/斜坡平均仿真通过率 97.60%。[HC2Robot: Hyper-Connection Transformers with Predicted Foresight for Multi-Terrain Humanoid Parkour](https://arxiv.org/abs/2610.36825)
- **随机运动 tokenization 全身控制**：用简洁运动表征（可由高层控制器按行为标签/文本生成）条件化跟踪策略，随机运动 tokenizer 在 Unitree G1 上重建质量超过 FSQ 与 VQ-VAE，执行 16.8s 舞蹈/格斗/行走及 35s 格斗→舞蹈序列。[Whole-Body Humanoid Control via Stochastic Motion Tokenization](https://arxiv.org/abs/2610.36452)

## 八、机器人学习效率 / 边缘部署 / 评测

- **VLA-HWBench**：18 个开源 VLA 在 Jetson AGX Thor 与 AMD Ryzen AI Max+ PRO 395 上的七阶段推理拆解。关键结论：动作生成策略比模型规模更重要（19 个 Jetson 配置中 14 个由它主导，延迟差 82×/157×，参数量最多解释 15% 方差）；4-bit 权重 + kernel fusion 对 π0.5/GR00T N1.7 提速 2.6–2.9×，但仅限这两个模型且仅 Jetson；优化后 CPU 预处理占比从 12% 升到 39%。[VLA-HWBench: Where the Time Goes When VLA Models Run on Edge Hardware](https://arxiv.org/abs/2610.34717)
- **TS-DP**：指出 Diffusion Policy 是 I/O bound 而非 compute bound，首次把投机解码用于 DP：Transformer drafter 蒸馏 + RL 调度器按任务难度时变调整投机参数；仿真最高 4.17× NFE 降低、3.2× 墙钟加速，接受率 >85%，真机 3.8× NFE 降低且传送带任务成功率 +23%，达 26Hz。[TS-DP: Reinforcement Speculative Decoding For Temporal Adaptive Diffusion Policy Acceleration](https://arxiv.org/abs/2512.15773)
- **MO-Playground / MORLAX**：GPU 原生多目标 RL 算法与可 pip 安装的并行多目标环境集，分钟级近似 Pareto 集，比 CPU 方法快 26–271×，并实现 BRUCE 人形 6 目标行走策略学习。[MO-Playground: Massively Parallelized Multi-Objective Reinforcement Learning for Robotics](https://arxiv.org/abs/2603.09237)
- **校准与不动点**：关于世界模型不确定性校准随部署策略变化而失效的理论与 Franka 实验（普通 90% conformal 覆盖降到 55.0%，学习比率校准 90.9%）。[Calibrated for Which Policy? Conformal Uncertainty for Fixed World Models Under Intervention](https://arxiv.org/abs/2610.35877)
- **铰接物体操作评测 CRS**：把末端指令 twist 投影到物体关节轴，分离沿关节进展与离约束浪费；在 74 个仿真铰接物体上揭示成功率无法归因的迁移失败，门训练策略开抽屉 59/110 但离轴旋转约为抽屉训练策略的 40 倍。[Kinematic Constraint-Referenced Evaluation for Articulated Object Manipulation](https://arxiv.org/abs/2610.37550)
- **双臂工具使用失败诊断**：在仿真双臂工具使用任务上测量各传感通道能读出什么——工具滑脱在工具手上读、哪只手慢需双臂、单手传感器只能读自身延迟；VLM 内部状态几乎完美编码"慢的那只手"但答案措辞决定是否报告。[Which Hand Was Late? Diagnosis for Robot Failure Recovery in Bimanual Tool Use](https://arxiv.org/abs/2610.37533)

## 九、其他值得一瞥（非核心但相关）

- **Robotic pipe stabbing**：摆锤 Kalman 滤波 + ResNet-18 关键点 + 残差 RL，200 组随机作业全部就位（传统固定导向 74%），中位接触速度 18.4→2.3 cm/s，峰值力 11.3→1.4 kN。[Predict the Swing, Match the Speed: Robotic Pipe Stabbing With Learned Stereo Vision and Residual Reinforcement Learning](https://arxiv.org/abs/2610.37535)
- **可微仿真穿越动态窄缝**：可微 moving-gap 公式把稀疏穿越事件变成稠密路径目标，单阶段从随机初始化训练视觉-惯性策略，仿真 99.3%，真机 10 次 8 成功。[Learning Visuomotor Quadrotor Flight Through Dynamic Narrow Gaps via Differentiable Simulation](https://arxiv.org/abs/2610.37557)
- **Rendering-free 事件相机仿真**：解析事件仿真器直接从场景几何与自运动合成事件流，64×64 观测 17µs（比渲染管线快 400×），30 分钟内收敛，零样本迁移到 Isaac Sim 光线追踪事件仿真，并量化部署到 56g Crazyflie（Prophesee GenX320 + OpenMV N6），三个真实赛道平均 82%。[Rendering-Free Event Frame Simulation for Fast Reinforcement Learning of Autonomous Robot Navigation](https://arxiv.org/abs/2610.37543)
- **自主固定翼拦截 RL**：单目视觉观测直接映射到舵面指令，仿真与真机均成功拦截机动固定翼目标。[Autonomous fixed-wing interception using reinforcement learning](https://arxiv.org/abs/2610.37470)
- **Omni-IGN**：四鱼眼 + 注意力 RL 策略 + 碰撞安全层的全机载 ImageNav，Habitat 连续动作基线最佳，IsaacSim 验证，真机零样本 sim-to-real 无微调无外部定位。[Omni-IGN: Onboard Image-Goal Navigation for Drones with Omnidirectional Vision](https://arxiv.org/abs/2610.36968)
- **机器人技能优化 / agent harness 方向**（与机器人学习流程相关）：BiPA 质疑通用技能优化器的收益是否只是选择偏差（dev 增益在测试集消失，输入 token 多读约 16%）。[Does Your Generalist Skill Optimizer Really Incentivize Agentic Tasks? Rethinking Skill Optimization via Bipartite Attribution](https://arxiv.org/abs/2610.37201)

## 一句话趋势观察

1. **WAM 进入"祛魅"阶段**：今天多篇工作（JAM、Trace-WAM、MoGAP、Best-of-N 分析、"世界建模到底改善了什么"、潜在世界模型忠实性）都在拆解"未来预测到底哪一部分有用"，结论倾向于：**动作相关的时序预测结构 > 像素重建保真度**，且收益在分布偏移下并不稳定。
2. **触觉/力从辅助观测变成一等公民**：FTP-1（跨传感器基础触觉策略）、FAWAM（力进入预测与闭环修正）、DreamTacVLA（触觉世界模型）共同指向"接触动力学建模"作为下一阶段重点。
3. **灵巧手硬件与手中操作同步推进**：Torch-Hand（全连杆 21-DoF）与 in-hand pose reaching（零样本真机 + 安全滤波器）显示硬件可控制性与学习可扩展性正在对齐。
4. **数据接口标准化**：OpenJaws（开源 UMI + 双目定位基准）、MILD/AprilVINS（定位评测数据集）在补"示教数据质量可度量"这一课。
