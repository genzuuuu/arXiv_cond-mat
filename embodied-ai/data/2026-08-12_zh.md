1.  **[FACT: Failure-Aware Causal Training for World-Action Models](https://arxiv.org/abs/2608.10232)**：提出FACT框架，一种因果世界-动作模型（WAM）。其核心创新是让世界模型能够感知并学习失败轨迹的结果，通过动作条件接口将失败经验转化为有效的训练信号，从而提升模型在复杂操作任务中的表现，并减少在错误动作下的"幻觉"预测。
2.  **[JEPA-WAM: Stage-Level Joint-Embedding Prediction for World-Action Models in Robot Manipulation](https://arxiv.org/abs/2608.10780)**：提出JEPA-WAM，在传统世界-动作模型（WAM）基础上，引入目标条件下的联合嵌入预测架构（JEPA），显式地建模任务从当前阶段到下一阶段的"语义级未来"，以更好地指导长时程任务的操作策略。
3.  **[Flex-π: A Multi-Stream World-Action Model with Compute Flexibility](https://arxiv.org/abs/2608.10860)**：介绍Flex-π，一个60亿参数的世界-动作模型。该模型能够利用同一个冻结的VAE在共享潜在空间中处理RGB、3D点图和语义特征，并在推理时通过流dropout实现计算灵活度，在多种操作任务上展现了卓越的演示效率和泛化能力。
4.  **[World Action Models in Real Time: An Empirical Study of Smooth Execution via Asynchronous Deployment](https://arxiv.org/abs/2608.01880)**：对世界-动作模型（WAM）在真实机器人上的异步部署策略进行了实证研究，比较了六种同步和异步执行策略，指出精确的时间对齐是保证动作平滑执行的关键，并推荐了前缀条件生成等方法。
5.  **[Learning in ImaginationLand: Omnidirectional Policies through 3D Generative Models (OP-Gen)](https://arxiv.org/abs/2509.06191)**：提出OP-Gen框架，利用3D生成模型从单一真实世界演示中生成全方位视角的增强数据，从而训练出对初始状态不敏感的机器人操作策略，显著增强了策略的泛化能力。
6.  **[Diffusion-Based Impedance Learning for Contact-Rich Manipulation Tasks](https://arxiv.org/abs/2509.19696)**：提出一种基于扩散模型的阻抗学习框架。该方法将生成模型与能量一致的阻抗控制相结合，通过从遥操作演示中学习柔顺轨迹，实现了在接触丰富的操作任务（如多几何体插孔）中的高成功率。
7.  **[Discovering Diverse Planning Policies for Multimodal Embodied Agents with Quality-Diversity Optimization](https://arxiv.org/abs/2608.08523)**：提出使用质量-多样性（QD）优化框架为多模态具身智能体发现多样化的规划策略，以解决在执行过程中陷入局部停滞的问题，提高长时程任务的效率和成功率。

### 灵巧操作、抓取与触觉感知

1.  **[Real-World Cooperative Bimanual Dexterous Grasp of Large Objects from Single-View Observations](https://arxiv.org/abs/2608.10383)**：提出了一个真实世界的双臂灵巧抓取大型物体的框架，该系统利用扩散模型从单视角点云生成关节级抓取配置，并结合运动规划与在线抓取优化，实现了对未见物体的鲁棒抓取。
2.  **[OmniVTA: Visuo-Tactile World Modeling for Contact-Rich Robotic Manipulation](https://arxiv.org/abs/2603.19201)**：构建了大规模视觉-触觉-动作数据集OmniViTac，并提出了OmniVTA框架，整合了自监督触觉编码器、视觉-触觉世界模型和接触感知融合策略，利用60Hz高频触觉反馈闭环控制，在接触丰富的操作任务中表现优异。
3.  **[Tri-Manual Visuomotor Imitation Learning of Robot Policies](https://arxiv.org/abs/2607.25731)**：提出TriManPolicy，一个用于三臂系统的模仿学习框架。通过其核心组件依赖感知三臂调度（DATS），离线重新编排示教时间，使单个操作员能有效示教三臂协调任务，并训练出单一同步策略。
4.  **[Precise Top-Layer Fabric Segmentation for Fabric Destacking with Edge- and Shape-Aware Deep Networks](https://arxiv.org/abs/2608.10648)**：针对布料拆垛任务，提出一种用于顶层布料精确分割的训练架构，通过引入边缘感知和形状感知分支，提升了对堆叠布料中细微边界的分割精度。
5.  **[HM3D: Embodied Multimodal Grounding for Open-Vocabulary Mobile Manipulation via Semantic 3D Gaussian Splatting](https://arxiv.org/abs/2608.10756)**：提出了一个用于开放词汇移动操作的具身多模态基础框架，该框架集成了主动多视角语义3D高斯泼溅、可达性感知的基座定位和基于扩散的视觉-语言-动作策略，在复杂和杂乱场景中显著提升了长时程任务成功率。

### 视觉-语言-动作模型 (VLA)与遥操作

1.  **[Lost in Reconstruction: Aligning Action Representations with Language in Vision-Language-Action Models](https://arxiv.org/abs/2608.10484)**：发现VLA模型中的动作表示重构目标（L1/L2损失）会侵蚀动作轨迹中的语言学信息，为此提出SALT（语义对齐动作分词器），通过辅助目标让模型从动作表示中恢复指令，从而提升语言条件控制性能。
2.  **[BooST: Bridging Semantics and Motions for Efficient Skill Transfer](https://arxiv.org/abs/2608.10600)**：提出BooST，一个两阶段的技能迁移框架。它利用跨模态VQ-VAE统一了语义意图和运动动力学，并将这种统一表示蒸馏到轻量级策略中，实现了高效的少样本适应和跨领域技能迁移，适用于真实机器人部署。
3.  **[A Neural Network Based Teleoperation for Remote Controlled Vehicles](https://arxiv.org/abs/2608.10367)**：提出了一个单边遥操作框架，结合波变量（WV）方法保证时延下的稳定性，并利用自适应径向基函数网络（RBFN）补偿车辆模型不确定性，在硬件在环实验中验证了其鲁棒性。
4.  **[TCAM for Autonomous Deformable Manipulation: The RMC2 Champion System for WBCD 2026 Track 4](https://arxiv.org/abs/2608.10718)**：介绍了RMC2团队在WBCD 2026 Track 4比赛中获得冠军的自主可变形操作（衣物抓取和折叠）系统，该系统围绕因果动作模型（TCAM）构建，通过定制夹具、多视角相机和UMI风格示教收集数据，实现了高效的全自动操作。
5.  **[Surgical WAM: A World-Action Model for Data-Efficient Surgical Robot Learning](https://arxiv.org/abs/2608.11204)**：提出Surgical WAM，一个用于手术机器人的世界-动作模型。它首先在无动作标签的内窥镜视频上预训练视觉动力学，然后在有限的带标签数据上进行微调，通过预测未来观测和动作段，在接触丰富和双臂协调的手术任务中显著提升了数据效率。

### 仿真到现实 (Sim-to-Real) 与导航规划

1.  **[Whole-Body Planning for Humanoids Navigating Confined Spaces via Self-Collision Avoidance References](https://arxiv.org/abs/2608.10220)**：为在狭窄空间中导航的人形机器人提出了一种三阶段全身规划框架，通过将可微碰撞避免与可达性约束相结合，生成体积感知的引导路径，并利用残差强化学习策略进行鲁棒的在线执行。
2.  **[Navigating the Proximity-Safety Balance: Constraint Decomposition for Human Following in Pedestrian Crowds](https://arxiv.org/abs/2608.10056)**：将人群中的跟随任务分解为稀疏任务奖励和独立成本约束，提出多约束强化学习框架，允许对接近-安全平衡进行显式且可调的精确控制，并在真实机器人上得到验证。
3.  **[Wind-Informed Rapid Flight-Planning in Complex Urban Topologies via Machine Learning and Experimental Validation](https://arxiv.org/abs/2608.10309)**：提出一种用于城市环境中无人机安全飞行的规划框架，该框架使用学习代理模型快速预测风场，并据此生成风感知的飞行轨迹，在风洞实验中验证了其有效性和稳定性。
4.  **[Risk-Aware Kinodynamic Motion Planning Under Uncertainty For Safe Navigation on Planetary Environments](https://arxiv.org/abs/2608.11175)**：针对行星探测场景，提出了一个风险感知的动态运动规划框架，结合了采样规划器（AO-RRT）和序列凸规划（SCP），并利用条件风险价值（CVaR）来量化风险，显著降低了轨迹风险。
5.  **[Learning an Interior Layout Policy in a Domain Specific Language Action Space](https://arxiv.org/abs/2608.07547)**：提出LayoutDSL，一个基于LLM的室内布局策略学习框架，通过将布局推理转换为领域特定语言（DSL）中的结构化动作，并结合强化学习进行优化，提高了空间布局的合理性和设计逻辑性。
6.  **[MPPI Planning with Gaussian-Based Human Cost Function for Social Navigation](https://arxiv.org/abs/2608.08323)**：提出预测性高斯交互场（PGIF），一种时空成本函数，通过在规划周期内预测行人位置并将其编码为各向异性高斯排斥场，使MPPI规划器能生成更安全的社交导航轨迹，降低了碰撞风险。

6.  **[Autonomous Exploration-Based Precise Mapping for Mobile Robots through Stepwise and Consistent Motions](https://arxiv.org/abs/2503.17005)**：提出了一种自主探索框架，通过步进一致性运动策略和基于图SLAM的闭环检测，在简化运动模式的同时提高了建图的一致性和精度。
