### 一、 模仿学习与策略学习

**1. 数据选择与鲁棒性**
*   **[It's Not Just More Demos: Counterfactual Action Sensitivity Coverage for Data-Efficient Robust Robot Imitation](https://arxiv.org/abs/2607.27261)**：提出CFNBC框架，通过测量策略在干扰下的“动作漂移”来选择最具修复价值的数据，用远少于随机采样的数据量即可显著提升策略对视觉干扰的鲁棒性。
*   **[Static In, Dynamic Out: Counterfactual Action Augmentation for Moving Object Manipulation](https://arxiv.org/abs/2607.27890)**：提出了SIDO方法，通过反事实动作增强，使仅使用静态物体演示训练的策略，能够在测试时泛化到运动物体上，将任务分解为“预测位置”和“到达位置”。
*   **[Machines that know they are aging: a framework for hardware-aware autonomous intelligence](https://arxiv.org/abs/2607.28451)**：提出AAA框架，将硬件健康状态直接集成到机器人推理、规划和任务执行中，使机器人能够感知并适应自身性能随时间的退化。

**2. 策略优化与微调**
*   **[RedFlow: Redirect Failure into Action-Level Corrections for Flow-matching VLA Policy](https://arxiv.org/abs/2607.27782)**：提出细粒度的离线强化学习框架，将失败经验重定向为动作级别的纠正信号，用以微调Flow-matching VLA策略，在LIBERO和真实世界任务中表现优于现有基线。
*   **[FA-RDP: A Frequency-Adaptive Reactive Diffusion Policy for Contact-Rich Manipulation](https://arxiv.org/abs/2607.28596)**：针对接触丰富的操作中，接触前多模态与接触后响应速度的矛盾，提出自适应频率的扩散策略，通过多频Transformer和流形一致性蒸馏来平衡二者。
*   **[World Action Planner: Generalizable Decision-Making with Action-Conditioned World Models](https://arxiv.org/abs/2607.27599)**：提出一种新型机器人规划系统，结合了VLM的推理能力和多任务世界模型的物理基础，通过想象世界模型的推演来迭代优化动作计划，在零样本泛化上优于端到端策略模型。

**3. 跨具身与技能迁移**
*   **[Cross-Embodiment Transfer via Behavior-Aligned Representations](https://arxiv.org/abs/2607.27549)**：研究了行为对齐表征（如物体边界框、末端执行器轨迹）在VLA模型中对跨具身迁移的作用，发现“末端执行器轨迹”对迁移性能特别有益。
*   **[UniCross: Unified Cross-Skill Dexterous Manipulation Synthesis](https://arxiv.org/abs/2607.28198)**：提出了一个统一框架，将抓取、重定位、手内旋转和平移四种灵巧操作技能在统一的公式下建模，并成功蒸馏出一个跨技能策略，可无缝组合成长期操作任务。
*   **[SemAnCorr: Semantic Anchored Correspondence for Zero-Shot Manipulation Skill Transfer](https://arxiv.org/abs/2607.28382)**：通过联合位姿-对应优化选择语义一致的锚点区域，并利用函数映射传播约束，建立语义一致且几何连贯的稠密对应关系，实现零样本的技能迁移。

### 二、 触觉感知与传感器

**1. 新型触觉传感器**
*   **[FasTac: A Curved Multispectral Vision-Based Tactile Sensor for High-Speed High-Precision 3D Shape and Force Perception](https://arxiv.org/abs/2607.28416)**：介绍了一种曲面多光谱视觉触觉传感器，通过多光谱光度立体视觉和FPGA硬件加速，在紧凑设计中实现了高精度3D形状重建、三轴力估计和高速处理。

**2. 触觉与策略学习**
*   **[TacWAM: Anchor-Guided World Action Model with Mechanics-Aware Tactile Prediction](https://arxiv.org/abs/2607.28391)**：提出一种力觉感知的世界动作模型，利用未来触觉状态的预测作为监督信号，在不作为行动生成的特权信息的前提下，提升接触丰富操作的性能。
*   **[τ: Learning Touch-Augmented Vision-Language-Action Models from Future Visual Supervision](https://arxiv.org/abs/2607.24485)**：提出一种触觉增强的VLA框架，通过JEPA架构从未来的视觉监督中学习动作条件下的时空触觉表征，并将其与视觉-语言特征融合以生成动作。
*   **[SharedAssembly: A Data Collection Approach via Shared Tele-Assembly](https://arxiv.org/abs/2503.12287)**：提出一种共享自主的双边遥操作框架，通过在领导端和从动端嵌入装配智能，极大降低了高精度、小间隙装配演示数据的采集门槛。

### 三、 遥操作与数据采集

*   **[DexDirect: Direct Kinesthetic Arm Guidance for Efficient Dexterous Demonstration Collection](https://arxiv.org/abs/2607.27784)**：提出一种直接动觉引导的数据采集方法，操作员直接拖动机械臂，同时通过单目摄像头重定向手部姿态，用较低成本实现了高效、低认知负荷的灵巧操作数据采集。

### 四、 世界模型与具身智能

*   **[ODEWorld: A Continuous Predictive Architecture via Physical-Time Flow](https://arxiv.org/abs/2607.27924)**：提出了物理时间流（PT-Flow），一种学习连续潜速度场的新颖方法，将未来预测视为在压缩潜空间中的时间积分（ODE求解），支持任意时间分辨率甚至反向预测。
*   **[LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments](https://arxiv.org/abs/2607.23969)**：提出一种基于JEPA的新型世界模型范式，放弃了像素级视频生成，转而进行预测性语义对齐和隐空间中的物理动力学提取，提高了效率和鲁棒性。
*   **[Do World Action Models Generalize Better than VLAs? A Robustness Study](https://arxiv.org/abs/2603.22078)**：对最先进的VLA和WAM策略进行了比较研究，在视觉和语言扰动下评估其鲁棒性，结果表明WAM通常具有更强的鲁棒性。

### 五、 机器人系统与仿真

*   **[Simulation of Surgical Suturing Using Position-Based Dynamics and the Material Point Method for Robot Reinforcement Learning](https://arxiv.org/abs/2607.27494)**：为机器人手术缝合模拟构建了一个新环境，使用PBD模拟缝合线，MPM模拟软组织，并考虑了两者间的双向接触，支持RL智能体训练特定子任务。
*   **[Failure Detection for Surgical Robot Imitation Policies via Flow-Matching World Modeling](https://arxiv.org/abs/2607.27511)**：提出了FoMo-FD，一种利用动作条件流匹配世界模型学习学习标称动力学的方法，在不需失败演示的情况下，实现了手术机器人策略的失效检测，并具有较高的检测率和低误报率。
*   **[MorphQuad: Morphable Quadrotor for Superhuman Maneuverability, Manipulation, and Resiliency](https://arxiv.org/abs/2607.02764)**：介绍了一种可变形四旋翼无人机，其四个旋翼系统可通过双轴云台独立偏转，实现了全向推力矢量化、全局稳定和操控能力。
