# Today's Robotics & AI Papers Summary

## Dexterous Manipulation & Grasping

### [GBPP: Grasp-Aware Base Placement Prediction for Robots via Two-Stage Learning](https://arxiv.org/abs/2509.11594)
Fast learning-based scorer that selects robot base poses for grasping from single RGB-D snapshots. Uses two-stage curriculum: distance-visibility rules for auto-labeling followed by high-fidelity simulation refinement. Outperforms proximity/geometry baselines on real mobile manipulators.

### [Vision-TL-Action: Neuro-Symbolic Trajectory Generation from Visual Observations and Temporal Logic](https://arxiv.org/abs/2607.26770)
Generates action trajectories from multi-view images, TL syntax graphs, and robot initial states using flow-matching with cross-attention fusion. Achieves 67.45% Success@1024 on Panda tasks, beating oracle-state baselines.

### [Reeling It In: Flexible Needle Pick Up via Thread Manipulation for Autonomous Suturing](https://arxiv.org/abs/2607.26337)
Uses suture thread as assistive tool for indirect needle pickup, enabling grasping even when needle is occluded. Evaluated on da Vinci Research Kit across various challenging conditions.

### [StructureGS: Structure-aware Gaussian Splatting for Articulated Object Reconstruction](https://arxiv.org/abs/2607.26889)
Integrates structure-aware guidance with 3D Gaussian Splatting using oriented bounding boxes to enforce spatial coherence and structural connectivity for articulated object reconstruction.

## Visuomotor & Imitation Learning

### [TurboVLA: Real-Time Vision-Language-Action Model at 32 Hz on an RTX 4090](https://arxiv.org/abs/2607.27205)
Reformulates VLA as direct V+L→A mapping without LLM as central interface. Achieves 97.7% success on LIBERO with 0.2B params, 31.2ms latency, and 0.9GB VRAM on consumer GPU.

### [CheckVLA: Execution-Time Verification with Action-Conditioned World Model](https://arxiv.org/abs/2607.26789)
Verifies VLA execution using frozen action-conditioned world model with conformally calibrated risk thresholds. Improves RoboCasa365 success rate from 27.6% to 36.1% over periodic replanning.

### [RL$^2$-VLA: Adaptive RL Latent Compositional Steering with Test-Time Scaling](https://arxiv.org/abs/2607.26991)
Adaptive inference-time steering combining offline RL with VLA latents. Activates compositional steering only when failure is predicted, improving out-of-domain success rates by up to +17.3%.

### [MoMo: Dial Motion Mode in Robot Manipulation with Spatiotemporal Action Tokenization](https://arxiv.org/abs/2607.26315)
Two-stage imitation learning framework learning motion modes as reusable behavioral factors. Demonstrates compositional generalization to unseen task-mode combinations across six real-robot tasks.

### [Teaching Tiny VLA Models Where to Look and How to Move](https://arxiv.org/abs/2607.04171)
XS-VLA framework teaching tiny VLA policies spatial grounding via distillation and flow-based action learning. Improves LIBERO average success from 82.8% to 90.3% with 0.25B model.

### [SG-CoT: An Ambiguity-Aware Robotic Planning Framework using Scene Graph Representations](https://arxiv.org/abs/2603.18271)
Two-stage framework where LLMs iteratively query scene graphs to detect and clarify ambiguities. Consistently outperforms prior methods with 10%+ improvement in question accuracy.

### [PACE: Phase-Aware Chunk Execution for Robot Policies with Action Chunking](https://arxiv.org/abs/2606.00537)
Training-free test-time method selecting execution horizons from predicted speed profiles. Raises RoboTwin2.0 success from 57.8% to 64.2%, ALOHA task scores from 60.7 to 77.7.
