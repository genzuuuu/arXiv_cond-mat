## 一、触觉感知与力觉反馈

**FORTH** 提出纯前向触觉编码与连续触觉验证门（SlipGuard），用于触觉 VLA 执行，抓握力峰值降低 29 倍，LIBERO 平均成功率 97.6%。  
[FORTH: Grounding Tactile VLA Execution via Forward-Only Proxy-Control Pairing](https://arxiv.org/abs/2611.26744)

**WiTac** 预训练腕部视觉-触觉融合编码器，约 300 小时 SharpaDex 数据，为 GR00T N1.7 与 π0.5 提供接触表示，四类接触丰富任务成功率提升（+28.8%/+15.0%）。  
[WiTac: Wrist-Informed Tactile Representations for Contact-Rich Manipulation](https://arxiv.org/abs/2611.21057)

**TacHOI** 训练-free 框架，用触觉接触约束单目自我中心视频中的手-物重建与跟踪，ARCTIC 误差从 15.6 cm 降至 3.6 cm。  
[TacHOI: Contact-Aware Object Reconstruction and Tracking for Egocentric Videos](https://arxiv.org/abs/2611.26764)

**Highly Deformable Proprioceptive Membrane** 可拉伸光波导硅胶膜，实时（~90 Hz）重建自身 3D 形变，形状误差 1.58 mm，接触定位误差 1.78 mm，可拉伸至 75% 应变。  
[Highly Deformable Proprioceptive Membrane for Real-Time 3D Shape Reconstruction](https://arxiv.org/abs/2601.13574)

**Geo-Force** 从深度几何定义“虚拟触觉传感器”的逐 taxel 力，证明旋转协变、接触即消失、Lipschitz 稳定性，并指出几何无法揭示刚度这一根本限制。  
[Geo-Force: A Theory of Force Sensing from Object Geometry](https://arxiv.org/abs/2611.26992)

**Capacitive Fingertip Array 机理分析** 金属指骨上电容指尖阵列的邻近-触觉机理建模（FEM），分析驱动屏蔽、TDM 帧率与力-材质耦合，主要为标定基线，尚无实测验证。  
[Mechanistic Analysis of Unified Proximity-Tactile Observation by a Capacitive Fingertip Array Constrained by a Metal Phalanx](https://arxiv.org/abs/2611.26950)

## 二、灵巧手、灵巧操作与多指抓取

**Task2Hand** 将操作需求文档转化为参数化灵巧手设计（SAGE Hand：4 指 16 DoF、引导手掌、对置拇指），六棱柱操作成功率 45.6%（LEAP 37.3%），双色圆柱 70.8%（51.6%）。  
[Task2Hand: A Contact-Grounded Skill for Parametric Dexterous-Hand Morphology Design](https://arxiv.org/abs/2611.27967)

**Latent Jacobian Steer (LJS)** 耦合关节空间扰动与潜空间语义，从预训练人形全身控制器中激发跨栏、开门、操作关节物体等分布外接触丰富行为；也迁移到目标条件灵巧手装配策略。  
[Latent Jacobian Steer: Eliciting Contact-Rich Out-of-Distribution Behaviors from Pretrained Humanoid Controllers](https://arxiv.org/abs/2611.27338)

**SiMDex** 用召回-排序-重排从约 3200 万自我中心人类视频中挖掘相似数据用于跨本体灵巧操作 VLA 后训练，仅用 <5% 数据将成功率从 47.7% 提到 61.7%。  
[SiMDex: Mining Similar Egocentric Videos for Cross-Embodiment Dexterous Manipulation](https://arxiv.org/abs/2608.04196)

**Koopman-UBM** 将灵巧技能表示为视觉流与动作流耦合的动力系统（Koopman 伪规划器），七项仿真、四项真机任务性能可比 SOTA，执行更平滑，支持自动在线重规划与遮挡鲁棒。  
[Going with the Flow: Koopman Behavioral Models as Pseudo Planners for Visuo-Motor Dexterity](https://arxiv.org/abs/2602.07413)

**FoRe** 力引导的抓取失败恢复框架，按力反馈划分阶段策略、局部 RL 训练重试策略，LIBERO-SUCTION 绝对提升 18.4%（VLA-Adapter）与 6.5%（π0.5），真机 25.0%/21.7%。  
[FoRe: A Force-Guided Framework for Autonomous Grasp Recovery in Vision-Language-Action Models](https://arxiv.org/abs/2611.27011)

**MIR-Depth / UA-Depth** 透明物体单视图 RGB-D 深度补全/恢复，为 6-DoF 抓取提供准确表面几何。  
[MIR-Depth: Multi-Range Refinement for Single-View RGB-D Depth Completion of Transparent Objects](https://arxiv.org/abs/2611.25417)  
[UA-Depth: Uncertainty-Aware Depth Restoration for Material-Agnostic Object Manipulation](https://arxiv.org/abs/2611.01645)

（另有 **Ahaan Dabholkar 等** 的 VLM 后门与 **Cleave** 等安全类论文，与操作本体关系较弱，略。）

## 三、VLA 策略、动作专家与预训练

**SCAP** 提出动作专家预训练阶段：视觉/文本 token 随机掩码，保留视觉-语言联合建模通路并降低视觉捷径依赖，四种 VLA 架构一致提升，真机三任务平均 76.67%（+25 个百分点）。  
[SCAP: Stochastic Context for Action Expert Pretraining](https://arxiv.org/abs/2611.27187)

**GenPA** 将图像生成骨干 + 轻量 19M 动作回归适配器直接变为策略，无需推理时生成或迭代去噪；LIBERO 99.10%、LIBERO-Plus 83.79%，H100 上 20.9 ms/动作块，比强 VLA/WAM 快 1.7–3.4×。  
[GenPA: Image Generators as Efficient Robot Policies](https://arxiv.org/abs/2611.27446)

**La-JEPA** 紧凑世界-动作模型，在冻结 V-JEPA 2.1 特征空间从零训练策略 transformer，无具身预训练即达 RoboTwin 2.0 / LIBERO-Plus SOTA，推理比 Fast-WAM 快 2–5×。  
[La-JEPA: Compact Robot Policies with Latent World Modeling](https://arxiv.org/abs/2611.08156)

**Interval Motion Supervision** 利用动作监督缺口两端可靠位姿的净位移/旋转做组合约束，LIBERO 20% 演示、70.5% 动作缺失下平均成功率 87.9%，真机五任务 59.6%（masking 48.8%）。  
[Learning from Incomplete Actions: Interval Motion Supervision for Vision-Language-Action Policies](https://arxiv.org/abs/2611.27171)

**LexiconVLA** 学习可复用原子动作码本（全局 + 细节），跨任务检索复用，26 个 RLBench 任务上未见任务成功率 16.67%→34.17%。  
[LexiconVLA: Learning Reusable Atomic Action Codebooks for Manipulation](https://arxiv.org/abs/2609.36774)

**Beyond Linear Decodability (LDS)** 发现指令跟随 WAM 中目标信息线性可分性更强，提出线性可解码监督，LIBERO-CF 成功率 74.6%（+26.8）、grounding 89.2%（+42.9）。  
[Beyond Linear Decodability: Understanding and Improving Instruction Following in World Action Models](https://arxiv.org/abs/2611.27401)

**RynnUnify** 16B 统一具身模型，视频-语言交错推理 + 世界-动作扩展，20 个 RoboCasa365 组合任务 51.5%，真机三任务 46.7%。  
[RynnUnify: Towards Unified Embodied Brain](https://arxiv.org/abs/2610.32965)

**Phoenix** 学习场景结构表示的世界-动作模型（DINOv3 双教师蒸馏 + CS-VAE），约 3.9 万小时预训练，LIBERO-Plus 94.8%、RoboTwin 2.0 C2R 72.4%。  
[Phoenix: Learning Scene Structure Representations for Generalizable World-Action Models](https://arxiv.org/abs/2611.24938)

**DIDO** 将多步视频世界模型蒸馏为单步去噪，并用抓取器/物体交互 token 与 DINOv3 对齐引导，LIBERO 99.0%、LIBERO-Plus 76.6%、RoboTwin 92.0%，真机长程迁移有效。  
[DIDO: Distilling Interaction-Centric Dynamics into One-Step Denoising for World Action Models](https://arxiv.org/abs/2609.15570)

**ReActWAM** 训练-free 的动作一致性缓存，动作意图引导前缀跳过 + chunk 内去噪复用，LIBERO-Long/RoboTwin 2.0 加速 1.41–5.44×，FR3 真机端到端 1.46×。  
[ReActWAM: Action-Consistent Caching for Efficient World-Action Models](https://arxiv.org/abs/2611.27372)

**CoMP** 针对 flow matching 策略的认知不确定性传播，证明 BayesDiff 方差以 O(1/T) 衰减，提出协方差递推修正，用于失败检测与演示筛选。  
[Coherent Moment Propagation: Epistemic Uncertainty for Pre-trained Robot Policies](https://arxiv.org/abs/2611.26855)

**SCAP 之外的多客户端 VLA 服务** 表征批处理与协同执行在延迟/吞吐/功耗/利用率上的权衡，属系统层分析。  
[Analysis of Multi-Client Inference Techniques for Vision-Language-Action Models](https://arxiv.org/abs/2611.26944)

## 四、世界模型、视觉规划与预测

**Skill-JEPA** 用状态条件 VAE 学习与规划器对齐的潜技能动作空间，规划器在高斯空间搜索，80 步远目标成功率 42%→62%，AntMaze 两格 0.4%→38%。  
[Skill-JEPA: Learning Planner-Aligned Action Spaces for World Models](https://arxiv.org/abs/2611.26825)

**LoCo-WAM** 测试时训练低秩适配器积累历史经验（不增加输入窗口），RoboCasa GR-1 上 2.4 s 历史匹配 9.6 s 训练模型，4.8 s 超出 4.8 个百分点。  
[LoCo-WAM: Test-Time Training as Long Context for World-Action Models](https://arxiv.org/abs/2611.26853)

**PACE-WM** 用已执行动作历史做并行世界模型预测，提出 RAMP 动作选择，四个视觉规划任务平均 98% 成功率，规划比自回归 LeWM 快 7–9×。  
[PACE-WM: Parallel World Modeling with Action History for Visual Planning](https://arxiv.org/abs/2611.27173)

**MomentMem** 视觉“时刻记忆”：VLM 选关键帧、执行器条件于记忆动作，VMBench 平均 49.9%（最强基线 +31.7 点），记忆选择器零样本迁移良好。  
[MomentMem: Memorizing Key Moments for Robot Manipulation](https://arxiv.org/abs/2611.26745)

**MoReWorld** 运动区域引导的动作条件视频世界模型，统一局部运动预测、区域感知监督与运动门控条件，WorldSimProbe 上模拟器保真度最高。  
[Learning Interaction Dynamics via Motion-Region Guidance for Robotic Video World Models](https://arxiv.org/abs/2611.27344)

**NoPeWorld** 防止交互视频世界模型中的物体穿透：在冻结 DiT 隐状态上训练安全头，六种视频世界模型平均违规率 74%→16%，零样本泛化到开放域与移动障碍。  
[Non-penetrating World Models](https://arxiv.org/abs/2611.27963)

**SOAR** 训练-free rollout 压缩，按决策自适应选 token 预算以保排序，七个导航/操作任务 2.3× 加速且成功率持平。  
[SOAR: Training-Free Rank-Consistent Rollout Compression for Latent World Model Planning](https://arxiv.org/abs/2611.27639)

**Ego4Gen / FlowInverse** 从单张自我中心图联合生成 RGB、稠密点图与场景流，4D 潜变量可解码为 3D 或映射为机器人动作。  
[Ego4Gen: Generating Geometry-Grounded Motion Tokens as a World-Action Interface](https://arxiv.org/abs/2611.27513)

**WorldFlow** 联合预测未来视频与查询式 3D 轨迹（MoT 骨干、rectified flow），WorldFlowBench 上 ADE/FDE 最低，SpatialCog ADE 降 54.2%。  
[WorldFlow: Joint Video and 3D Motion Prediction via Large-Scale Pretraining](https://arxiv.org/abs/2610.39278)

**GenSight** 统一视频生成与稠密 4D 感知（深度、本体分割、首帧相对 2D 流），共享 DiT 与速度预测空间。  
[GenSight: Unified Video Generation and 4D Perception for Embodied World Modeling](https://arxiv.org/abs/2610.39232)

**LoopNav** 基于 Minecraft 环路导航的 200 小时数据与 Scene Graph Consistency Score，评估世界模型长程空间一致性。  
[LoopNav: Benchmarking Spatial Consistency in World Models](https://arxiv.org/abs/2505.22976)

**PhiJEPA** 两阶段潜预测（掩码 Transformer + token MLP），ImageNet-1K 预训练，线性 PASCAL VOC 69.3 mIoU，用于 DINO-WM 遮挡补全时 PushT 成功率 33%→65%。  
[PhiJEPA: Denoising Latent Predictions for Visual Representation Learning](https://arxiv.org/abs/2611.27516)

**CoMP / NormFlowSDE** 后者为归一化流 + 神经 SDE 的摊销贝叶斯状态估计，面向接触丰富操作中难建模动力学，估计误差最低且比最快粒子滤波快 4×。  
[NormFlowSDE: Normalizing Flows for Amortized Bayesian State Estimation](https://arxiv.org/abs/2611.27362)

## 五、遥操作、人机协作与交互

**LocoPilot** 单操作员双边遥操作框架（Go2 + 双 Piper L），无力矩传感器估计交互力并经无源性约束触觉通道反馈，统一 11D 动作接口用于采集与部署，微调 MolmoAct2 后真机零重定向部署。  
[LocoPilot: Single-Operator Bilateral Teleoperation for Loco-Manipulation Policy Learning](https://arxiv.org/abs/2610.27998)

**TRIP (Tripwire)** 训练-free 事件驱动 harness：智能体在调用策略时编写“绊线”程序，配合紧凑 VLM 监测人类干扰并中断/交还控制；RoboHD 上人机接触率减半，安全率 61.3%→81.3%，任务成功率不降。  
[Tripwire: Robot Agents that Program Their Own Interrupts under Human Disturbance](https://arxiv.org/abs/2611.27182)

**EIP** 全双工人机交互统一流式策略，音频交互专家与动作专家逐层联合注意力，支持主动回应与打断式轮流，warm-start 延迟降低 64%。  
[Embodied Interaction Policy: A Unified Model for Full-Duplex Human-Robot Interaction](https://arxiv.org/abs/2611.27327)

**Humanoid 电气切换安全滤波** VR 遥操作 Unitree G1，基于头部相机场景模型与目标条件 CBF-QP 避免误触非目标开关，真机 10/10 目标操作成功、无非目标动作。  
[Humanoid robots for safety-critical electrical switching: A perception-informed runtime constraint filter](https://arxiv.org/abs/2611.27845)

**Ego2Ego** 生成式视觉视角采择：给定自我中心视频、点云与协作者相机轨迹，生成协作者视角连续视频，为 HRC 与机器人学习提供多视角同步数据。  
[Ego2Ego: Generative Visual Perspective Taking Across Collaborators](https://arxiv.org/abs/2611.27459)

**BeyondEgo** 人形 loco-manipulation 引入外中心视角 DINOv3 token 与双视角 0.6 s 未来表征作为特权监督（部署时丢弃），HELM 基准分布内 48%→92%，200 个分布偏移场景 23.5%→65%。  
[BeyondEgo: Learning to Act Beyond Egocentric Perception via Humanoid Ego-Exo Foresight](https://arxiv.org/abs/2611.27047)

**EgoSurgHands** 开放手术训练自我中心 3D 手部姿态数据集与基准（41,909 训练行 / 9,476 验证行），评估八种零样本方法，JointTransformer 最优 14.95 mm。  
[EgoSurgHands: An Egocentric 3D Hand Pose Dataset & Benchmark for Open Surgery Training](https://arxiv.org/abs/2611.27101)

**EgoPhys** 从单段自我中心 RGB 交互构建可形变物体物理数字孪生（弹簧-质点 + 状态条件残差），预测更优且局部精修成本降 10–59×。  
[EgoPhys: Physics-Informed Digital Twins for Deformable Objects from Egocentric Video](https://arxiv.org/abs/2606.16202)

**HermiteTwin** 双三次 Hermite 壳数字孪生，形变与接触分辨率解耦，真实布料/泡沫操作上重建、重仿真与未来预测均优于弹簧-质点。  
[HermiteTwin: Bicubic Hermite Shell Digital Twins for Contact-Rich Deformable Manipulation](https://arxiv.org/abs/2611.27282)

**HumanoidPose** 单目人形机器人 3D 全身姿态估计基准与框架（合成 3D 监督 + 真实 2D 标注 + 真机 Roban 状态评估）。  
[HumanoidPose: Monocular 3D Pose Estimation for Humanoid Robots](https://arxiv.org/abs/2611.27181)

## 六、仿真、基准与评估

**RoboDyna** 20 个动态概念任务 + 10 个家庭任务，物理落地动力学与同步/异步评估；5.4K episode 上所有策略成功率 <20%，推理延迟翻转 5–12% episode 结果。  
[RoboDyna: A Benchmark for Evaluating Robotic Manipulation under Physically Grounded Dynamics](https://arxiv.org/abs/2611.26969)

**RoboPRO** 80 个双臂原子/组合任务、四个室内环境、16K 演示，含干扰物密度与两个安全事件指标，系统分析视觉/语言/物体扰动。  
[RoboPRO: A Perturbation-Resilient and Obstacle-Aware Benchmark for Robotic Manipulation](https://arxiv.org/abs/2611.26971)

**RoboColiseum** 仿真-评估-模型协同平台，22 组真-仿配对任务 Pearson 0.9686，八条评估赛道（含灵巧、精密、全身协调）。  
[RoboColiseum: Co-evolution of Simulation, Evaluation, and Models](https://arxiv.org/abs/2611.27042)

**ManipScope** 诊断基准：48 个变化需求场景，84.6% 失败源于抓错干扰物，十个 checkpoint 仅在 3.9% 状态上完全遵循指令。  
[ManipScope: A Diagnostic Benchmark for Instruction Following and Generalization in Robotic Manipulation](https://arxiv.org/abs/2611.27305)

**ROSWorld** 物理仿真机器人工作站 + 实时 OSWorld 桌面，同一目标下桌面 agent 完成 31–39 任务，机械臂仅 ≤23（探针）/≤28（灵巧手）。  
[ROSWORLD: When Digital Task Competence Meets Physical Execution](https://arxiv.org/abs/2611.27467)

**Staleness Deadlines** 语言模型规划期间用行人预测区域与偏差管设定“过期期限”，Qwen3-4B 81,000 次仿真任务中错误决策约降 20 倍，迟到至多降 64%。  
[Staleness Deadlines for Motion Plans during Onboard Reasoning](https://arxiv.org/abs/2611.26858)

**RoboCap-10k** 10,000 小时自我中心操作数据，单设备六同步全局快门相机 + 双 IMU，<1 px 极线误差、cm 级手部位姿，标注任务/子任务语言。  
[RoboCap-10k: A Metrically Accurate Egocentric Dataset for Robot Learning](https://arxiv.org/abs/2611.26916)

**γ-Scape** 面向移动具身智能的 agent-centric 仿真与基准平台，结合导航与操作、接触丰富交互采集与程序修订。  
[γ-Scape: An Agent-Centric World for Mobile Embodied Intelligence](https://arxiv.org/abs/2611.27306)

**Mem-X** 跨 episode 记忆依赖 VLN 基准（2,071 episodes / 710 sessions），配套 MemBridge 模块化基线。  
[Mem-X: A Memory-Dependent Cross-Episode Benchmark for Vision-and-Language Navigation](https://arxiv.org/abs/2611.27166)

**2Dor3D** 3D VLA 的 2D/3D token 联合剪枝，RLBench/LIBERO 端到端加速 1.86–2.10×，成功率仅降 0.5–0.6 个百分点。  
[2D or 3D? Rethinking Token Pruning in 3D VLAs with Cross-Modal Correlation Awareness](https://arxiv.org/abs/2604.09244)

**SparseHPS** 单一权重从点云恢复 SMPL-X，兼容深度相机与 LiDAR（密度差 10× 以上），SLOPER4D/FreeMotion 根相对关节误差降 22%/11%。  
[SparseHPS: A Unified Model for Human Pose and Shape across Depth Cameras and LiDARs](https://arxiv.org/abs/2611.26730)

## 七、运动规划与强化学习

**SI-MPPI** 将 MPPI 轨迹优化嵌入 MCTS 树搜索（bait 引导、GPU 批处理、ESS 自适应），四个大规模 2D 栅格地图上搜索树最小、角控制最平滑。  
[Search-Informed MPPI for Kinodynamic Motion Planning via Monte Carlo Tree Expansion](https://arxiv.org/abs/2611.26763)

**GeoSDF-Diff** 多尺度 SDF 条件扩散规划器，交叉注意力注入 DiT-X，轨迹级 SDF 间隙/违规/平滑/路径长联合训练，未见杂乱环境 65.2% 成功率（+25.4–28.5）。  
[GeoSDF-Diff: Geometry-Aware Diffusion Planning for Collision-Free Trajectories](https://arxiv.org/abs/2611.27373)

**MPAO** 连续时间 top-quality 多样规划：采样满足边界条件的未训练网络、共享修正、随时采样，接触丰富操作上唯一达到 best-cost 25% 内的方法。  
[Many Plans at Once: Diverse Top-Quality Planning in Continuous Time](https://arxiv.org/abs/2611.27012)

**PACE** 四足运动：联合空间扰动观测器 + 前馈力矩补偿 + 策略观测增强，11 种动力学条件下速度跟踪误差降 18.1–57.0%，真机负重 11.5 kg（近自身质量）、16 cm 下台阶与五种户外地形。  
[PACE: Policy Augmentation and Compensation With Explicit Disturbance Estimation for Robust Locomotion](https://arxiv.org/abs/2611.27061)

**S-BFM** 从稀疏时空目标（姿态、位置、到达时间）生成人形全身过渡，仿真全局关节误差降 32%+，固定目标到达 43.5%→74.6%，部署于 AGIBOT A3。  
[S-BFM: A Behavioral Foundation Model for Humanoid Control from Sparse Spatiotemporal Goals](https://arxiv.org/abs/2611.27552)

**Trust What Repeats (Capped WMPG)** 人形运动跟踪：世界模型策略梯度中梯度范数前 0.5% 的 rollout 不可靠，按批中位数 10× 截断 + 按预测梯度范数采样起点，SuperMimic 归一化回报 0.953→0.967，训练时间减半。  
[Trust What Repeats: Capped World-Model Policy Gradients for Humanoid Motion Tracking](https://arxiv.org/abs/2611.27648)

**TRQAM** 对预训练 flow 策略做 off-policy RL，通过信任域 λ 精确加权路径空间 KL，50 个 OGBench 任务离线 RL 68%（最强基线 46%）。  
[Trust Region Q Adjoint Matching](https://arxiv.org/abs/2605.27079)

**THRIFTY** Thompson 采样 bandit 控制器，按 token 预算收集多样正确推理轨迹，每 token 多 22% 多样正确轨迹。  
[THRIFTY: Cost-Constrained Reasoning-Data Synthesis for Small Language Models](https://arxiv.org/abs/2611.27436)

**ADAPT** 小模型 agent 的 advisor-aware 后训练，TextWorld 24.5%→77.3%、LiveCodeBench 21.8%→56.0%、GAIA 17.5%→49.3%，每任务仅约 1–2 次求助。  
[Learning When to Ask: Advisor-Aware Post-Training for SLM Agents](https://arxiv.org/abs/2611.27443)

**PEAR / RURL** 在仿真中用强化学习训练 27B 开源推理模型原生使用真机，LIBERO 1.6%→74.4%，真机双臂 60%（基座 0%），LIBERO-Pro 新任务 57.4%（π0.5 仅 0.75%）。  
[Training Reasoning Models in Simulation to Natively Use Real Robots](https://arxiv.org/abs/2611.18562)

**SLA-Aware Offloading** IoT 边云任务卸载的类加权 DRL 与精确动态规划对比，类盲惩罚比最优高 65–118%，修正后 0.13% 内。  
[SLA-Aware Task Offloading in the IoT Edge-Cloud Continuum: Class-Weighted Deep Reinforcement Learning Against an Exact Optimum](https://arxiv.org/abs/2611.10638)

## 八、Sim-to-Real 与机器人感知系统

**LiDAR Signals for Locomotion** 传感级（还原真实 LiDAR 角采样 + GPU 光线投射）与表示级（球面距离图）对齐，四足运动 sim-to-real 优于深度图/高程图基线，无需 teacher-student 或在线建图。

[Instant-LIVO: Efficient LiDAR-Inertial-Visual Odometry with Compact Geometry and a Bounded Single-Reference-Frame Map](https://arxiv.org/abs/2611.27633)

**HermiteTwin / EgoPhys** 见前文（形变物体数字孪生）。

[Trailblazer-F: Speculative Action-Flow Inference for Autonomous Driving](https://arxiv.org/abs/2611.27226)

**GGDriver** 每个候选轨迹投影走廊并按其自身路径证据打分，三个规划器上均提升，ViT-S 无感知标签达 WOD-E2E 8.110、NAVSIM-v1 94.2 PDMS。  
[GGDriver: Glance at What Is Shared, Gaze at What Differs for Perception-Free Planning](https://arxiv.org/abs/2611.27330)

**StereoVLM** 首个几何感知双目 VLM，分层学习跨视图对应→视差→标定条件度量深度→语义空间推理，Stereo3D-Bench 深度精度 95.17%，RoboCasa 操作成功率 +4.3 个百分点。  
[StereoVLM: Binocular Vision-Language Models for Metric 3D Spatial Reasoning](https://arxiv.org/abs/2611.27915)

**R3D** 自我中心可穿戴定量 3D 空间推理：RGB-D 构建场景 + 七个可组合空间工具供 LLM 调用，R3D-Bench 上 Qwen3.6 35B 达 55.6%，Qwen3-VL 235B 57.0%。  
[R3D: Quantitative 3D Spatial Reasoning for Egocentric Wearables](https://arxiv.org/abs/2607.02921)

**Contexture / ESSENCE / FreqCache** 分别面向 agent serving 的 KV 驱逐、视频 LLM token 预算分配与流式 VLN 缓存，属效率优化，与操作间接相关。  
[Contexture: Runtime Context Eviction for High-Throughput Agent Serving](https://arxiv.org/abs/2611.26980)

[Frequency-Enhanced Token Caching for Efficient Streaming VLN Models](https://arxiv.org/abs/2604.24391)

## 十、简要提及（与操作/具身弱相关）

VLA 安全与后门（[Cleave](https://arxiv.org/abs/2611.27426)、[TrojanMaxxing](https://arxiv.org/abs/2611.27425)、[SecretAgent](https://arxiv.org/abs/2611.26936)）、GUI/computer-use agent 基准（[ScopeAct](https://arxiv.org/abs/2609.30186)、[SkillForgeBench](https://arxiv.org/abs/2610.14918)）、医疗 agent（[LesionAgent](https://arxiv.org/abs/2611.27876)、[MedicalRSI](https://arxiv.org/abs/2611.26806)）、科学发现 agent（[Unsatz](https://arxiv.org/abs/2611.03713)、[LUCA](https://arxiv.org/abs/2611.03100)、[AutoDFT](https://arxiv.org/abs/2605.26179)）等，与具身操作主线关联较弱，未展开。

**总体观察：** 今日投稿中 VLA/世界-动作模型（WAM）已高度融合，JEPA 系潜空间预训练与动作空间对齐成为热点；触觉侧从“是否有力感知”转向接触几何、滑移检测与腕部视觉融合；灵巧手设计开始与策略训练闭环（Task2Hand）；基准建设明显从静态抓取转向动态、扰动、记忆与执行延迟；sim-to-real 的焦点从深度图转向 LiDAR 传感级对齐与结构化表示。
